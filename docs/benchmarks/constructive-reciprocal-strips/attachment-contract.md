# Attach downstream processors and integrate graph deltas

Input: original graph snapshot, independently validated reciprocal-strip portfolio,
retained cycle-block inventory, runtime catalogs and independent validator executable.
The complete factory incumbent is retained separately throughout the experiment.

For each strip candidate, apply its explicit compatible-allocation delta to a private
normalized graph. Require every replaced edge to exist, unique replacement identities,
unchanged item/transport and exact per-node per-item input/output margins. Reject stale,
duplicate or unbalanced deltas. Do not silently reuse the old graph's split supply edges.

Attach the original downstream consumer bank using the shared structured composition
engine, considering its packed/source row portfolios and safe interface compaction.
Also test a single-input direct attachment: enumerate unused supplier ports, east-flow
consumer rotations/ports, and shared or adjacent connection cells. Derive placements from
those actual port pairs, independent of the supplier's global face. Reject all retained
body/transport collisions and preserve at least one straight-east free consumer output
for subsequent structured composition. No longer path or extra logistics component is
silently introduced by this direct family. Normalize actual used coordinates afterward.
Directions unsupported by the east-facing composition interface remain recorded local
candidate failures. Each private expanded region must independently validate exact recipes,
membership and outgoing margins before selection. Choose area, tiles, then turns.

Validation policy is ranked by default, with exhaustive available as an explicit control.
Sort each block's generated candidates by the exact same score and stable directory-name
tie break as final selection; validate until the first accepted candidate. Later candidates
cannot win that selection rule and need no per-candidate files. Report generated, validated
and skipped counts separately. A rejected best-score candidate must advance to the next,
never promote without validation. Compare selected witness hashes with the exhaustive control.

Keep unsupported larger reciprocal regions from the validated retained block inventory;
do not discard their shared producers. After selecting seven replacements, apply their
disjoint graph deltas once to the original snapshot and revalidate every selected region
against that combined graph. Emit graph.json in the existing snapshot contract plus
blocks.json in the existing region-inventory contract for normal cluster composition.

This is a geometry/input experiment, not a compatibility shim or production cutover.
The final factory must still include all original members, recipes, rates and real external
obligations. A smaller partial region is not evidence of smaller complete-factory area.
Inspect the attached region and complete result, recording any new placement obstruction.
