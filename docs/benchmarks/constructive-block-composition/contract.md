# Structured compound-block composition

Status: research. Preserve validated block interiors; no production cutover or whole-graph claim.

Inputs are the normalized actual requirement graph, runtime catalogs, concrete cyclic/compound
block witnesses and a selected ready consumer frontier. A facility belongs to exactly one region.
Every newly introduced consumer must have all recipe inputs supplied by retained members; this
first slice handles belt-only frontiers with no new incoming external obligations.

Pack whole source regions, translate all concrete geometry and namespace component/requirement
identities. Preserve every existing rate, directed segment and terminal relative to its region.
Aggregate compatible networks without treating a disconnected physical commodity as a new source.
Choose free east-facing output ports with unobstructed horizontal access to the common source face.
Place new consumers near supplier port rows, respecting their order and non-overlapping bodies.

Allocate only the original outgoing margins consumed by the new frontier. A shared supplier's
unmatched output remains an exact pending graph cut, not an external terminal or a second facility.
Preserve all recipe utilizations. Plan an ordered port interface with fixed split/merge/cross modules
before lowering its paths. Use a shared single cell when all matched faces are exactly aligned.

Output includes witness v1, original membership, cut obligations, port assignments, region
translations, exact allocation, geometry reservations, score, timing and structured failures.
Compare only independently validated candidates by area, physical transport tiles, then turns.
Compaction creates a separate candidate. Keep prior valid artifacts when expansion fails.
Component count is diagnostic only, never a score term or a reason to reject a smaller layout.

The bounded bank-order search uses port pressure, inversions and allocation fragment count as
construction heuristics, not the final objective. Compare packed lane rows with source-height
preserving rows, each with and without strip compaction. Nonuniform rows are monotone with a
three-cell minimum separation: stretch complete paths and junctions together, materialize unit
steps, and retain the explicit row transform in diagnostics. This does not prove minimum area.
Cache at most eight translated bank orders. Index the rightmost occupied belt/body/component
cell per row to test straight source-face access without repeatedly rasterizing long empty rays.

IDs inside translated networks are reindexed per region, not recursively JSON-encoded. Original
facility identities and graph cut IDs remain unchanged. Dictionary keys may be arbitrary accepted
facility strings, including prototype-named IDs. Reindexing is research-only: production's stable
improvement-history identifier contract is not replaced by this experiment.

Profiles separate stack/index construction, node setup, allocation, complete ordering, port placement,
interface geometry, lowering, compaction, validator execution and CLI elapsed time. Ordering fields
are shared by portfolio candidates; do not sum them across candidates. Materialization guards are
diagnostic resource limits, not game canvas limits or infeasibility proofs.

Acceptance requires independent covered-geometry validation AND exact graph coverage: one owner
per original member, all original recipe inputs satisfied, no external terminals, pending outputs
exactly matching remaining original cuts. This remains a partial factory until all members and
actual external obligations have been completed. Width/height are measured, never caller limits.

Initial gates: actual nine-facility shared-supplier composition, its fourteen-facility completion,
then all ready processing frontiers. Inspect actual rendered output at every meaningful gate.
An exit obstruction or exhausted order/cell search is a local planner failure, not infeasibility.
The current no-ready-belt-frontier stop retains the last accepted partial witness and exits 2.
It does not authorize omitting mixed-transport facilities or replacing original external obligations.
