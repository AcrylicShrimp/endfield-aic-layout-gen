# Connected cluster packing

Status: research improvement candidate; retain the independently validated complete incumbent.

Input: original normalized graph, runtime catalogs, validated source cycle blocks and a complete
incumbent report. Identify connected components in the bipartite region/ready-consumer graph. A
shared source region belongs to one component only; never duplicate its facilities or its rates.
Within each component, attach all closed-input belt frontiers through the existing structured
interface planner. Independently validate each stage before retaining it. Unsupported regions remain
explicit failures rather than being dropped from the request.

Output cluster witnesses cover their exact original membership and pending outgoing margins. The
packing stage translates whole concrete clusters, including ports, components and all network cells.
It compares a bounded portfolio of horizontal/vertical shelf orders and alignments; this is not a
minimum-area proof. Partial packing success is not factory success. Every candidate must pass the
original graph coverage gate and then complete the unchanged mixed-transport closure stage.

Select only complete independently validated factories by area, physical transport tiles and turns.
If none beats the complete incumbent, retain its original artifact and score. Diagnostics include
cluster ownership, growth stages, pack translations, candidate failures, complete scores, hashes and
separate construction/validation/closure timings. Never weaken a gate to obtain a smaller result.

The current portfolio runs both simple and perimeter corridor families for each packed candidate,
with two closure processes in parallel and at most four independent validators per closure process.
Revalidate a purported complete child result independently before it enters the improvement ranking.
Keep partial closure scores explicitly labelled partial/complete observations, never complete scores.
Whole-region translation is shared with the existing stack constructor; generated geometry DTOs are
detached so candidate mutation cannot alter another retained region.

The optional occupied-cell nesting family enumerates integer relative translations of exactly two
fixed concrete clusters in a measured contact neighborhood. Row bitsets reject body/body, body/any
transport and same-layer collisions; independent belt/pipe overlap remains legal. Select a bounded,
spatially diverse low-area shortlist for full closure, without claiming globally optimal placement.
The complete incumbent remains available even if every shortlisted partial packing fails to close.
Record the exact search domain, number of tested/collision-free translations, shortlist policy and
separate enumeration/closure times. Bitset extent and shortlist bounds are diagnostic resource limits,
not game geometry limits. Full independent geometry and graph-margin checks remain mandatory.

Before shortlisting, screen the remaining outgoing edges against catalog-projected unused output
ports. Each edge needs ceil(rate / transport capacity) ports in the current separate-edge closure;
count these per source and transport. A connection cell must avoid both bodies and its own transport
layer in either translated region. Opposite-layer cells do not block it. Report collision-free and
output-accessible counts separately, with low-area rejection examples and structured diagnostics.
This necessary-condition screen is scoped to the fixed-interior unused-port strategy, not a proof
against shared trunks, reassignment or rip-up. A free connection cell does not prove route reachability.
