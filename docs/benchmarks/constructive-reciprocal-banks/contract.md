# Adjacency-constrained reciprocal bank reconstruction

Input: runtime catalogs, normalized production graph, retained concrete source-bank
inventory and explicit target bank ID. The downstream whole-factory comparison also
receives the complete incumbent. Retain all other bank
witnesses unchanged. Identify the target's two-commodity reciprocal family from recipe
inputs/outputs, not facility names or labels. Ordinary processors remain pending until
the reconstructed source family has valid geometry.

Enumerate touching alternating strips and runtime-allowed per-recipe orientations
under explicit small-group budgets. Keep the return-commodity allocation fixed.
Forward-commodity allocation may change only within the selected bank's current
source/target margins. Direct internal arcs require available adjacent connection cells
and at most one catalog-capacity line per source/target pair. Pending ordinary consumers
participate in the exact flow calculation so no production disappears at the cut.
An exact rational max-flow chooses compatible allocations. Apply the existing checked
graph-delta contract before accepting any such allocation.

Assign actual ports jointly and route every retained internal edge with a two-cell
connection. A private candidate must validate physical geometry, covered recipe margins
and pending interface access. This is a bounded template family, not general infeasibility
or minimum-area proof. Return allocation, alternating order and shared recipe orientation
are explicit experiment restrictions, not game rules.

Use actual SCCs of the resulting allocation to expose independently checkable input-
closed construction prefixes: include source SCCs, then ready dependent atoms. A region
is not published as usable unless all required prefix and final checks pass. This is
an atomic reciprocal-bank research transaction, not a facility-only global placement.
Prefixes are projections of a privately planned bank, not a production frontier event
trace. This experiment does not replace the Rust constructor's immediate-routing contract.
Then attach the bank's ordinary consumers through the existing shared structured
interface and independently validate the complete replacement bank.

Output a new graph snapshot, source-bank report compatible with the current research
constructor, and explicit candidate/allocation/prefix/validation diagnostics. Preserve
exact outside obligations and disjoint ownership. Retain only variants sharing the
selected checked allocation in the emitted shape portfolio. Do not migrate to Rust.
Finally reconstruct and independently audit the whole factory before promoting any
improvement over the complete incumbent. Report time by generation and validation,
write detailed JSON/log files, and keep stdout to a short completion record.
