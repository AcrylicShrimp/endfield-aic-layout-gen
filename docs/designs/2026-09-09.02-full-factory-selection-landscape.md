## Bounded hypotheses

Compare five fresh depth-zero, width-32 policies from the same training seed 17:

| Arm | Candidate prior | Observed-failure memory | Episode horizon |
| --- | --- | --- | --- |
| flat | Flat candidates | No | 8 |
| balanced | Equal operation mass at zero logits | No | 8 |
| memory | Flat candidates | Yes | 8 |
| balanced-memory | Equal operation mass at zero logits | Yes | 8 |
| longer | Equal operation mass at zero logits | Yes | 32 |

For balanced selection subtract log available-candidate count for that operation
from each action logit before constructing the categorical distribution. Learning
can change operation mass. Keep the same categorical entropy objective; its optimum
need not preserve the initial operation balance. This is a sampling intervention,
not a proof that equal operation mass is optimal.

Memory stores actions only after they are selected and observed to fail, leave
geometry unchanged, or revisit geometry. Key states by order-independent physical
witness contents, including stable entity identities and rates. Key reroutes by
network identity and directed chain geometry, not enumeration index; include the
best witness identity in rollback keys. On revisiting that same state, mask only
remembered unsuccessful actions. Do no extra routing or validation to populate this
memory. If all actions are masked, explicitly allow charged restore-best and record
the exhaustion. Masks are heuristic episode history, not infeasibility proofs.
Memory resets at each independent episode. No recurrent model is claimed.

Every arm receives 4096 selected training actions with the same four rotating roots,
terminal-rank objective, learning rate, entropy coefficient and four episodes per
update as the preceding screen. Thus horizon eight has 128 updates and horizon 32
has 32; this compares episode/update regimes and does not isolate horizon from the
number of updates. Freeze initial/final policies, optimizer/RNG state and all traces.
No existing training stream or final policy is resumed.
