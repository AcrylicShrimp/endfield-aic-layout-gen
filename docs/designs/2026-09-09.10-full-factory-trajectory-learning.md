# Original trajectory learning across opened families

Status: implemented; corrected-context shallow comparison and independent audit complete.

## Contract

Use the completed family admission and capability artifacts as explicit inputs.
The schema-1 experiment declares admission report, imported original inputs,
teacher probe, optional additional evaluation roots, update count and episode
bounds. Hash all original requests and teacher records. Join case identities
against the preassigned admission family/split; do not infer a split from geometry
or silently train on an evaluation family. Additional evaluation roots cannot
contribute lessons. All participating evaluation families have already been opened.

Replay each recorded improving geometry trajectory from its original native
session. Every teacher action must be ordinarily offered, produce the recorded
native status and metrics, improve the retained score, and recover the recorded
final witness. Record each pre-action validated state and the selected action as
a lesson. Preserve original obligations, family, split and sequential position.
Preserve the original episode's initial and best metrics as well as the current
metrics. Reopening a witness for admission must not reset the observation's
current/original and best/original ratios. Check its reconstructed float32 context
against the context recorded during the original trajectory replay.
This dataset records actual compression, without adding inverse perturbations.
Generation is measured work; lessons are not populated from failed edits.

Train the unchanged schema-three depth-two width-32 policy by cross entropy on
training-family teacher choices, with seed 17, Adam at 0.0003 and gradient clipping
0.5. The declared final update is the only learned checkpoint selected for rollout;
development labels cannot select updates or change the curriculum. Cache bounded
lesson observations for this small screen and report their aggregate array bytes.
Retain weights, optimizer and RNG state and an update log with loss/gradient/source.

Compare untrained, learned, uniform and existing geometry selection with the same
eight-action/30-second/5000-route-expansion episodes and history mask. Use two fixed
sampling seeds per original root. No rule removes actions because a model predicts
failure. Every selected edit executes the ordinary physical engine and native
acceptance. Keep best validated layouts, shortened/late episodes and unchanged
actions in the report; exhaustion is not a successful full-budget episode.

## Outputs and interpretation

Produce protocol, replay-admitted lessons, checkpoint and update records, per-episode
best/trace payloads, grouped paired scores and a final report. Structured failures
name the admission/replay/training/evaluation stage and affected case or lesson.
Independently validate every retained best against original graph coverage and the
complete area/physical-transport/terminal-aware-turn metric. Keep data and generated
views under ignored artifacts and commit concise findings and reproduction sources.

The known geometric teacher selects strip contractions on these sparse new roots.
Report whether the learned policy approaches that baseline as well as whether it
beats random/untrained selection. Better teacher imitation is not evidence of
learned relocation, pipe-path optimization, dense-layout compression or unopened
family generalization. Original Heavy Xiranite remains an explicit transfer check
with its 1% empty-XY goal unchanged. This is a shallow screen, not a release gate.
