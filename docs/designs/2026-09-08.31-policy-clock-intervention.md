# Frozen policy clock intervention

Status: declared before diagnostic outcomes. Training-only; no training changes.

The native observation encodes remaining time as `(horizon - steps) / horizon`.
Training uses 16 commands; original-root evaluation uses 128. Increasing the
budget therefore changes policy conditioning after the first command. The prior
prefix-recovery comparison does not isolate this effect.

## Contract

Inputs: the audited final width-one and width-two seed-17 actors, all sixteen
admitted training geometries, unchanged native library and policy source, and
`tools/factory-edit-pilot/clock-intervention.json`. Freeze both actors before
observing any diagnostic outcomes. Use CPU, one thread, batches of sixteen and
32 paired sampling seeds beginning at 1024000 per case and condition.

Three conditions start from the same original root:

- `native16`: 16 commands, native remaining-time feature.
- `native128`: 128 commands, native remaining-time feature.
- `clamped16_in128`: 128 commands, replace only policy tensor `stats[:, 0]`
  with `max(0, (16 - t) / 16)` before inference, where `t` is commands already
  attempted in that episode. Do not alter native state, action candidates, rewards,
  termination, validity or incumbent selection. After command 16 this diagnostic
  holds the feature at zero, a value outside ordinary pre-action training inputs.

Output: schema-one report containing frozen-source provenance, protocol hash,
per-condition episode scores, command counts, translated successes, changed
completions, paired wins/ties/losses and timing. Retain best/median traces and
layouts and their independent replays. All 3072 episode outputs must pass native
and reference acceptance. Charge all 278528 policy commands, with no prefix or
free repair. No held-out cases or outcomes are admitted.

For every paired seed, require the entire native16 trace to equal the first sixteen
clamped16_in128 transitions and require the extended incumbent score to be no
worse. This is an executable control for time-only intervention and identical
sampling, not a performance success gate. Native128 need not share this prefix.
Verify frozen actor hashes remain unchanged at completion.

Failures have stable `clock_intervention.*` diagnostic codes, error severity,
`policy_clock_intervention` stage and the active case reference where available.
Reject incompatible protocols, source changes and existing output directories;
record interrupted status on failed acceptance, accounting or paired controls.

## Interpretation and decision

Compare clamped16_in128 against native128 at the same 128-command allowance.
Report per-case paired score outcomes and aggregate translated successes for each
actor; do not select a new actor or alter the capacity-study gate from this probe.
A consistent gain would support time conditioning as a contributor and motivate
a separately declared matched-clock training/evaluation study. Mixed or absent
gains would argue against treating clock mismatch as the sole explanation.
No result establishes a fundamental learning impossibility. Clamping is a
diagnostic intervention, not a proposed production clock contract.
