# Case-specific curriculum to original roots

Status: experiment complete, stage-one acceptance not met; see the
[results](../reports/2026-09-08.17-case-curriculum-results.md).

## Question and protocol

Complete the curriculum bridge to each case's original root without changing the
policy, action semantics or reward. Use the existing spatial BN policy and eight-edit
training episodes, eight streams, 1,024 samples per PPO update, four epochs and
64-example minibatches. Train fresh seeds 17/29/43 for a predeclared 262,144 sampled
edits each. The protocol is `case-curriculum-study.json`; no interim retuning.
This is a goal-directed capability experiment, not an isolated causal test of rehearsal.

Derive all remaining-witness prefixes from the first positive reward in each external
case witness. A has levels 1 through 6, B 1 through 3. The last level is identified by
an empty actual prefix and is original-root training. Remaining witness length is
not a proved minimum edit distance. Scripted preparation is never a policy label or
rewarded training action and always preserves the original base/reward denominator.

Each case has an independent current level and passing streak. Every 8,192 total
sampled edits, assess each case's current level on 64 eight-edit episodes with separate
CPU generators, seeds 200000–200063. At least 52/64 successes at two consecutive
checks advances that case one level. The last level remains the root and must retain
its passing streak; a failed assessment clears that streak. No shared A/B gate and no
jump over intermediate prefixes. Record before/after controller state and actual root
exposure independently of stage labels.

Use a deterministic 3:1 current/rehearsal episode schedule per case. Every fourth
case episode rehearses a previously passed level, cycling over levels below current;
with no previous level, use current. Rehearsal never includes an unpassed harder level.
Case alternation and total A/B sample budgets stay equal. This mixes easy states with
current learning rather than replaying old PPO samples. All observations are freshly
collected on the current frozen rollout policy.

Original-root outcome evaluation remains 128 edits, 32 seeds 100000–100031 per case,
at 0, 65536, 131072, 196608 and 262144 sampled edits. Outcome seeds never select stages.
Stage-1 success requires at least 26/32 improving root outcomes on both cases in each
of the three trained policies at both final evaluation checkpoints, with valid retained
outputs. This is a milestone for two cases, not unseen-factory generalization or a
proof of optimality. If it fails, record the failing transition and use bounded evidence
to decide the next intervention; do not call budget exhaustion impossibility.

## Interfaces and diagnostics

Extend the start table to all witness levels, with level zero retained only as the
explicit-root identifier used by the existing controlled studies. The collector takes
one declared level per stream; reject missing/out-of-domain levels before any reset.
This replaces its scalar-level internal contract. Existing uniform-level experiments
supply an explicit repeated list. Partial-collection state records this level vector.

Outputs retain normal policy/optimizer/RNG/environment state and add per-case controller,
per-episode current/rehearsal reason, actual level, setup length and root flag. Record
stage/reset/sample/preparation exposure and normalization calibration costs. Save each
assessment checkpoint and the initial checkpoint. Interrupted states retain completed
rounds and the partial round; do not claim automatic resumability.

Stable failures include `case_curriculum.protocol`, `case_curriculum.state`,
`collection.levels`, and `case_curriculum.accounting`, with stage/entity context in the
run error. Independent assessment replay reconstructs controller advancement and the
rehearsal schedule rather than trusting recorded levels. Source/checkpoint and selected
valid-layout checks remain the existing scoped checks; bitwise learning reproducibility
is not a goal.
