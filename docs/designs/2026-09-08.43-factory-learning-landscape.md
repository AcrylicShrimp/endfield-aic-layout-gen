# Broad, shallow factory-learning screen

Explore several hypotheses quickly, as requested by the user. Start all seven
branches from the same existing width-one seed-17 final policy. Measure its frozen
baseline first, then compare short adaptation branches: old sixteen roots/horizon
16; broad twenty-eight roots/horizon 16; broad mixed curriculum starts/horizon 16;
broad roots/horizon 64; broad mixed starts/horizon 64; broad witness imitation;
and broad imitation followed by root PPO/horizon 64. PPO/BN is a prototype choice,
not a required final architecture. This first screen does not exhaust alternatives.

Broad training includes the sixteen previous training geometries and twelve
previous development geometries. The eight three-facility geometries stay outside
training in every branch. All 36 are evaluated with four sampling seeds, using the
existing 4x32 best-valid inference procedure. Opening these outcomes is recorded;
future unseen-geometry claims need a new split. No all-case reliability gate applies.

Each PPO branch has at most 32768 sampled commands, stopping before a full collection
round would exceed it. Record actual counts: different case counts and horizons
produce different update/episode counts, a screening confound rather than an exact
causal comparison. Mixed starts sample root half the time and a uniformly chosen
positive remaining-witness level otherwise, without mastery thresholds. Imitation
uses only broad-training witnesses, forty supervised epochs, with label exposure
reported separately. The combined branch uses both allowances. Save final full
states and optimizer state; do not run a checkpoint-selection search.

Use one adaptation seed and four evaluation seeds for this exploratory screen.
Report every branch/case, success counts, area/tiles/turns, losses, costs and errors.
Keep existing native validity and incumbent preservation and use the tested
evaluator's independent acceptance/representative replay. Do not perform exhaustive
training replay or require exact historical trajectory reproduction. An errored
branch is retained as uncertain evidence and does not cancel other branches.
Keep raw pilot artifacts ignored and source/protocol hashes recorded. Bound the
whole screen at 1800 seconds. This is coarse triage: four trials cannot certify
reliability, a short negative branch cannot disprove eventual learning, and a
positive branch needs replication before a general performance claim.

The next investment follows the strongest architectural/data/credit-assignment
signal, not perfection on these geometries. Action abstraction and other model or
objective changes remain candidates; zero-shot transfer is not a required gate
before training on richer factories. The full factory/semantic/CLI/density goal
remains unchanged.
