# Layout External Connections

## Purpose

The facility-instance wiring graph contains non-facility nodes for continuous external inputs, requested target output, and recipe surplus. The integrated solver must represent these flows without making the hard search-domain perimeter part of the installed blueprint.

## Endpoint Contract

An external-input node is valid only as a route source. A target or surplus node is valid only as a route target. A facility remains valid in either position when it exposes an available port with the required direction, transport kind, and item.

Every external node must carry the same item as its logical edge. A mismatch returns `external-item-mismatch` before solver construction.

The route output uses a discriminated endpoint:

```text
facility { instance, port }
external { node, side }
```

`side` is the selected facility port's outward world direction: north, east, south, or west. It is not a search-canvas perimeter label.

## Geometry Contract

For a facility-to-external or external-to-facility requirement, the external endpoint occupies the selected facility port connection cell. The corresponding facility endpoint occupies the same cell. A one-cell route is therefore the minimal and preferred legal representation.

External-to-external requirements are invalid. External connections do not select a fixed perimeter coordinate and never force routing to the search-domain boundary.

Each facility port is projected independently. A connection outside the hard search domain is unavailable for selection, but it does not invalidate the facility placement when the port is unused. Every selected port connection cell remains part of route geometry.

The accepted witness is translated so the minimum used facility, route, or logistics-component coordinate is `(0, 0)`. Reported bounds are calculated from the translated used geometry, not from the search-domain size or an origin prefix.

## Deferred Work

This contract does not model an outside storage building, depot geometry, startup bootstrap injection schedule, or shared external manifold.
