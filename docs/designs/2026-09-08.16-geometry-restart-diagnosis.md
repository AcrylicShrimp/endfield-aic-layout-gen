# Fixed-budget geometry restart diagnosis

Status: declared before new diagnostic rollouts.

The geometry pilot fails only gap 8/rotation 0, in both held-out banks. Failure
rows show zero completions and predominantly transport erase/extend operations;
median discard count is zero. These observations suggest unrecovered draft states,
but do not establish that model capacity is sufficient or that restarts will help.

Freeze the selected pilot policy and compare one 128-command attempt, four
32-command attempts and eight 16-command attempts. Every episode consumes exactly
128 learned commands. Each attempt starts from the original valid root, without
witness setup. Keep the best independently validated layout across attempts using
area, transport tiles and turns. Report resets separately; no oracle edit or free
repair is allowed. Use one continuous sampling generator per episode, initialized
with the same seed across methods. Model parameters and BN buffers remain frozen.

Use the already opened gap 8/rotation 0 failure, gap 8/rotation 90 control, gap 2/
rotation 0 development and gap 4/rotation 0 training root. Execute 32 episodes in
each of two new diagnostic banks, 700000 and 710000. These are development data,
not restored held-out evidence. Record per-attempt score, first improvement step,
command/outcome counts, and retained episode score. Save all episode best layouts
and best-attempt traces; independently validate each selected layout and replay
best/median representative traces per cell. An interrupted run retains its outputs.

A method qualifies diagnostically only if every cell reaches 26/32 actual translated
valid improvements. Among qualifying methods, prefer the lowest sum of cell median
area, then transport tiles, then turns, then fewer resets. If none qualifies, report
the failure and diagnose capacity/representation or training coverage next. This
selection rule is development-only; it does not pass stage 3. A subsequent method
must use a newly declared untouched geometry split and training-seed replication.

Inputs and exact policy/case hashes are in `geometry-restart-diagnosis.json`.
CLI contract: explicit protocol, native library and fresh output directory. Report
schema includes protocol hash, source/native provenance, frozen policy hash,
per-method/case/bank cells, charged command/reset counts, validation and diagnostics
with stable code, severity and stage. Reject hash drift, unequal budgets, invalid
seeds and dirty source before rollouts. No production integration in this slice.
