# Facility Catalog V2 Rotations

## Design Goal

Extend facility catalog data with the orientations that each facility instance may use during placement, without introducing ports, channels, or placement policy.

This is a hard cutover from schema version 1 to schema version 2. V1 files must add `allowed_rotations` to every facility and change `schema_version` to `2`.

## JSON Schema

```json
{
  "schema_version": 2,
  "facilities": [
    {
      "id": "grinding-unit",
      "footprint": {
        "width": 3,
        "height": 2
      },
      "allowed_rotations": [0, 90, 180, 270]
    }
  ]
}
```

`footprint` remains the canonical zero-degree grid-cell rectangle. `allowed_rotations` is a non-empty list containing unique clockwise quarter-turn degrees selected from `0`, `90`, `180`, and `270`.

For rectangle placement, rotations `0` and `180` use the canonical width and height. Rotations `90` and `270` exchange width and height. Keeping all four values distinct allows a later port-aware stage to rotate directional ports without changing this contract.

Rotation capability is external game data. Application code must not assume that every facility supports every rotation.

## Validation Diagnostics

V2 adds these semantic validation failures:

- `empty-allowed-facility-rotations`: path `/facilities/{index}/allowed_rotations`
- `unsupported-facility-rotation`: path `/facilities/{index}/allowed_rotations/{rotation_index}`
- `duplicate-facility-rotation`: path `/facilities/{index}/allowed_rotations/{rotation_index}`

Diagnostics follow the existing facility catalog report schema and catalog order.

## Non-Goals

- No ports or port direction transforms.
- No rotation cost or preferred orientation.
- No placement coordinates.
- No layout objective or solver policy.

## Migration

V1:

```json
{ "schema_version": 1, "facilities": [{ "id": "assembler", "footprint": { "width": 5, "height": 4 } }] }
```

V2:

```json
{ "schema_version": 2, "facilities": [{ "id": "assembler", "footprint": { "width": 5, "height": 4 }, "allowed_rotations": [0, 90, 180, 270] }] }
```
