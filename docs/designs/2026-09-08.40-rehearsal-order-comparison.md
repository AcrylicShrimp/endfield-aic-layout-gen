# Matched rehearsal-order continuation comparison

Status: declared before outcomes. This is a bounded scheduling experiment following
reports 51/52, not a new full capacity matrix or a permanent scheduler change.

Use the same audited width-one seed-43 anchor at 1179648 commands and its saved Adam
state. Both arms use learning rate 0.00003, chosen because the lower-rate interval
showed disproportionate rehearsal contribution despite short-task stability. The
ordinary production/pilot setting is not changed. Compare synchronized rehearsal
against staggered rehearsal on all sixteen training cases. Freeze the original
case controller through all 32 updates; do not advance or remove cases.

Construct each case's original 32 rehearsal levels by executing the saved scheduler
over its restored episode ordinal. The synchronized arm uses the original scheduler
unchanged. For the staggered arm, rotate that case's 32-entry rehearsal list left
by its zero-based position in the frozen case order. Only rehearsal starts change;
all current starts remain identical. This preserves the exact per-case level
multiset, 96 current starts, 32 rehearsal starts and setup-command totals. Record
the full precomputed orders and per-update level histograms before training.

Run three paired fresh continuation seeds 1100000, 1110000, 1120000; these are not
independent original training seeds. Alternate arm order: synchronized/staggered,
staggered/synchronized, synchronized/staggered. Retain the established independent
per-stream sampler and seed+100000 minibatch shuffle. Every arm gets 32768 policy
commands in 32 updates, four collection rounds of sixteen streams, horizon sixteen,
four PPO epochs, minibatch 64 and 64 Adam steps per update. Save all checkpoints,
collection commands/samples/incumbents and source identities. Each arm collects its
own on-policy data; order changes can affect later observations and calibration.

Assess the frozen anchor once and every arm at updates 8/16/24/32 using 64 paired
seeds per current case, starting at 1130000. Evaluate the anchor and six endpoints
on every original root with 64 new paired seeds starting at 1140000, horizon 128,
batch sixteen, no prefix, restart or repair. All incumbents must pass native and
reference acceptance; independently replay all training and short-assessment
episodes and the 224 selected best/median root traces. Root episode/command totals
must be derived from retained rows rather than inherited from a sixteen-seed probe.

## Predeclared decision

Mark `candidate_for_replication` true only when all conditions hold:

1. Worst aggregate short-assessment success is nonworse in every staggered pair.
2. It is strictly better in at least two of three pairs.
3. Endpoint root success is nonworse in every pair.
4. Pooled endpoint quality is nonworse, using mean case medians and lexicographic
   normalized area, physical tiles, then turns.
5. Every staggered endpoint case has at least 52/64 translated improvements.
6. Pooled staggered endpoint quality is nonworse than the common anchor.

Report every criterion and every case, including failed criteria and anchor-relative
degradation. A passed diagnostic only warrants separately declared replication;
it does not override the old failed capacity or learning-rate gates, open development
or held-out banks, establish a universal scheduling effect, or finish stages 4/5.

The full declared work is 196608 training, 409600 short-assessment and 917504 root
policy commands (1523712 total), plus unchanged separately charged setup work and
12288 Adam steps. Sixteen-case counts are diagnostic scope, not game limits.
Keep a 1200-second elapsed guard between branches, structured interruption evidence,
and full checkpoint preservation. Source/protocol/order/input hashes must stay fixed.

Test exact visit-multiset preservation and reduced stage synchronization, rejection
of invalid schedule tables, every decision condition including area/tiles/turn
priority, and unchanged normal current starts. Run full Python/workspace verification,
the actual CLI, independent recorded-evidence audits and artifact checks before
committing conclusions. No additional case selection or rerun-until-pass is allowed.
