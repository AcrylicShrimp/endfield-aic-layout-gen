## Question and distinction from historical experiments

Can the ordinary complete-factory edit vocabulary compose a sequence that releases
an occupied boundary band of the current 379-transport-tile incumbent? Historical
lower-boundary and deflection reports tried simultaneous rigid/support movements and
two-part relative poses on older 41x53 witnesses. They found specific routing failures,
not impossibility. This screen explores successive independently validated complete
factories, admitting temporary secondary-score worsening. It does not repeat their
fixed simultaneous movement/port product or claim a new physical operator.

## Stage contract

Inputs: original full-factory case and catalogs, a separately retained valid initial
witness, explicit side (`south` or `west`), beam width, depth, per-parent candidate
allocation, selected-action, route-expansion and wall budgets. Geometry and game data
come from the input files. No recipe/facility ID or test width/height is a premise.

Output: structured protocol, trace and status; best complete witness and, when found,
an ordered area-improving trajectory containing native-validated predecessor/successor
states and ordinary descriptor actions. Keep a recoverable frontier on interruption.
Record hashes, parent IDs, selection costs, failure diagnostics, original/current/best
scores and search-only boundary potential. A beam failure is a finite search result,
never global infeasibility. A port-only gain is retained but is not an area lesson.

Use the current schema-two default groups descriptor. No teacher-only commands or
unreported speculative route checks. The teacher may rank offered actions by a
geometric boundary potential; every executed action is charged and native checked.
At each depth, interleave candidates from all live parents before retaining up to
eight distinct child geometries. Track physical duplicates across depths. Select
children by current area, weighted facility-body occupancy in the initial two-cell
boundary band, terminal/component occupancy there, all physical XY occupancy there,
then current secondary score. The search potential is neither a game rule nor the
exported score, and will not silently replace the learner's objective.

Candidate allocation per parent: up to 24 inward/body-band-reducing relocations,
eight rotations of facilities near the band, eight nearby port changes, and eight
nearby component/bridge/route/strip edits. Sort each pool by geometric band reduction
where applicable, then stable descriptor order. Include only actions that can affect
the boundary region; this is a declared teacher shortlist, not an exhaustive domain.
If a pool is smaller, do not spend its unused allocation on another class. A missing
useful command is a search/domain limitation to measure, not proof of inability.

Bounds before opening outcomes: south and west independently start at the same
379-tile witness; beam eight, depth twelve, up to 48 selected edits per parent,
4608 selections and 180 seconds per side, 5000 shared route expansions per selected
edit. Stop a side at the first validated area reduction, retaining best lexicographic
score across all examined results. Each child is checked against the unchanged full
original request. Resets, descriptor generation and recording count toward wall time.
The retained current extent is an explicit edit neighborhood, not a game W/H limit.
