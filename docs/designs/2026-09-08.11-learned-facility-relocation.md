# Learn a complete facility relocation transaction

Status: protocol declared before training. Stage 1 retained-policy evaluation passed.

## Input and scope

Use the external `tools/factory-edit-pilot/case-relocation.json` fixture: the same
four-facility battery production obligations as A/B, with external tails already
trimmed. This small deliberately selected runtime fixture is tracked because it
isolates actual placement/rerouting learning from boundary-tail deletion. It is an
independent input, not a retained generated report. No game data is added to code.

Its score is (133 area, 14 transport tiles, 1 turn). With original positions and
orientations, facility bodies occupy at least seven columns, with y extrema 0 and 16.
Every allowed F input port requires a neighboring transport cell at y=17; every T
output port requires one at y=-1. The covered positive-rate obligations require both.
Thus fixed poses require at least 7*19=133 area regardless of route/port choices.
The fixture test recomputes this argument from external catalog geometry. Rotation
alone is not counted as translation in the learned acceptance criterion below.

The nine-command witness disconnects quartz/glass, removes three old belt cells,
translates F from (0,14) to (0,12), and reconnects both inputs/outputs. Final score is
(119,12,1), with a 10.526% area gain. All intermediate actions must be legal draft
edits; the retained factory stays valid until the final complete improving commit.
The witness establishes expressibility, not learned competence.
