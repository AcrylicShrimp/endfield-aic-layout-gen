# Circulation-Permitted Routing Cutover

## Status

Accepted for the current exact joint-solver experiment.

## Decision

Commodity-network flow may contain net-zero circulation. The solver does not need to prove that
every selected route is cycle-free.

The following remain hard constraints:

- every selected directed channel has positive integer flow;
- every unselected channel has zero flow;
- selected terminals inject or consume their exact required flow;
- every ordinary transport cell conserves flow;
- every channel and logistics component respects capacity;
- facility, transport-layer, component, crossing, and collision rules remain valid;
- caller-supplied width and height remain hard ceilings.

A circulation cannot create material or increase delivered terminal flow. It consumes modeled
capacity and is therefore operationally harmless unless an observed blueprint demonstrates a
different practical problem.

## Removed Model Structure

The formulation no longer creates one wide-domain topological-order variable per network cell or
one big-M order constraint per selected directed arc. The `route-order` variable family,
`acyclicity` constraint family, and their public model counters are removed rather than retained as
zero-valued compatibility fields.

This changes the integrated-layout report schema from 16 to 17, the static search-space report
schema from 2 to 3, and the formulation identity from `joint-lexicographic-layout-v4` to
`joint-lexicographic-layout-v5`.

## Observation Policy

No route-arc objective, cycle cleanup, or cycle-specific rejection is added in this cutover. If a
solver-produced layout contains undesirable circulation, preserve that result as benchmark
evidence and decide the next formulation or objective experiment from the observed case.

Witness validation therefore checks positive flow, terminal balance, ordinary-cell conservation,
capacity, topology, and collision rules, but does not require every occupied transport cell to lie
on a directed terminal-to-terminal path. Such a reachability check would reject the circulation
that this contract explicitly permits.
