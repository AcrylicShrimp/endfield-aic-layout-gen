# Profile-Guided Factory Edit Data Preparation

Status: measured implementation, 2026-09-07.

After sparse category templates, the user requested further elapsed-time reductions. The
latest CUDA run still spent 28.467 s constructing observations and 29.176 s in CPU inference.
Measure representation reuse before changing model execution or learning exposure.

## Contract

Candidate encodings are pure functions of catalog-derived categories, two absolute points,
segment length, placement count, and the fixed initial-area scale. Memoize this pure function
in a per-environment LRU bounded to 4,096 entries. Include every changing encoding input in
its immutable key. Terminal positions must be resolved from the current state before lookup.
The bound limits implementation memory; it does not limit candidates, coordinates, geometry,
or legal actions. Eviction recomputes an identical encoding without pruning anything.

Cached arrays are read-only and returned observations own their copies. Raster-relative point
indices are computed from the current raster origin after lookup. Root resets do not change
the catalog or encoding scale, so reuse across episodes is allowed. No mutable geometry index,
acceptance outcome, network state, or action selection is cached.

Also memoize canonical JSON sort strings for generated typed commands in a separate 4,096-entry
LRU. Its key includes every field of each generated command variant, including placement order
canonicalization and erase-cell order. This helper accepts the generator's closed command schema;
it is not a generic cache for arbitrary external command dictionaries. Compare its strings
against the unchanged standard JSON encoder. Neither cache skips command generation/checking.

For CPU inference of one observation, measure a direct unsqueezed tensor view instead of
padding/copying a one-element batch. These views are read-only during forward execution.
General minibatch padding and all PPO update mathematics remain unchanged.

## Verification and decision

Compare every ordered candidate, observation byte, and transition on the same three retained
256-command sequences against `5562ae4`, using the existing environment diagnostic. Exercise
encoding eviction and observation ownership. Compare single-observation input tensors and
policy results against the normal padded batch. Benchmark CPU inference and environment work
on identical inputs before selecting either change.

Retain only changes with measured benefit. Run behavior checks, independent acceptance, and
a full same-allowance GPU experiment. Keep numerical variation allowed, as requested by the
user; interpret full-run time separately from exact-input throughput and learned outcomes.
Record cache size/hits/misses as implementation diagnostics, never as learning features.

## Higher-impact PPO preparation target

The 118.670 s CUDA run's synchronized update stages total 11.236 s in batch construction and
transfer, 3.769 s in forward/loss, 5.681 s in backward, and 2.033 s in optimizer work. Repeated
preparation is therefore the first update target; optimizer or custom neural kernels are not.

For CUDA, prepare the collected rollout tensors once and reuse them across the unchanged four
epochs. For each unchanged sampled minibatch, crop to exactly its former maximum height, width,
and candidate count before selecting the same samples in the same order. Values, dtypes,
shapes, advantages, RNG consumption, and optimizer-step count remain fixed. Do not increase
convolution work through a globally padded minibatch.

Bound the prepared tensor payload to 1 GiB. If its estimated size exceeds the bound, construct
ordinary minibatches as before and record the selected preparation mode. This is a memory
optimization bound, not a training-data or geometry bound. CPU updates retain ordinary batching.
Count all preparation and selection work in the existing batch clock. Record cached bytes/mode.
Verify exact cached-versus-original minibatch tensors and fixed-input update timing before
selecting this implementation; leave stochastic numerical variation permitted.
