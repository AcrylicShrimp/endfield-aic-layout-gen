# Official Blueprint Limits

## Source

The pinned official-data extraction contains `FacBlueprintConst.json` with:

- `BluePrintXLenMax`: 50
- `BluePrintZLenMax`: 50
- `BlueprintNodeCountLimit`: 160

The table is vendored with the existing game-data snapshot and normalized without network access.

## Runtime Data Contract

`blueprint-limits.json` has schema version 1 and contains `max_width`, `max_height`, and `max_nodes`. The normalized values are exact positive integers copied from the source constants.

The 50 by 50 dimensions are the hard maximum for one exported blueprint. They do not limit the whole factory layout. Whole-factory placement requests use explicit caller-supplied bounds; a future blueprint partition/export stage must enforce these values.

`max_width`, `max_height`, and `max_nodes` are retained as authoritative export data but are not enforced by the whole-factory spatial solver. Enforcement requires a blueprint partition/export projection that defines how routed grid cells become game blueprint nodes; the current solver route representation is not that export contract.
