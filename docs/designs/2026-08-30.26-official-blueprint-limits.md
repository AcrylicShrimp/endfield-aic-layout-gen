# Official Blueprint Limits

## Source

The pinned official-data extraction contains `FacBlueprintConst.json` with:

- `BluePrintXLenMax`: 50
- `BluePrintZLenMax`: 50
- `BlueprintNodeCountLimit`: 160

The table is vendored with the existing game-data snapshot and normalized without network access.

## Runtime Data Contract

`blueprint-limits.json` has schema version 1 and contains `max_width`, `max_height`, and `max_nodes`. The normalized values are exact positive integers copied from the source constants.

The 50 by 50 dimensions are the system hard maximum for blueprint layout requests. A smaller requested rectangle remains valid, but a caller must not enlarge it beyond these limits.

`max_nodes` is retained as authoritative data but is not yet enforced by the spatial solver. Enforcement requires a blueprint-export projection that defines how routed grid cells become game blueprint nodes; the current solver route representation is not that export contract.

## Current Heavy Xiranite Run

The selected production graph requires 1,133 facility cells and therefore fails the old 12 by 8 example bound. It passes the facility-area lower bound for the official 50 by 50 maximum. A solver timeout at 50 by 50 is an unknown search result, not evidence of infeasibility.
