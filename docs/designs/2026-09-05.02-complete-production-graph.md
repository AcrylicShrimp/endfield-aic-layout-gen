# Complete Production Graph Construction

Status: Implemented; full graph and physical external I/O validated in release experiments.

## Contract and sequence

Keep `construct-production` and its explicit operation budgets, runtime data and first-feasible
facility/SCC transactions. Continue until the full Heavy Xiranite graph is covered, not merely until
another obstruction is measured. Implement and verify bounded slices in this order:

1. Remove the artificial bridge-free restriction from the dedicated router. A crossing may use only
   a runtime-catalog bridge over an existing straight, non-terminal, non-component cell. Both axes
   remain straight, independent and capacity-valid. Initially cross distinct commodity networks
   only, avoiding ambiguity in same-commodity shared-path attachment traversal. The independent
   validator must reject missing, turning, overloaded and single-axis bridges.
2. Recheck future access with the same legal crossing capabilities. This remains a constructive
   screen, not a global extendability proof. Retry local SCC choices transactionally as required;
   do not bypass unresolved logical requirements or relocate unrelated validated regions.
3. Complete every required facility and internal edge, then realize true external inputs, target and
   surplus outputs as capacity-bounded physical boundary connections. External terminals must match
   the original wiring identity/item/rate and lie on the actual used bounding box, with legal
   direction. No implicit import may replace a required production facility.
4. Independently audit exact logical coverage and physical witness validity before full success.

## Diagnostics and migration

Report schema 2 separates internal completion from external connection completion. Each step records
its stage, routing counters and physical components, including crossings. Request schema 1 remains
unchanged. Constructive nodes add `external_requirements`; their `internal_requirements` retain the
facility-to-facility meaning. Preserve the last independently valid state
on a budget stop; failed local candidates are never successful factory witnesses. The meaning of
`success` and `complete` remains complete validated factory only. Counters and termination stage
must identify exhausted bounds. No exact-solver fallback or compactness optimization is introduced.

## Verification

Add controlled crossing and invalid-crossing tests before accepting bridge output. Preserve all

regressions. Run the full real graph in release mode after each material routing change. Final gate:
all required facilities, every internal and external requirement, zero unresolved requirements,

## Implemented outcome and limits

The unchanged real graph completes with 59 facilities, 89 internal requirements and seven external
requirements. Bridge-aware routing and boundary screening suffice; the run requires no accepted-state
rollback, global exact fallback or new SCC route-order search. It accepts first-feasible local
placements at a natural footprint. The original seed/moss obstruction is crossed legally instead of
being misclassified as a bridge-free dead end.

Crossings currently join different commodity networks only. Same-commodity crossings, general
rip-up-and-reroute, accepted-history rollback and post-completion improvement remain unimplemented.
The external stage uses a padded envelope derived from completed geometry, chooses endpoints on
that envelope, and independently verifies they lie on the actual used bounds. That envelope is a
constructive choice, not a caller W/H limit or an infeasibility premise.

Large native histories remain available, but report-file serialization is buffered and stored
benchmark histories are losslessly compressed. No geometry or diagnostics are removed from the
compressed evidence. The capture tool additionally audits original wiring coverage and exact
terminal-rate sums using a separate rational arithmetic implementation.
