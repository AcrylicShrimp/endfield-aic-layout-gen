# Validated original-root action contrasts

Status: collection, independent replay and shallow ranking comparison complete.
See [results](../reports/2026-09-09.12-full-factory-action-contrasts.md).

## Collection contract

Use the corrected trajectory experiment's twelve complete originals and their
preassigned family splits. Every trial starts from the same original native session
for that case. Collect at most four ordinarily offered contraction/insertion pairs
at the same axis/position, 32 poses, eight reroutes and four port changes per root.
Choose half the poses by the existing center-distance geometry proxy and half by
fixed-seed sampling without replacement from the rest. Prefer pipe reroutes before
belt reroutes and longer eligible chains within each kind. This is a bounded teacher
collection heuristic, not a new runtime feasibility rule or a global search.

Every proposal consumes one selection and up to 5000 route expansions. A root gets
60 seconds of collection and the study 900 seconds. Keep rejected, unchanged,
exploratory, late and improving outcomes in the denominator. Persist accepted
improving witnesses; do not train failures as successful edits. A timeout is missing
evidence for ranking, not proof of a bad action or of factory infeasibility.

An improvement is strict lexicographic area/physical-transport/terminal-aware-turn
gain under native original-request acceptance. Preserve all original facilities,
required cycles, pipes, capacity and external identities. Only ordinarily offered
actions may become labels. Independently execute/validate the improving outcomes
against their original graph before treating them as curriculum evidence.

## Ranking comparison contract

Train only on the original food/medical family. Pair observed improving choices
with observed completed non-improving choices on the same root; untried and late
actions are not negative labels. Start from the preceding trajectory checkpoint and
run 256 predeclared pairwise logistic-ranking updates, with Adam 0.0003 and gradient
clip 0.5, using fixed seed 17. Report positive-action kinds, family coverage and
loss/gradient/update membership. If no improving pose/reroute is collected, report
that shortfall rather than calling the dataset a relocation curriculum.

Before training, freeze a schedule that cycles through seeded-shuffled positive
action kinds and samples a root, positive and completed negative uniformly within
that kind using seed 17. With the four observed positive kinds, each gets 64 of 256
updates. This deliberately oversamples the single training reroute positive; report
that dependence. Retain the explicit pair schedule with the protocol. Cache original
observations within 128 MiB and bound training/evaluation to 900 seconds. Reset Adam
when starting this new pairwise objective; retain its final state and Torch RNG.

Evaluate the frozen resulting weights at T=1 and T=0.05 with the same parent
twelve originals, two banks, eight actions, 30-second episodes, 5000 route expansions
per action and history mask. Compare to the already measured parent policies and
geometry baseline, preserving all ordinary actions and native incumbent protection.
These are opened development comparisons, not sealed evaluation or release approval.
Check all retained bests independently; preserve optimizer/RNG and concise provenance.
