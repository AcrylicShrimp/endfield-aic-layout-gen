# Full-factory family admission

Status: implemented; development admission and capability screen complete.

## Contract

Before more learned-policy comparisons, measure admission of explicit new source
plans through the current production constructor. The schema-1 study contains
catalog and executable paths, bounded construction settings, and named families
with source plans and requested rates. Resolve paths relative to the study file.
Family splits are assigned before construction; related recipes must share one
family and split. This screen permits train/development only. Every inspected
family is opened; it cannot later be called a sealed test family.

Generate wiring through `recipes contextual-instance-wiring`, then invoke
`layouts construct-production` once for every eligible request. Use downstream
closed growth, with no global placement, exact fallback, or automatic external
substitution. A rate variant changes the requested throughput, never an already
generated graph. Record actual facility count, internal pipe requirements, cyclic
SCCs, branching and merging. Facility and elapsed guards are operational limits.

Publish a root only when the constructor reports complete success and an independent
Rust witness probe plus original graph coverage accept every margin and external
identity. Derive the original request from wiring before reading geometry. Roots
use the existing closure-factory DTO and can enter `full_factory_inputs.mjs`.
Keep split/family provenance in the admission report and roots. Admission alone
does not demonstrate policy support, learned transfer, or successful compression.

## Diagnostics and evidence

Write an attempt record after every completed attempt, including rejected source
plans, instance guards, constructor deadlines/stops, independent validation
failures, timings and structured diagnostic codes/severity/stage/entity. A timeout
cannot be called infeasibility or a complete factory. Execute serially with bounded
child processes; no retry based on admission outcomes. Preserve failed denominators.
Unexpected harness errors stop the study and leave completed attempt records.

Freeze hashes of study, source plans, runtime catalogs, binaries and JS dependencies
before execution and verify them before publishing the aggregate. Retain source
plans, wiring, constructor reports, admitted roots and validation evidence under
ignored artifacts. Generated HTML is disposable; selected views may be inspected
locally. Commit only source configuration, scripts, concise findings and provenance.

## Initial screen

Use the existing complete enriched medical/food source definitions at three rates,
grouped as one family. Add an explicit copper liquid chain with required internal
pipe transport and original water import, and a grass production cycle requiring
water. These explicit imports define new requests; they do not modify the original
59-facility Heavy Xiranite request. Run with 128 facility and 60 second per-request
construction guards. Inspect all attrition before choosing the next capability slice.

This follows the accepted constructive planner lifecycle: wiring contains no spatial
placement, construction routes incremental growth, and improvement starts only from
a completely validated factory. No production architecture cutover occurs here.

## Admitted-root capability probe

For every accepted root, verify native session admission and a finite CPU forward
pass of the existing schema-three policy. Report raster/node/action sizes and timing;
random untrained weights are only an interface check. Run at most eight ordinary
geometry-selected edits with history masking and the existing 30-second/5,000-route
expansion episode guards. Additionally try one offered reroute per required internal
pipe chain from a fresh root (at most eight). Record selected actions, native results,
best witnesses and original-request hashes. Revalidate all retained bests with the
independent original-graph coverage and metric audit. No weights are trained, no
learned-gain claim is made, and pipe probes are not pooled into geometry results.
