# Reduce full-factory description cost without shrinking the action domain

## Stage contract

Input is a complete validated physical witness, external catalogs and the existing
explicit vocabulary options. Output remains description schema 3: ordered ports,
chains and actions, plus diagnostic counts and timings. Every non-timing field must
match the current bridge-channel-correct implementation. Preserve action limits,
scan order, routing/acceptance and checkpoint bytes. Do not omit candidate types,
silently shortlist poses or reclassify rejected preflights to improve throughput.

Profile the accepted medical 116 original first. Hoist repeated immutable geometry
and connectivity derivations only where the profile and source justify it. Any
reusable state belongs to one immutable witness/chain extraction and one description
or local edit search; never reuse it across mutated geometry. Independent candidates
must receive fresh mutable movement state, including after a failed candidate.

## Evidence and bounds

Before edits, freeze full descriptions for twelve existing original/incumbent roots,
the admitted medical 26/116 originals and the retained large cold-control best.
Run all fifteen cases under the ordinary default vocabulary once. Preserve generated
descriptions and CPU profiles under ignored artifacts, with source/input hashes.
After edits, require exact ordered equality of all non-timing description fields
on every case. Check isolation across multiple proposals and exceptions, existing
movement semantics, full workspace tests and the native-backed Python policy tests.

Measure three serial fresh-process large-root descriptions before and after with
no concurrent owned verification jobs. A profile run is separate from these timing
samples. Record total and pose time, not just a favorable hot function.

If this materially reduces cost, run frozen parent/learned/geometry controls on the
same original, bank 1310000, T=0.05, eight selections, 30 seconds and 5000 route
expansions per selection, using fresh runtimes and explicit source delta provenance.
Validate every retained best against the original graph and replay selected actions.
Use any recovered runtime for subsequent broad, shallow large-factory relocation
teacher experiments; performance alone is not learned relocation or final success.

Do not change native acceptance or production construction in this slice. The
research episode deadline remains soft between operations. Failures retain their
existing structured diagnostics and validated incumbents. Keep new reports concise,
record cleanup and commit only source, findings and compact provenance.
