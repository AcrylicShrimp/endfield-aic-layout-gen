# Two-Case Factory Edit Learning Experiment

Status: protocol fixed before training, 2026-09-08.

## Question and scope

The user authorized a second inefficient input and an A-only/B-only/A+B comparison to test
whether varied placement experience helps escape the single-input learning plateau. This is
a bounded learning experiment using the completed Rust environment, not a performance project.
It does not claim generalization to unseen factories or convergence to an optimum.

Case A is the existing four-facility battery input, unchanged. Case B has identical production
obligations, identities, catalog data and feature categories but larger facility gaps, a bent
internal powder path and longer external tails. Its tracked `case-spread.json` is a deliberately
selected runtime input, not a generated solver output. A scripted witness must establish several
successive complete area improvements before training. The witness is never a demonstration,
policy input, reward term or action-ordering hint. Known witness quality is not an optimum.

## Inputs and matrix

`two-case-study.json` names the two external case paths, the existing CUDA learning configuration,
three independent training seeds (17, 29, 43), and three conditions per seed:

| Condition | Episode schedule | Training commands | Commands per trained case |
| --- | --- | ---: | ---: |
| A-only | A | 65,536 | A: 65,536 |
| B-only | B | 65,536 | B: 65,536 |
| A+B | A, B, A, B, ... | 131,072 | A: 65,536; B: 65,536 |

All conditions use the same driver and unchanged policy/PPO/environment configuration except
the declared seed, allowance and final checkpoint. Use the A observation to instantiate every
model so each seed has exactly identical initial parameters across conditions. Do not add a
case-ID feature. Require equal categorical feature meaning and model dimensions, not merely
matching tensor widths. Existing variable-size raster/candidate batching supports both cases.

Every episode restarts its selected case's original valid root and lasts 128 edits. Retain
episode-best layouts independently per case; never compare their absolute areas as a shared
champion. A 256-command mixed rollout contains one complete episode from each case. The existing
terminal `done` boundaries prevent GAE from crossing between episodes/cases. Reward remains the
episode-best area decrease divided by that case's initial area. Changing geometry also changes
reward magnitudes and exploration difficulty; this experiment does not isolate diversity alone.

## Outputs, diagnostics and comparisons

The diagnostic CLI accepts an explicit protocol, condition, seed, native library and fresh
output directory. Stable input diagnostics reject incompatible categories/production semantics,
invalid schedules or allowances, unsupported learner settings and existing output directories.
Normal Rust admission/observation errors retain their existing stage/entity diagnostics.

Each run records the protocol/base-config/case/catalog/source/native-build hashes, effective
configuration, initial parameter hash, condition, per-case commands/episodes/counters/champions,
global Adam/command counts and timings. Completed-rollout checkpoints contain model/Adam/RNG,
both native snapshots, scheduler position and per-case accounting. On interruption preserve the
partial rollout, active case/episode return, both native states, actor/learner/Adam/RNG and phase.
Automatic resume of this new study format is outside this experiment; interrupted streams are
not replaced by a seed or silently treated as complete runs.

At 0, 8,192, 16,384, 32,768 and 65,536 total commands, evaluate both A and B with the frozen
policy, 32 fixed sampling seeds and 128 edits, even if a case was not used for training. Mixed
training also evaluates at 131,072. Evaluation uses separate engines and local sampling RNG;
it never updates the model, training state, minibatch RNG or training champion.

Report each case separately: initial/final area, mean/median/best area reduction, improvement
frequency, multiple-positive-improvement frequency, and retained geometry/trace evidence of
facility movement versus boundary trimming. Keep training discoveries distinct from frozen
policy quality. The three independent learners are the replication unit; 32 evaluation rollouts
are within-model sampling, not 32 independent training trials.

Primary comparisons are A-only/B-only at 65,536 versus mixed at 65,536 (same total learning
allowance), and versus mixed at 131,072 (same exposure to each case, twice the total allowance).
Untrained-case evaluations show transfer within these two specified cases. Report all seeds,
including flat or negative results; do not tune architecture, reward or input after inspecting
learning outcomes. No extra optimization, curriculum, best-layout carryover or demonstrations.
