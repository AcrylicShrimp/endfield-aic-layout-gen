# Retain useful small-factory continuations alongside large compression

## Evidence and source selection

Report 24 learns the complete large compression trajectory but loses some smaller
factories' follow-up contractions. Its smaller-root rehearsal covers only initial
states. Extend rehearsal with complete, independently audited improvement paths on
the six existing training roots. Development-family data remains excluded.

Use the preceding two audited evaluation screens, reports 23 and 24. For each smaller
training root, choose the minimum lexicographic final score among budget-complete
episodes across their methods and banks. Break score ties by declared source-screen
order and then report-row order. Stop the teacher prefix when that best score is
first reached. The six selected prefixes each contain eight improving actions.
Require this property in admission rather than silently stripping unsuccessful
actions or altering their episode context. These are best measured demonstration
paths, not global optima or best actions over every possible continuation.

Replay every chosen prefix under the current runtime, preserving original metrics,
current/best metrics, remaining eight-action context, ordinary action membership,
native status/work and exact retained best geometry. Keep the existing first-state
target sets, including ties, and require each selected first action to belong to
its retained set. Retain all five large lesson states unchanged. Add the seven later
states from each smaller path: 42 new states, 53 total lessons and 56 targets.

## Learning and evaluation

Start from the same report 13 pretrained checkpoint with the same model, objective,
optimizer, learning rate, clipping and two adaptation seeds. Each 32-update block
contains eight initiating-large-pose lessons, four large continuations, two original-
large contractions, six smaller initial states and twelve smaller follow-up states.
Shuffle each block with the declared seed. Cycle smaller roots and cycle each root's
seven follow-up states without weighting a root by the number of retained records.

Use 1024 updates per model. The large quotas remain 256 initiating poses, 128
continuations and 64 original contractions. Smaller initial states receive 192
updates; smaller follow-ups receive 384. Increase the training observation-array cap
to 512 MiB for the additional states. This changes data, update count and training
cache capacity together; it is not an equal-training-compute comparison. All
inference limits and the per-episode fresh runtime remain unchanged.

Run parent, both learned policies and geometry on the same fourteen starts and two
sampling banks, temperature 0.05, eight actions, 30 seconds and 5000 route expansions
per selection. Preserve every validated incumbent and retain all budget outcomes.
Compare against the pretrained parent and report 24's matching adapted seeds. Check
that repeated controls have identical non-timing action/score results.

## Verification and decision

Before optimization, independently replay all 48 selected teacher actions against
their original requests, physical rules and complete metrics. Verify selected-path
minima, inherited lesson identity, intermediate contexts and exact schedule quotas.
Freeze source, case, teacher and schedule provenance.

After evaluation, independently replay every selected action and retained best.
Report initial-state versus follow-up target ranks separately, actual scores and
relative pose movement, retention, large-trajectory reproduction, timings and all
remaining regressions. Inspect full native-validated views for recovered smaller
compression or newly improved layouts. Teacher accuracy alone does not satisfy the
retention criterion.

If this restores useful continuations while retaining large behavior, use the result
to choose broader fresh-geometry curricula and unopened evaluation. Otherwise inspect
the first divergent state and measured ranks before another bounded intervention.
Do not train on previously opened development-family labels to hide their regressions.
