# Integrated Layout Area Lower Bound

## Contract

Before constructing placement candidates or route variables, the integrated layout stage sums every facility instance's unrotated footprint area. Quarter-turn rotation preserves area. The hard layout capacity is `max_width * max_height`.

If required facility area exceeds hard layout capacity, the request is proven infeasible independent of placement, ports, or routing. The solver must not be invoked.

## Diagnostic

The report status is `infeasible` with diagnostic code `facility-area-exceeds-layout-bounds`. The message reports required facility area and available layout area. This is a necessary lower bound only: passing it does not prove that facilities or routes can be packed.

All arithmetic is checked before conversion into the solver's integer domain. Overflow remains an invalid-input diagnostic.

## Heavy Xiranite Evidence

The selected Heavy Xiranite hierarchy requires 1,133 facility cells before logistics. The current 12 by 8 example permits 96 cells, so it is infeasible without a solver search.
