## Sampled return and policy gradient

Each update samples four independent 32-action episodes from one current reset
case using the same unchanged policy. Use temperature 1, existing ordinary-history
masking and the existing action-kind balance adjustment. Both are part of the
sampling distribution and must also enter recomputed log probabilities.

The score `S_i` is episode i's best complete validated terminal incumbent. Its
relative return is `A_i = sum(j != i, sign_lex(S_j - S_i)) / (G - 1)`, so lower
area wins before any transport/turn difference. Ties contribute zero. No weighted
scalar substitutes a different score priority, and no action is assigned a correct
label. Every sampled action receives its episode return, including an initially
worse action followed by a better final result.

For one update, this estimates the policy gradient of expected pairwise score
preference against an independently sampled, frozen pre-update policy. Other group
episodes serve as that reference sample. The reference distribution is refreshed
after each update; this is relative-return REINFORCE, not PPO, a critic, or a proof
of optimal factory construction. Equal terminal scores provide zero return gradient.

Minimize `-mean_i(A_i * sum_t(log pi(a_it | observation_it, mask_it)) / H)` plus
`-0.001 * mean_it(entropy(pi_it))`. The fixed horizon scaling changes gradient scale,
not score ordering. Report return and entropy gradient norms separately, including
flat-return groups, then clip their combined gradient to 0.5 and apply Adam at
0.0003. Report that entropy is an explicit exploration regularizer; it is not a
measured factory improvement and cannot establish reward-driven learning by itself.

## Bounded recomputation and verification

Sample without retaining autograd graphs. Save each episode's pre-action physical
states and context temporarily under ignored artifacts. Before one optimizer step,
recompute every sampled log probability from the unchanged model, ordinary action
description and recorded mask. Require exact probability/observation identities;
accumulate one step's gradients at a time. Measure the largest observation-array
payload against 512 MiB. Do not change parameters during this group replay.

Retain group checkpoints with model/optimizer/RNG, all episode traces and bests,
source hashes and structured reports. Keep temporary states until their gradient
recomputation and independent physical/mask replay pass, then remove regenerable
state duplicates. A group that fails its episode bound receives no optimizer step;
retain the partial group and stop the arm instead of silently resampling it.

Each arm gets 64 groups (8192 selected training actions), four 32-action episodes
per group, 120 seconds per episode, 5000 route expansions per selection and a
5400-second arm guard. Include startup, observation, inference, routing, validation
and recording in episode/arm timing. Freeze source/configuration/schedules before
training. No independent timed workload runs alongside the measured training.

Before training, test exact lexicographic comparison, a flat-return zero-gradient
case with entropy separated, and delayed-return credit using an enumerated small
sequential policy. Compare accumulated/recomputed gradients with ordinary retained
autograd gradients on sampled complete-factory episodes, including masks. Test
failure handling and immutable policy checks. These are implementation tests, not
action labels supplied to the RL learner.
