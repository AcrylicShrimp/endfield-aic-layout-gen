# Selected training-prefix recovery diagnosis

Status: declared before new inference. This is a retrospective training-case
diagnostic, not a capacity selection or fresh generalization outcome.

Report 37 establishes a five-command repair from one failed policy prefix. Both
completed seed-17 streams allocated 196608 commands (12288 sixteen-command episodes)
to each training case. Width two allocated 7104 root episodes each to battery gap-zero
rotations zero and two; absence of root training is not the explanation.

Freeze both audited final seed-17 actors before sampling. Use the existing battery
gap-zero rotation-two training case only. Compare three starts: original root;
the first six commands of the admitted witness; and the first five commands of the
width-two failing median. The latter two have identical facility placements but
different unfinished transport/bindings. Preserve the original valid best/base.

For each actor/start, sample 32 episodes at each of 16 and 128 policy commands from
CPU generators seeded 1013000 through 1013031. Batch size 16, CPU inference with one
thread. No restarts, teacher suffix, online update, search or repair. Prefix setup
commands are separately reported and are not counted as policy actions; this is a
conditional recovery test, not an end-to-end equal-work comparison between starts.

Inputs: versioned JSON protocol, audited source directory, native library, selected
trace/witness files with SHA-256 identities. Output: running/complete/interrupted
report, all episode counters and traces/layouts, per-cell translated area success,
best/upper-median score, completion counts, elapsed evaluation/validation time,
checkpoint/policy/source/input identities and diagnostic stage/code/entity.

All prefix commands must belong to the candidate domain, have zero reward and retain
the original valid incumbent. All sampled outputs require native and independent
reference acceptance. Independently replay best and upper-median traces per cell,
including the setup prefix, and verify every action is in the reference domain.
Compare policy hashes before/after. Refuse overwritten outputs or changed evidence.
Any mismatch stops the diagnostic; an incomplete report cannot support conclusions.

Publish all twelve cells without selecting a favorable subset. Better performance
on the witness prefix than the failed prefix would identify sensitivity to the
unfinished geometry; it would not by itself establish overfitting or the benefit of
more data. Similar failures from both would weaken that specific explanation.
Improvement at 128 versus 16 commands measures conditional recovery within those
allowances, not convergence. Nothing here alters the frozen six-stream protocol.
