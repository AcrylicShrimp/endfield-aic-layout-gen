# Confirm the same frozen root policy on independent development samples

Status: declared before confirmation or outcome evaluation.

The [relocation experiment](../reports/2026-09-08.19-relocation-curriculum-results.md)
trains three capable policies, but one has only a single root assessment before its
allowance ends. This follow-up changes development certification from consecutive
training checkpoints to two independent sampling banks on the same frozen policy.
It does not retroactively pass the original selection protocol or claim training stability.

Select each policy's **first assessed original-root pass** (52/64 on bank 200000).
A transition into the root from a shallower prefix does not qualify. Selected counts
are 245760, 262144 and 229376 for training seeds 17, 29 and 43. The counts are derived
only from development records. No later candidate is tested if confirmation fails.

Confirm these same frozen policies on a fresh development bank 420000–420063, with
16 edits per episode and at least 52 translation-qualified improving outcomes per
policy. All three confirmations must pass before opening either outcome bank. The
frozen policy state must stay unchanged; there are no optimizer updates. If any policy
fails, return `not_met` with `selection.confirmation_failed` and do not open outcomes.
Missing first-root passes retain `selection.no_mastered_policy`.

Only after every confirmation passes, evaluate 32 episodes at 128 edits on each
untouched outcome bank 400000 and 410000. Every policy/bank must produce at least
26 strictly smaller valid retained factories with an actual x/y translation. Rotation
alone does not count. Preserve all raw confirmation and outcome rows, selected model
hashes, accepted best/median layouts and independent representative trace validation.

Inputs use the existing selection DTO with strategy
`first_root_pass_then_frozen_confirmation` and a `confirmation` object specifying
horizon, seed start, episode count and required successes. Confirmation and outcome
banks must be disjoint; source development/outcome seeds must also be excluded.
The source audit, source/checkpoint hash checks and output freshness remain required.
All selected models are resolved before confirmations; all confirmations precede outcomes.

This bounded evaluation totals 3072 confirmation edits and, only if those pass,
24576 outcome edits. It measures retained relocation capability on this one factory;
held-out layout and production-chain generalization remain later stages.
