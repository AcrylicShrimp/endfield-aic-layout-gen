# Batched PPO execution for the twelve input contracts

Status: implementation contract for the user-requested renewed shallow screen.

Reuse the twelve registered observation/action contracts from the earlier input
screen, with the existing actor parameter architecture and a separate full
current/best critic. Training factories remain freshly generated per episode;
this does not revive the old fixed-reset experiment. The common shallow budget
and complete comparison protocol will be frozen before execution.

## Inputs and outputs

Each trajectory records its explicit input-contract name, actual causal actor
observation, full pre-action critic observation, actual behavior probability,
mask and reward. The collector accepts the contract explicitly. Prepared
minibatches retain variable candidate/member counts, optional current/best
worlds and bounded variable history lengths. Model parameter names are unchanged.
The new execution schema identifies support for these richer inputs.

A shared world-batching implementation serves separate actor and critic encoders.
It preserves exact raster shapes, graph offsets and per-world pooling. Geometry
observations must skip message updates and their normalization, including when
batched with full observations in a test. Hidden worlds contribute zero features
and cannot alter predictions or gradients. An absent operand remains the zero
sentinel after node-index offsetting. Equal current/best worlds are encoded once
per encoder, with the same reuse semantics as the reference model.

History inputs are causal and limited by the selected contract. Pad only the
recurrent input sequence, and select the output at each actual history endpoint;
never use the padded final hidden state. Empty histories contribute zero and
must not create an optimizer gradient when the whole batch has no history.
Keep the recurrent/history block in FP32 during an AMP probe. No trainable
parameter is added, removed or shared between actor and critic.

## Collection and failures

During training build the full critic observation once, then derive the actor's
permitted current/best/context/history view. Evaluation constructs only the
requested actor observation. Record history only for contracts that consume it.
Native proposal acceptance, budgets, best retention and action-key memory are
unchanged. No-restore controls never re-enable restore on exhaustion; retain
the original structured action-exhaustion failure rather than silently granting
extra behavior or pretending a full selection budget completed.

Do not add recurring input/mask/reward replay validation to the normal update.
Use standalone equivalence and native integration tests. Compare all contract
observations, reference forward probabilities and gradients, meaningful history
gradients, geometry message omission, absent operands and mixed history lengths.
Check representative geometry/full-current/best-layout-history throughput and
precision before finalizing the experimental setup. Production harness and
monitoring requirements, independent review and readiness tests follow setup
finalization and precede the shallow learning comparison.
