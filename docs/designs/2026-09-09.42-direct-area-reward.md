# Direct area rewards and causal credit

Status: implemented, completed and audited; contract defined before
implementation. See the [results](../reports/2026-09-09.42-direct-area-reward.md).

## Scope and experiment

Replace heterogeneous-factory episode ranks with the actual reduction in the
best valid layout's area. The first controlled comparison keeps the existing
actor, generator, action mask, kind balancing, temperature, Adam, entropy,
gradient clipping, batch size and action budget. Use undiscounted reward-to-go
score-function gradients without a critic. PPO and a learned value/GAE baseline
are separate follow-up changes; this slice must not be called PPO or GAE.

Run on the existing experimental server in a new isolated source directory.
The stopped rank continuation stays stopped. Compare with the completed audited
stage-39 rank pilot, starting each new seed from its original untrained actor,
not from its trained rank endpoint. Use the same 17/29 seeds, generation/action
seed schedules, 32 batches of 32 attempts and 32 actions per admitted episode.
Use the same 16 evaluation draws per seed, measuring at 0/8/16/24/32 updates.
The historical rank reference has measurements at 0/16/32 only. A reduced smoke
may alter counts, but must be labeled and cannot supply full learning evidence.

The two treatments change both reward definition and temporal credit, including
removal of transport/turn rank tie-breakers from the training objective. They do
not isolate magnitude from credit assignment. Report unchanged optimizer scales:
direct fractional returns and rank returns have different numerical ranges.
No claim of equivalent effective entropy or step size follows from identical
hyperparameters. Match evaluations and first-batch physics/sampling to the
archived rank reference before interpreting subsequent differences.

## Reward contract

Input: the initial native integer area A0 > 0 and the sequence of validated best
scores. For each selected action, r_t = (B_t - B_(t+1)) / A0. B is the area of
the best validated witness, never an unvalidated proposal or merely the current
exploration state. Require non-increasing best area. Keep exact integer
numerators and the episode denominator in diagnostics; floats enter gradients.

The undiscounted sum telescopes to (A0 - B_final) / A0. A reduction by two cells
has twice the reward of one cell in the same factory. Worsening and restoration
of an already achieved record earns no reward. Restoring the retained best does
not reset reward accounting. Rejected/unchanged actions earn zero immediate
reward. They still consume a selection from the fixed horizon. No additional
invalid/no-op/time penalty or terminal bonus is introduced. Incomplete timed-out
rollouts are errors, not shortened training episodes or successful zero returns.

The action at time t receives G_t = sum_(u=t)^(H-1) r_u. Preparation actions can
receive later rewards; rewards before an action cannot credit that action.
Gamma is exactly one and terminal bootstrap is zero. The batch loss is the mean
over admitted episodes of -sum_t G_t log pi(a_t|o_t) / H, plus the unchanged
mean entropy regularizer. No across-factory rank or return standardization.

Accumulate policy-score gradients in a prefix P_u = sum_(t<=u) grad log pi_t / H
and accumulate r_u P_u. This is algebraically the same reward-to-go gradient
without retaining H copies of every parameter gradient. Store reward-gradient
and entropy-gradient tensors with a new explicit payload schema. Require model,
input and tensor hashes, shapes, dtypes and finite values before Adam mutates.

## Semantics and diagnostics

Production/native acceptance remains lexicographic: area, transport tiles, turns.
The area-only training objective intentionally provides no direct reinforcement
for secondary-only improvements. Existing valid-current exploration and best
retention are unchanged. No production architecture, routing, graph, geometry,
external boundary or candidate vocabulary change is part of this experiment.

Raw unused-cell count is not a reward: adding unnecessary transport can fill
empty cells and falsely improve that metric. A later dead-space diagnostic must
define unusability and distinguish usable corridors. Secondary reward design
requires proven bounds that preserve the existing score order; arbitrary scalar
weights and diagnostic canvas limits cannot become production invariants.

Output per action: before/after best area, reward numerator/denominator, reward,
reward-to-go in the completed trace, native current/best score and existing action
identity/sampling/validation evidence. Output per batch: admission denominator,
reward distribution, zero-reward episodes, gradient/entropy norms, optimizer and
checkpoint identities, selected actions and actual collection/audit time.

Every failure is structured with code, severity, stage, message and entity:
`direct-reward.contract`, `direct-reward.payload`, `direct-reward.comparison`,
`direct-reward.run-failed`, `direct-reward.plot-failed`. Failed collection cannot
update parameters. Source changes stop execution. Owned workers are cleaned up
on interruption; completed checkpoints and partial evidence are retained.

evaluation and refresh at most once per minute between evaluations. Separate
