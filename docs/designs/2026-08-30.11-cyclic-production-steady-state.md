# Cyclic Production Steady State

## Decision

A recipe cycle is a valid production graph. A seed loop, for example, can consume an initially supplied seed, produce crops, recover more seeds, and then operate without continuous seed input.

Graph resolution therefore preserves cycles instead of rejecting them. Recipe choice still happens before throughput calculation: every traversed item must have exactly one selected producer unless the request declares that item external.

## Steady-State Model

For every resolved recipe `r`, the planner creates a nonnegative continuous run-rate variable `x_r`. For every non-external item `i`, it requires:

```text
sum(recipe output of i * x_r) - sum(recipe input of i * x_r)
    >= requested final demand of i
```

The requested demand is zero for non-target items. The objective minimizes total recipe work seconds per second. This selects the smallest feasible circulation while allowing intentional surplus when recipe ratios require it.

The current implementation uses the pure-Rust `microlp` backend through `good_lp`. Solver values are converted back to bounded rational `Rate` values and checked against exact material balances before a report succeeds.

## Bootstrap Contract

`bootstrap_item_options` lists cycle-carried items that can initialize at least one feedback loop. They are alternatives, not continuous external input rates. The steady-state planner does not yet calculate a minimal startup quantity or a time-dependent startup schedule.

A lossless or shrinking cycle cannot supply a continuously drained target without replenishment. Such a request returns `cyclic-throughput-infeasible`. The caller may instead declare an item external when continuous replenishment is intended.

## Stage Boundary

The throughput stage owns recipe run rates, material balances, continuous external input rates, and bootstrap diagnostics. It does not select facility counts, place facilities, route transport, or schedule startup.

Downstream stages receive fixed recipe rates and may materialize a cyclic facility-instance wiring graph. The spatial solver must route that fixed graph but must not choose recipes or reinterpret the production balance.
