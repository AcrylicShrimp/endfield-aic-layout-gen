# Retained advantage and value-signal diagnosis

Status: retrospective. Selected after report 51's rehearsal-gradient measurements
and a preliminary inspection of one lower-rate glass rehearsal trajectory per
update. The full analysis includes both first-pair rates, all sixteen cases and
updates 9–16. It does not sample new outcomes or alter any policy.

Inputs are the hash-identified comparison, collection files, incoming update-eight
configurations and complete gradient diagnostic. Reconstruct the exact full-rollout
GAE and normalization from stored rewards, values and terminal flags. Independently
check GAE using a closed finite sum of temporal-difference residuals. Compute sampled
discounted return-to-go with terminal boundaries, and its difference from saved
value predictions. A sampled return is not the true expected value or a ground-truth
advantage; positive error alone does not establish a critic implementation bug.

Classify each observation as before, at, or after its episode's first positive
reward, or in an episode with no positive reward. Later positive rewards remain
counted in the after-first group. Split all results by case and current/rehearsal
start, retaining the original global normalization over 1024 observations.

Schema-one `signals.json` records input/config hashes, per-update normalization,
independent arithmetic errors, and per-case/start/phase counts and sums of rewards,
values, sampled returns, prediction errors, raw/normalized GAE, absolute normalized
advantage mass, and raw/sample-Monte-Carlo sign disagreements. Aggregate only from
these preserved counts/sums. Check phase totals, episode boundaries, reward/trace
identity and correspondence to the incoming gradient diagnostic's policy loss.
Reject changed input or existing output with a stable `retained_signals.*` error
and the relevant path. No replay is necessary after the previous command audits.

Tests must distinguish terminal boundaries, multiple rewards after first improvement,
and zero-reward episodes; verify lambda-one GAE against sampled return minus value.
Run the actual CLI, full Python/workspace verification and artifact checks. Keep
full structured results ignored and commit concise findings plus reproduction.
Do not infer gradient direction from advantage magnitude alone, remove rehearsal,
terminate all episodes at first success, or adopt a new advantage estimator merely
because this diagnostic exposes a large signal or baseline discrepancy.
