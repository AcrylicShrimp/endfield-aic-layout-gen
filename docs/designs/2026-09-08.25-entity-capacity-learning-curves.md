Report actual-root translated area-improvement frequency, median/best area, physical
tiles and turns, normalized area reduction and curriculum progress. Aggregate cases

lowest mean per-case median area ratio, then mean median physical tiles, then turns,
then fewer sampled training edits. Median means the actual upper-median episode by
lexicographic score, consistent with retained evaluation artifacts. Do not replace a
chosen checkpoint after seeing development results. If any seed has no qualifier,
that width is ineligible, but still publish its complete learning curve.

## Curve aggregation

`entity_learning_curves.py --source <completed-matrix> --output <fresh-report.json>`
requires all declared streams and their matching completed audit hashes. It emits
all case/checkpoint scores and translated success counts, exact rational ranking
keys, each retained checkpoint hash, width eligibility, and the actual observations
available at four common training-time allowances. This command opens no development
or held-out outcomes. An ineligible width retains all its curves in the report.
The confirmation stage must independently verify current policy/input/native source
and freeze the selected policy artifacts before opening development outcomes.

## Restart confirmation execution

Confirmation uses bounded waves of independent restarted episodes (16 per wave) with
batched frozen inference. Each episode keeps one CPU sampling generator across all
four attempts. Trim masked padding before categorical sampling so another episode's
candidate count does not change its random-stream consumption. The already running
training/root-curve evaluator remains frozen with its declared implementation; this
confirmation sampler does not revise those recorded results. Device and wave size are
reported for each confirmation cell. Hardware floating-point differences may still
change sampled trajectories; independent action replay is the semantic check.

`entity_capacity_confirmation.py --source <completed-matrix> --native-library <path>
--output <fresh-directory>` recomputes the audited retention report, verifies current
native/catalog/policy source, and exports every eligible policy before evaluating any
development cell. It retains the training device for inference. Its report records
all development outcomes and exact capacity-ranking keys before opening only the
selected width's held-out cells. No eligible width or a failed criterion returns
`not_met`; malformed or changed evidence returns an explicit interrupted diagnostic.
Held-out failure never triggers evaluation of the other width.

The implementation preserves per-attempt native validation, independently validates
every retained episode layout and replays the best/median representative traces.
A regression compares a partial final wave against serial sampling with continuous
per-episode generators, checking both attempt counters and retained traces. Batch
normalization buffers and the global Torch RNG must remain unchanged.
