# Diagnose the bounded RL pilot before increasing experience

## Status and question

The user asks why report 30's trained endpoints do not improve evaluation. Pause
the not-yet-started collection-throughput study while examining the existing
evidence. Its implementation and tests remain separate work in progress. Do not
equate changing parameters with useful learning, or infer fundamental RL failure
from this short pilot.

## Read-only evidence contract

Use the frozen training protocol, audited completed-group records, episode traces,
state snapshots and existing checkpoints. Perform no training, additional factory
edits, teacher-label construction or checkpoint selection by evaluation score.
Keep completed and unapplied episodes separate.

First quantify reward-bearing versus flat-return groups by original/prepared reset
type, sampled action kinds and observed incumbent-improving kinds in positive-return
episodes. These associations do not identify causal action contributions or the
exact policy-gradient direction. Measure actual initial/terminal parameter changes.

Then construct a fixed observation panel from the first pre-action state of attempt
0 in each of the first ten random-arm groups. These cover the ten distinct reset
cases. Require the reconstructed observation and saved ordinary-history mask to
match the retained source evidence. Never use the selected action as a target.

On each unchanged panel observation, evaluate both policies at initialization and
every completed update. The initial five-checkpoint panel found a large warm-arm
reversal between updates 32 and 48; inspecting every retained update localizes it
without running a new optimizer step. Record probability mass by action kind,
entropy, largest action probability and total variation from the initial and
preceding distributions. Use the original temperature and action-kind balance rules. Check
parameters remain unchanged. This separates input/sampling variation from actual
policy drift; it does not replace rollout evaluation.

Inspect the first recorded Adam transition from each empty optimizer state. Use
the saved moments and hyperparameters to reconstruct its parameter delta and
compare with the saved checkpoint within float32 rounding. Report the update's
reward/entropy gradient norms, median absolute parameter change and fraction near
the learning-rate scale. This is arithmetic on existing checkpoints, not a new
optimizer step or a counterfactual outcome experiment.

Retain a compact source/hash manifest and local JSON/figure outputs under ignored
artifacts. Record confirmed findings, plausible mechanisms and unresolved causal
questions separately in a concise report. The report must not call ordinary
episodic REINFORCE invalid merely because all sampled actions receive terminal
credit. Any reward, horizon, optimizer, curriculum or experience-budget intervention
requires its own explicit controlled experiment after this diagnosis.

## Decision

Identify which failure descriptions the evidence supports: absent updates, absent
reward signal, policy drift toward an easier behavior, insufficient measured
exposure, or another implementation defect. More than one may contribute, and
uncertainty must remain explicit. Choose the next controlled comparison from this
evidence before launching a larger training run. Keep the full Heavy 1%/visual,
sustained relocation/rerouting and bounded CLI objective unfinished.
