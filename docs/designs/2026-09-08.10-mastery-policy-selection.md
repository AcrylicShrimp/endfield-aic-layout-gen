# Preserve the first jointly mastered root policy

Status: protocol declared before selected-policy outcome evaluation.

The [full curriculum experiment](../reports/2026-09-08.17-case-curriculum-results.md)
learns both original roots but fails its final-checkpoint retention gate. This follow-up
changes policy selection, not training weights, architecture, rewards or outcome thresholds.
It does not retroactively pass the earlier experiment.

For each of its three audited runs, select the earliest saved checkpoint whose development
assessment leaves **both** cases at their actual original-root level with two consecutive
passing assessments. Use only `assessments.jsonl` and the already audited controller/start
contract; do not inspect root outcome values to select a model. The selected counts are
172032 / 163840 / 180224 for seeds 17 / 29 / 43, derived from development feedback.
Never fall through to a later checkpoint if its outcome test fails.

Evaluate each selected frozen policy from unmodified roots for 128 edits using two fresh
sampling seed banks, 300000–300031 and 310000–310031. These seeds have not been used in
training assessment or previous outcome evaluation. Keep at least 26 improving episodes
out of 32 as the acceptance threshold for each case, bank and trained policy: all twelve
cells must pass. This tests a retained policy on two independent sampling banks; it is
not the earlier test of continued-training stability at two final checkpoints and does
not establish generalization to new factories.

CLI inputs: selection protocol, source run root, native library and fresh output path.
Require complete audited source runs, matching metadata/checkpoint hashes, an empty
actual prefix at each declared root level, the configured source commit and exactly the
three declared training seeds. Missing eligible policies are a `not_met` result with
`selection.no_mastered_policy`, not an invitation to choose an unrelated policy.
Invalid inputs use `selection.source` or `selection.protocol`; execution failures record
`selection.interrupted` with the active source run and stage.

Output: immutable selected-count/hash references, CPU inference model exports, every
outcome episode's return/score/counters, per-bank summaries, accepted best/median layouts
and independent representative-trace replay. No optimizer updates occur. The original
training checkpoints remain intact; selected inference exports contain model state,
architecture/configuration and source provenance. Report selection/evaluation time
separately from historical training cost.

If all cells pass, stage one has a usable retained-policy path and may advance to the
relocation milestone. If any cell fails, preserve that result and diagnose the policy
selection/generalization gap within these roots before further expansion. Do not reduce
the threshold or test many candidates on these same banks.
