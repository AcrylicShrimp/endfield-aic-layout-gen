# Immutable Internal Factory Edit Candidates

Status: bounded cutover, 2026-09-07.

The user asked to keep optimizing while measured opportunities remain. After data preparation
reuse, observation and candidate construction still spend time allocating and reparsing many
mutable command dictionaries. A fixed elongated replay profiles 71,751 canonical-key parses
and candidate feature dispatches for only 256 selected edits.

## Internal contract

`Environment.candidates()` returns a `CandidateSet`, containing an ordered tuple of immutable
`Command` values plus the current draft identity, revision, and already-computed geometry index.
`Command` stores the operation and immutable positional arguments; its serializer produces the
unchanged external command JSON. Field order within placement assignments follows the existing
catalog traversal, while the exact JSON sort key still uses sorted object keys. Erase-cell and
edge direction order remain significant.

Training selects a typed command and serializes only that selected command for `Environment.step`.
The external serialized edit, witness, trace, acceptance, and checkpoint observation contracts
remain unchanged. This is a hard cutover of internal candidate APIs; do not retain a production
list-of-dictionaries path. Explicit full serialization is reserved for diagnostics and tests.

Observation construction rejects candidate sets from a different draft identity/revision.
It reuses their geometry index rather than rebuilding the same current-state index. No index
is reused across state changes. The separately validated base still gets its own current index.

Cache exact canonical sort strings and complete encoded feature/absolute-point pairs by typed
command in separate bounded LRUs. Include current terminal locations and discard-anchor position
in keys for state-dependent commands. Other points are determined by immutable command arguments.
Return owned observation arrays and compute raster-relative point indices from the current origin.
Caches retain no validation outcomes or mutable geometry. Remove obsolete dict parsing and prefix
cache code. Cache bounds remain implementation memory controls, never legal-domain restrictions.
