## Stage contract

Inputs are fresh generated requests and complete randomized factories, external
catalogs, an explicit training configuration and an authenticated release native
library. Every episode binds its actual request/start. The native declarative
blueprint remains immutable while placement, rotation, physical ports and bands
change in the private draft. Only validated improvements replace the retained
best. Normal construction and the isolated global exact solver are unaffected.

The policy selects a pose (facility, candidate position and catalog rotation) or
a band insertion/deletion. For a pose it then selects every original facility
terminal's compatible port without replacement. The complete joint decision is
submitted as one native action, with no intermediate environment steps. Its
likelihood is the root choice probability times all conditional port choices;
PPO and successful-experience imitation use the log of that whole probability.
A conditional decoder avoids enumerating the Cartesian product of port maps.
Root choices retain per-kind count normalization. Entropy regularization retains
the configured coefficient and uses root categorical entropy plus conditional
port entropy on recorded prefixes; it does not enumerate exact joint entropy.
This is an explicit consequence of the new structured action distribution.

Position proposals preserve the predecessor's one/two-tile moves and other
facility origins, and include the current position for pure rotation/port edits.
Repeated actions can grow the natural footprint; current extent is not a game
canvas bound. Band candidates use current geometry and configured positive
widths. Original incidence and current ports/anchor/component positions must all
be observable. Invalid geometry remains a permitted unfinished draft; do not
mask away preparation actions because they are temporarily worse or overlapping.

The graph encoder, directed message passing, path pooling, shared actor encoder
and separate critic head remain. The new root and conditional-port decoder need
a new model/checkpoint schema; old actor checkpoints and action labels are not
silently reinterpreted. Compatible execution and optimization code is shared.
Historical old-contract research commands remain explicit, isolated comparators.
No old action is inserted into a new-policy rollout.

The training command exports bound checkpoints, update metrics, input coverage
and failures, evaluation reports and retained valid best witnesses. A structured
failure preserves the latest published complete update and catchable partial
worker evidence. Resume restores both optimizers, all RNGs, replay state and
unfinished native episodes without regenerating inputs. Resource failure is
neither convergence nor infeasibility.
