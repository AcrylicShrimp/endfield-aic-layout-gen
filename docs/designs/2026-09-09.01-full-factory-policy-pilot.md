# Model-connected full-factory pilot

Status: bounded stage-four learning experiment, declared before evaluation. The
preceding transaction API accepts real mixed/cyclic factories but has no policy.
This slice connects physical observation, selected edits, validation and learning.

## State and actions

Use the immutable original-request ledger and `FactoryEditSession` acceptance.
Observe each current complete witness as a spatial raster plus a sparse typed graph:
facilities, commodity networks, individual network cells, terminals, components and
catalog ports. Preserve two different network-cell tokens at a bridge and both
transport layers at the same XY position. Include exact incident segment rates as
numeric features and connectivity. Model features omit string identities, candidate
outcomes, routed scores and historical teacher labels. Coordinates are relative to
the actual used box; observations and checkpoints use a new explicit schema.

Enumerate unranked finite local actions: single-facility cardinal translation and
catalog rotation, compatible unused terminal ports, chain rerouting, component poses,
bridge release, and explicit single-strip insertion/contraction. Restore-best is a
charged rollback action. Selected reembedding uses the existing dedicated bounded A*
engine, pipe-first, with at most two new crossings. This finite local domain is a
prototype, not a completeness or final action-space claim. Do not use its heuristic
candidate generators or silently rank/filter actions by routing outcomes.

Insertion chooses a grid cut that does not bisect a facility. Shift all geometry on
one side and explicitly subdivide crossing segments at unchanged rates. This also
moves affected external endpoints onto the expanded actual boundary. Contraction
removes one selected event-free strip, preserving bodies, terminals, components,
turns, junctions and transverse segments. These are complete physical edits, not
facility-only construction. They permit expansion before local relocation despite
the reembedding kernel's current-extent neighborhood. They do not establish that
all useful larger relocations/topology changes are expressible efficiently.

Every selected action is charged, including executor failure, unchanged geometry and
rollback. Keep private current/best separate. Pass completed proposals to native
acceptance; executor failure cannot alter the retained state. The episode wall clock
includes action extraction, model inference, routing, serialization and validation.
Record costs separately. Bound A* expansions per action and the complete experiment;
do not claim the cooperative time checks preempt native or Node computation.

## First learning screen

Train fresh policies, not historical checkpoints. Compare sparse graph message depth
zero and four with otherwise common width 32 and three training seeds 17/29/43.
Use on-policy terminal-rank policy gradient: four independent eight-action episodes
on the same training root, exact lexicographic final-best comparisons, summed sampled
log probabilities and entropy regularization. This is a deliberately simple signal
control; no claim that PPO, normalization or this objective is optimal.

Training roots: battery-38, citron-48, iron-nine-108, and closure-refined from the
retained full-factory input manifest. Rotate them deterministically. Each arm has
1024 selected actions (32 groups), learning rate .0003 and entropy coefficient .01.
Evaluate the untrained and final policy, uniform selection and a declared geometry
control on all 23 roots plus the existing strong 59-facility witness, two evaluation
sampling seeds per input, eight actions each. The geometry control prefers an
available contraction and otherwise a facility translation toward the facility
centroid; it observes no route result or candidate score. All controls use the same
vocabulary, action allowance and per-action routing-work limit (5000 expansions).
The episode elapsed bound is 30 seconds and whole-screen guard 1800 seconds.

Every evaluation geometry has already been observed historically. Twenty roots are
excluded from these adaptations, but related production graphs span training and
evaluation: this is geometry transfer and an implementation/learning screen, not
sealed family generalization. No numerical all-case gate blocks the next experiment.
Report all seeds, factory sizes, mixed/branch/cycle coverage, score changes, rejected
and unchanged/revisited actions, routing work, timings and errors. Distinguish learned
benefit from the executor and simple contraction bias. A short negative result does
not prove that the goal is impossible.

Before the full screen, smoke the new observation/gradient/action path and audit
selected complete outputs against the independent original-graph checker. Keep
checkpoints, trajectories, selected outputs and source/input hashes ignored under
`artifacts/`; commit source, contract and concise findings. Production inference,
new-family training diversity, the 1% target and visual acceptance remain open.

## Concrete observation and execution contract

The schema ID is `full-factory-spatial-relational-v1`: 28 raster channels, 32
features per entity, 16 per directed edge, 24 per action and eight episode context
features. Network cells remain separate entities per owner. Edges encode directed
segments and their reverse observation edges, network membership, terminal/cell,
terminal/facility, port/facility, component/cell, terminal/port and commodity equality.
No model feature is a string ID or vocabulary index for a particular item/recipe.
Float32 rate signals include the quotient and log numerator/denominator; the physical
witness and validation retain exact rationals. The model representation itself is
not an exact rational arithmetic encoding. Out-of-box catalog ports retain their
relative coordinates while their local raster sample clips to the nearest edge.

Both models use two spatial convolution layers, GroupNorm and a shared candidate
scorer. Four message layers use sparse directed edge aggregation and LayerNorm; the
zero-layer control omits these updates. Pooling and action scoring accept variable
entity/candidate counts. Terminal ranks are averaged over other group members;
summed log probabilities are divided by the common eight-action horizon. Clip the
gradient norm at .5. There is no value network, PPO ratio or historical weight reuse.

The first screen runs on local CPU with one Torch thread and deterministic operators.
It retains all episodes and their validated best witnesses, initial/final policies,
optimizer/RNG checkpoints, exact source/input/native hashes and partial records on
failure. The outer episode deadline begins before native session initialization;
completed native proposals that return after it are discarded by the outer episode.
Executor failures consume a selected action without pretending a native proposal was
submitted. These two counters remain separate in the report. An unexpected untyped
executor exception aborts the screen as a bug instead of counting as an ordinary
rejected edit. The graph-depth comparison also changes parameter count and compute;
it does not isolate message depth from those effects.

## Port-arm correction before the repeated screen

The first complete run (112.595 seconds, 11520 selected actions) exposed 370 rejected
insertions. All were attachment-geometry failures: a cut could separate a facility
body from an adjacent used catalog-port connection. The native validator rejected
these candidates and preserved incumbents. This is a defect in the proposed
shape-preserving insertion vocabulary, not evidence against learning or game
feasibility. Preserve the complete first run, its independent audit/replay, and the
exact pre-fix executor source under ignored artifacts.

Exclude insertion cuts between the nearest facility-body cell and each used terminal
connection. This is a state-local port-adjacency condition, not routing-outcome or
score filtering. Test every offered insertion on the immutable crossing fixture and
check arm cuts independently using the projected catalog ports. Repeat the entire
original two-depth, three-seed screen from fresh initializations with unchanged
training/evaluation budgets and splits. Retain both matrices; label the repeated
one `full-factory-policy-screen-port-safe`. Do not merge selected outcomes from the
two executions or attribute the changed vocabulary's benefit to training.
