# Distant and connected-group factory relocation

Status: stage-four implementation contract, declared before experiment outcomes.
The preceding turn made progress: learning improved sampled quality, but the strong
59-facility footprint stayed fixed. Its new incumbent has a 7x10 empty rectangle
and no available single-strip insertion/contraction at the root state.

## New internal contract

Cut the model-connected executor RPC/description to schema 2 and the observation/
checkpoint schema to `full-factory-spatial-relational-v2`. Replace `move(instance)`
with `relocate(members, dx, dy)`, where members are unique placement indices in the
current witness. Action x/y denote the translated group-body minimum, not the old
single-facility origin. Reject old schema/actions/checkpoints explicitly. Historical
experiments remain reproducible from their committed versions; do not add a runtime
legacy adapter. Native complete-witness acceptance stays schema 1 and unchanged.

The policy observes normalized full-range displacement, destination geometry, group
size/body bounds and all selected member embeddings. Pool source member features
and destination spatial features; do not represent a group using only one member.
Rates, ownership, both physical layers and original-request validation remain intact.

## Group and target generation

A required translation closure joins facility owners of a co-located typed terminal
slot that the existing executor cannot detach. A closure sharing a fixed external
terminal is omitted from this retained-terminal relocation domain. This is not proof
that it cannot move after another port/boundary edit. Additional groups are required
closures of physically reachable production SCCs and producer/consumer pairs. Derive
reachability through directed network segments, including zero-length connections;
do not falsely connect disconnected paths merely because their commodity IDs match.
Deduplicate groups and respect the existing 16-member local movement limit. Record
omitted groups and reasons. Whole-factory facility-only placement is not an action.

Use the current extent as this explicit local routing neighborhood. New distant
translations jump directly to a destination; the blueprint edit does not require
all intermediate positions along the jump to be collision-free. Generate local
one/two-cell cardinal shifts and a deterministic spread of destination translations
across the neighborhood. Defaults are 256 examined grid translations and at most
32 retained translations per group, with a 512-group guard and a 200000-cell
observation/enumeration area guard. These are operational prototype bounds, not game
W/H or feasibility limits. Record truncation and scan/filter work.

Preflight checks use actual member bodies, moving terminal/component anchors and
carried internal paths against stationary bodies and anchors. Prefix occupancy
queries accelerate body checks. Ordinary route cells may be ripped up later; do not
treat every route as immutable body occupancy. No A* or full-candidate validation
runs while enumerating. Static rejection never becomes a global impossibility claim.
Selected edits use the dedicated pipe-first A* engine with the existing shared
5000-expansion bound and at most two new crossings, then native complete-factory
acceptance. Every selected failure and every candidate-scan CPU cost remains charged.
Outward routing and external-terminal re-anchoring are not implemented by this slice.

## Controlled learning comparison

Compare four vocabulary settings through the SAME new observation and policy:
raw local single-facility shifts; statically filtered local singles; filtered distant
singles; and filtered distant singles plus connected groups. Other edit operations
are common. These are declared candidate-domain ablations, not compatibility modes.
Use fresh depth-zero width-32 policies, one common training seed 17, 1024 training
selections each, four eight-action episodes per rank update, and the preceding four
rotating training roots. Keep rank objective, Adam .0003, entropy .01 and norm clip .5.
Use flat candidate sampling so operation-prior changes do not confound the vocabulary
comparison. Retain untrained/final snapshots and full source/input/checkpoint hashes.

Evaluate each initial/final model and uniform control for each vocabulary on all 23
retained roots, the prior 392-tile strong start and the latest 386-tile incumbent.
Two sampling banks 1230000/1240000 receive 32 selections per input, four independent
eight-action attempts with best retention. Use one common 30-second total cell
allowance including resets/selection/recording; each episode receives only the
remaining allowance. The screen guard is 1800 seconds. Record every failure rather
than dropping hard inputs. This is a one-seed, historically opened geometry screen,
not sealed family generalization or production readiness.

Before training, verify real distant and multi-facility transactions against native
acceptance, model gradients through group operands, and rejection of old contracts.
Audit all selected best witnesses against original graphs and independent metrics;
replay a declared bank and any new target discovery. Report learning versus executor
benefit separately. Preserve every prior validated incumbent. If the richer vocabulary
still fails, use that evidence to select the next concrete capability, not to claim
that the full goal is impossible or to stop at another acceptance-only report.
