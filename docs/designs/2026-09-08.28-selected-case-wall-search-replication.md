# Selected-case wall-allowance search replication

Status: declared after the complete transition pilot and before these fresh outcomes.
This is a post-selection training diagnostic, not untouched-case confirmation.

The first pilot has one area win for PUCT at 8192 transitions: battery gap-zero
rotation-zero, seed 1000001, area 98 versus 105 for independent policy rollout.
Select that case explicitly to ask whether the gain recurs under fresh sampling.
Do not generalize from this selected case to other factories or policy seeds.

Use the identical width-one training-seed-17 final checkpoint, environment horizon 32,
CPU inference with one Torch thread, UCT/PUCT constants, rollout and backup semantics.
Keep the value head unused. Repeat random rollouts, policy rollouts, UCT and PUCT at
sampling seeds 1002000 through 1002031. Rotate method order by seed index modulo four.
Every arm receives the same six-second exploration allowance. Keep safety ceilings of
1000000 native transitions, 16384 tree nodes and 1 MiB tree-array storage. These guards
are not intended to bind first; report any guard-limited cell separately.

Check elapsed time between operations. Record search time and total cell time including
runtime setup, independent final acceptance/replay and output selection. Report overrun
above the configured exploration allowance explicitly; this is not an exact total-time
deadline. A completed paired wall comparison requires both arms to reach the wall
allowance rather than terminate at another guard. Actual simulated-command counts may
differ substantially across methods and must remain visible. All work is hypothetical.

The selection-evidence input must match first-pilot SHA-256
`f6853dd6661b428210ce11f83244cafafbd16194a89384230a2928b07a434891`.
Verify and freeze the identical policy hash before opening any new cell. Preserve all
128 results, validated layouts and complete selected traces. Independently replay each
selection and verify frozen policy/BN tensors. No training, witness prefix or repair.

Report each method's best/median score, area-improvement and additional-compaction
frequencies, total simulated work and elapsed time. The predeclared additional-compaction
threshold is area below 119, the first pilot's median for this case; it is a descriptive
diagnostic rather than a new factory objective. Retained selection remains lexicographic.
Show paired wins/ties/losses for UCT/random, PUCT/policy and UCT/policy at completed wall
allowances. Publish all pairs and distinguish a repeated best result from a median or
frequency improvement. Do not retune parameters within these 32 pairs.

This experiment does not consume the capacity study's development or held-out outcomes.
The five remaining capacity streams continue on frozen server source without alteration.

Run `tree_search_wall.py --source <matrix-directory> --protocol
tools/factory-edit-pilot/tree-search-wall.json --selection-evidence <first-pilot.json>
--native-library <path> --output <fresh-directory>`. The command verifies the original
selection record, audited checkpoint and unchanged frozen policy, then records each
cell and its selected artifact hashes in `wall.json`. Only after all 128 cells finish
does it write the complete summary and paired outcomes. Guard-limited pairs stay
explicitly unmatched. Tests cover this distinction and reject missing/duplicate cells.
