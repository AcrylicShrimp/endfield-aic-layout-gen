# Full-factory family admission and physical capability

## Outcome

The current production constructor supplies ten new complete original factories
from twelve predeclared source-plan/rate requests. They cover 2, 3, 16, 18 and 48
facilities, required plant return cycles, branching/merging, external water pipes
and a required internal gas pipe. Every admitted root passes independent Rust
geometry and original-graph coverage, native edit-session admission, schema-three
observation and a finite CPU policy forward pass.

Eight ordinary geometry-selected strip contractions improve every admitted root.
All 80 selected contractions validate and reduce area. Two separately charged
internal-pipe reroutes validate but reproduce identical geometry and score.
An all-best audit passes all twelve episodes and 82 selected edits. These are
constructor and operator results; no policy weights are trained in this slice.

The original 59-facility Heavy Xiranite incumbent is unchanged at
`[2132,374,148]`, 41x52, with **30.5347% empty XY area**. The requested 1% target,
learned transfer, sealed diverse evaluation and bounded production CPU CLI remain
unfinished. No fundamental impossibility has been established.

## Input and split discipline

The [stage contract](../designs/2026-09-09.09-full-factory-family-admission.md) and
`tools/factory-edit-pilot/full-factory-family-study.json` precede the screen.
All paths are explicit, and source plans remain external data. Medical and food
share the training family `enriched-consumables`; their common production subtree
is not misrepresented as independent held-out content. Copper liquid and watered
grass are opened development families. None of these families may later be called
sealed evaluation families. Two copper rates have identical geometry but different
required rates; they are not two independent topology samples.

Medical and food reuse the complete tracked tier-three source selections at
1/100, 1/40 and 1/10 target units per second. Copper uses explicit liquid-from-gas,
gas-from-copper and ore-furnace sources, including the furnace's actual water import
and sewage export. Grass uses the watered planter with its required seed return
cycle and original water import. Copper/grass rates are 1/10, 1/2 and 2 units per
second. These are new requests, not substitutions into the Heavy Xiranite request.

The fresh release CLI runs ordinary downstream-closed construction, serial analysis,
256 growth steps, 256 placement attempts and 4096 route searches per transaction.
No fixed flow direction is imposed. A request has a 60-second construction guard;
the study admits up to 128 facilities. These are experiment guards, not game limits.
No historical partial witness, global placement or exact fallback supplies a root.

## Measurement corrections

The first admission script used the historical compaction score helper, whose turn
count omits terminal arms. Before finalizing, it was replaced with the existing
independent complete metric definition `used-area-layer-tiles-all-terminal-arms-v1`.
A fresh canonical run returns the same twelve statuses and byte-equivalent ten
root DTOs. All numbers above use the corrected metric. Imported roots from the
first run remain valid because their complete geometry, graph and rates match.

An initial capability run repeatedly computed the same best-state hash for every
offered action. It was explicitly stopped after recording partial results; those
timings and incomplete episodes are excluded. Computing that hash once per state
restores all eight selections for every root. The corrected run finishes, and its
source provenance and all retained bests pass audit. Both superseded source
snapshots remain local for identifying the corrections.

## Next decision

Required pipes/cycles can now enter the full-factory edit interface from fresh
production requests. Feed their actual compression trajectories and original
obligations into a family-aware learning curriculum, keeping the easy strip baseline
visible. Measure whether learning improves selection beyond that baseline and
whether pose/reroute examples provide harder useful tasks. Larger 65–128 facility
admission, required internal pipe trees, diverse unopened families and the final
300-case sealed suite remain separate unmet gates. Resolve the two zero-attempt
construction stops by examining frontier/group formation, not by lengthening runs.
