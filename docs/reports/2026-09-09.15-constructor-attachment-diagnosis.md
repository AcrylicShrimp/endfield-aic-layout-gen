# Large-factory constructor attachment diagnosis

## Result

The first failed medical-85 growth frontier exposes missing same-item crossing
support. The selected target cannot be reached through its existing physical belt
occupancy, even after removing all heuristic reservations. An eight-cell route
becomes available when a perpendicular same-item bridge is eligible. Candidate
eligibility alone does not repair construction: existing capacity and topology
validation cannot represent both same-item axes in one commodity network.

The controlled intervention returns paths in 4001 of 4096 trials, versus 166 in the
baseline, but commits no additional facility. This changes the next action from
longer search or more learning on the one accepted small root to a complete,
axis-aware crossing implementation. It does not establish that this implementation
alone will complete the 85-facility request.

The [stage contract](../designs/2026-09-09.15-constructor-attachment-diagnosis.md)
uses the original medical request at 1/6 output per second from
[report 14](2026-09-09.14-fresh-size-factory-transfer.md). Preserve its 85 facilities,
original wiring, external obligations, catalogs, 256 growth steps, 256 placement
attempts and 4096 searches. Each child has a 60-second deadline. These are diagnostic
resource bounds, not game limits. No request reduction or policy training occurs.

## Baseline and local geometry

A read-only instrumented release CLI reproduces the original complete construction
report exactly after removing elapsed-time fields: all committed nodes, decisions,
operation counters, final state and failure status match. This takes 11.263 seconds.
The target connection is iron powder from the third grinder instance to the first
enriched-powder thickener, at rate 10/21 per second. The retained incumbent covers
10 facilities; the first private placement contains 11.

The selected 4096 trial records contain 3868 failed routes with free endpoints,
53 reservation-only target conflicts, nine reservation-only source conflicts and
166 returned paths. Attachment pairs comprise 64 new/new, 219 new/existing and
3813 existing/new. Lane zero contributes 283 records and lane one 3813. Endpoint
reservation conflicts alone therefore do not explain the dominant failure.

In the first trial, the source connection is `(27,40)`, target `(28,34)` and routing
workspace 51x52. Independent directional BFS, including straight-only bridge
transitions and forbidden bridge endpoints, finds no route with either the actual
mask or physical occupancy alone. This is one concrete trial, not a proof about
all port choices or all facility placements.

The external bridge catalog admits 21 additional same-item straight cells after
checking terminals, installed components and both axis capacities. One is used:
`(28,38)`, on an existing horizontal iron-powder line. Its current 10/21 rate and
the proposed vertical 10/21 rate each fit the catalog's 1/2 capacity. The eight-cell
counterfactual route also traverses the already eligible different-item crossing
at `(28,37)`. Independent BFS and native A* choose slightly different first turns
but both return eight cells through the same critical crossings. These are routing
witnesses, not validated factory candidates.

## Candidate interventions

Both interventions keep all existing factory validators and commit rules. They
change crossing candidate generation in an isolated checkout, with original
production and learned-native binaries preserved.

The all-connection intervention changes earlier geometry and is not a controlled
comparison of the same first placement. Retain it as an unsuccessful broader
observation. The second intervention permits same-item crossings only in internal
routing for the explicitly configured edge. Its prior committed steps, final
retained node, first private node, physical occupancy, reservation mask, endpoints,
workspace and lane are identical to baseline. Its first A* call returns the
expected path where baseline returns none. Later search trajectories may diverge;
aggregate counts are outcomes, not paired trial-by-trial causal estimates. Timings
are single instrumented observations, not throughput benchmarks.

Selected-edge rejection reasons include 2502 cell-flow conservation/capacity
failures, 470 component-arm topology mismatches and 504 duplicate/opposing-arm
failures. These are aggregate report counts, not a complete classification of all
3826 boundary dead ends or a claim that each arose at the first crossing. The
source-level unsupported representation is independently visible:

- `network/crossings.rs` excludes the current item from all crossing candidates.
- `network/validation.rs` first caps aggregate incoming flow per coordinate; two
  10/21 axes sum to 20/21, above the ordinary belt capacity of 1/2.
- Component capacity is also checked against that aggregate. A bridge is then
  required to have exactly one input and one output per commodity network.
- Coordinate-based connectivity must also preserve independent axes; simply
  removing the capacity/topology checks could introduce false turns or flow mixing.

The accepted [mathematical model](../designs/aic-game-rules-mathematical-model.md)
describes straight independent bridge axes and per-axis capacity; the axis commodity
IDs may differ, so equality is allowed. The gap is between that accepted contract
and the current implementation. No new inference about unresolved game elevation
or other domain ambiguity is used to relax or prune anything.

## Next implementation and scope

Define a consistent channel representation or equivalent directional semantics for
both same-item axes. Candidate construction, capacity, component arm topology,
original-obligation routing and supply/demand reachability must agree. Cover two
independent same-item channels, unequal rates, one-axis overflow, forbidden turns,
terminal misuse and phantom reachability in regression tests. Keep distinct-item
crossings and existing factory cases valid. Then rerun this exact original request
and the failed fresh-size requests under the declared bounds; do not assume other
boundary obstructions disappear.

This diagnosis follows the constructive planner design: incremental connected
growth, private routed transactions and validated commits remain intact. The
standalone source patches are explicit research instrumentation and never become
a production fallback. No global exact model, custom propagator, new dependency,
production canvas constraint or changed pipe-first rule is introduced.

The wider learned-improver goal remains incomplete: accepted 65–128-facility
originals, broader relocation curricula, unopened diverse evaluation, required
semantics and bounded production CPU CLI still need work. Heavy Xiranite is not
rerun; its preserved dense incumbent remains `[2132,374,148]`, 41x52 and 30.5347%
empty XY. The requested 1% and visual target remains unmet. This is a concrete
implementation gap, not a verified fundamental barrier or global infeasibility.
