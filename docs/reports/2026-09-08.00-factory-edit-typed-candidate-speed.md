# Immutable Candidate Throughput

Status: verified and measured, 2026-09-08. Implementation: `3b60753`.

## Result

Replacing mutable candidate dictionaries with immutable commands reduces fixed-input total
candidate/observation/step time by 13.5–29.5% on the server. All 768 retained transitions
preserve every ordered external command, observation array byte, reward, and final state.
The selected command alone is serialized during training. The candidate DTO also carries
its current revision's geometry index; stale candidates are rejected. Obsolete dictionary
cache-key parsing and prefix feature caching are removed.

| Server replay, 256 commands each | Before seconds | After seconds | Reduction |
| --- | ---: | ---: | ---: |
| Initial | 0.223625 | 0.160330 | 28.3% |
| Late | 0.251460 | 0.217632 | 13.5% |
| Elongated | 0.433709 | 0.305748 | 29.5% |

Reference: `387727a`. Three alternating measured rounds follow warm-up. The local three-input
matrix also passes byte parity and improves by 15.4–18.8%. These remain four-facility probes.

## Complete server run

The same 100,898-parameter model, float32 CPU actor with 16 threads, CUDA learner, seed 17,
65,536 commands, 512 episodes, 4,096 Adam steps, and five 32-seed evaluations were retained.
Training took 76.5195 seconds versus 85.5213 previously; separate evaluation took 21.1660
versus 23.7361 seconds. This observed 10.5% training reduction is not an equal-trajectory
comparison: candidate exposure was 6,349,706 versus 7,705,035. CUDA numerical variation
remains permitted. The fixed-input replay supplies the controlled performance evidence.

Current non-overlapping costs are actor inference 22.0145 seconds, observation 17.2713,
candidates 8.5620, validation 4.5357, other environment step 6.5366, PPO update 12.0554,
actor snapshot 0.1563, and other training 5.3878. PPO includes batch preparation 2.4145,
forward/loss 2.8447, backward 4.6936, optimizer 1.7981, and residual 0.3045 seconds.
Peak allocated CUDA memory was 253.58 MiB and process RSS 2655.23 MiB; trajectory-dependent
shapes explain why these are lower than the preceding run, despite no memory-saving target.

No training episode or frozen evaluation earned positive area reward. The training champion
only reduced transport from 25 to 24 tiles at unchanged area 154, increasing turns to one.
Every frozen evaluation retained score `[154, 25, 0]`. Throughput is improved; learning the
known `[140, 21, 0]` witness remains unresolved. Independent audit passes all five layouts
and seven traces with no completion-counter discrepancy.

## Remaining actor probe

Fixed elongated observations show CPU batch-one/no-grad at 0.111820 seconds, CPU inference
mode at 0.148201, CUDA batch-one/no-grad at 0.122360, and CUDA batch-one/inference mode at
0.113648. Moving a single actor to CUDA or enabling CPU inference mode is not justified.
CUDA batch-two reaches 0.078591 seconds (0.073804 with inference mode), but requires a
separate two-environment collection contract and does not yet establish end-to-end benefit.
These probes include host preparation, completed forward/transfer, and action sampling.
No actor execution change is installed by this slice.
