## Boundary and arithmetic

`Engine.observe()` constructs the native candidate domain and returns an observation dictionary
plus a separate opaque handle. The dictionary contains only float32 raster/object/candidate/stats
arrays and int64 candidate points. NumPy receives ownership of native array storage; Python does
not rebuild layout DTOs, geometry, candidate features, coordinate channels or episode statistics.
`observe_candidates(handle)` remains an explicit diagnostic operation for an already inspected
domain. Handles never enter the neural inputs.

The raster reuses the draft domain index and builds the working-base index. Runtime-derived
object/category tables remain native. A bounded 4,096-entry LRU caches candidate features using
the typed command and any state-dependent absolute context. Array assembly copies cached rows
into independently owned output storage, so caller mutation and subsequent steps cannot change
past observations or poison the cache.

Object/candidate scalar normalization computes float64 division before float32 conversion.
Coordinate channels reproduce float32 `arange` increments and float32 scalar division. The actual
increment follows NumPy's documented cast-before-subtraction behavior, including zero or doubled
increments at large origins. See the [NumPy arange reference](https://numpy.org/doc/stable/reference/generated/numpy.arange.html).
No fused multiply-add substitution or coordinate-origin rebasing changes those values.

## Verification

All 768 retained initial/later/elongated actions match both a fresh independent Python observation
and the recorded rollout observation in every shape, dtype and byte. Candidate order, all transition
results, draft/base/best, traces, scores, episode counters, sort-cache counters and encoding-cache
counters agree. The same observation comparison now runs through the 1,024 seeded random edits,
scripted relocation/witness, escaped identifiers and restored partial episodes.

Boundary tests additionally cover all four rotations with bound ports, unbound rotated facilities,
negative coordinates, origins around both signs of 2^24 and beyond 2^53, array mutation/retention,
stale observation handles, and failed raster allocation guards. A failed observation leaves the
factory and episode accounting unchanged; its snapshot can be restored and the same structured
resource failure reproduced.

Snapshot testing exposed a separate confirmed issue: the default JSON floating-point parser
changed 138 of 1,000 generated positive timing values by one final bit on restore. Enabling
`serde_json`'s `float_roundtrip` feature fixes it. A regression test checks all 1,000 values and a
positive-reward episode trace through export/restore. This is a parser precision fix, not a change
to reward, learning arithmetic or the serialized snapshot schema.

Local release Python suite: 42 passed, three platform/CUDA skips. Workspace format/check/test
and artifact worktree/index checks pass. `array_export` measures native array-to-Python object
construction separately from native observation work; it does not claim to isolate every FFI
dispatch cost. No end-to-end speed or learned-quality claim is made before the final runner test.
