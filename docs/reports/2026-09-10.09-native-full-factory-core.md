# Retained native full-factory environment

Status: native environment milestone; normal PPO and fresh-generation caller
cutover is still pending. No post-cutover performance result is claimed here.

## Implemented boundary

`FullFactoryRuntime` loads the external catalogs once. `FullFactoryEpisode` owns
the accepted complete layouts, ordered candidates, bounded routing, selection
memory, observation buffers, history, scores and reward. Python receives owned
NumPy arrays and an opaque handle, then selects an index. A selected edit returns
compact trace metadata. Whole layouts are exported only for cold evidence.

The native port retains the existing pose/port/chain/component/strip domain and
pipe-first bounded routing semantics. It uses the existing production physical
acceptance authority. Even unchanged executor results consume a native proposal,
as they did before. The episode's earlier deadline is checked inside acceptance
before committing a validated layout.

This is simpler than the previous normal boundary: it removes the need for
per-action complete-witness JSON transfers, a Node executor process and Python
geometry/observation assembly. Caller cutover is required before those savings
can be measured in the real harness.

## Scope correction

The user challenged the growing implementation scope. Inspection of the actual
harness confirmed that it resumes published complete episodes and learner
checkpoints; it does not resume a native episode halfway through its actions.
Removed the newly added native snapshot import/export and restoration machinery,
its shared-core DTO and its dedicated tests. Preserve existing cold partial
experience/layout evidence and the existing harness checkpoint boundary.

The production constructor remains unchanged. This slice neither adds a global
placement/routing solver nor changes complete-factory acceptance, measured bounds
or the score priority in the constructive planner design and repository policy.

## Verification

- The explicit Node oracle matches 450 bounded A* cases and the crossing fixture's
  chains, ports, all ordered candidates in four vocabulary modes and their edits.
- The explicit Python oracle matches float32 spatial, graph and action buffers,
  action tokens, geometry ablation, contexts and histories for all 12 contracts.
- Continuous Python/native comparisons pass for 8-facility battery and 3-facility
  liquid factories: 12 contracts × 10 actions per factory, including array
  ownership, candidate order, masks, physical/ordered identities, status, route
  expansions and reward. The separate 59-facility extended matrix was stopped
  during the scope correction and is not reported as a passed check.
- Native unit tests reject foreign, stale, out-of-range and masked selections
  without charging work. The earlier-owner-deadline test verifies late validation
  cannot replace the accepted state.
- Rust formatting and workspace checking pass; workspace tests pass 541 tests
  with six explicit ignored tests. The separate six-test native oracle run also
  passes. The tracked-file worktree check passes.

Oracle tools are explicit standalone commands, not dependencies of collection.
Run `cargo test -p aic-pilot-native full_factory::tests -- --include-ignored`
with Node and the pilot Python environment available. Continuous comparisons use
`native_episode_parity.py --reference-root <frozen-reference> --library <extension>
--catalogs <catalog-paths.json> --case <case.json>`. Retained local results belong
under ignored `target/native-cutover/`; the frozen pre-cutover runtime remains in
the archived baseline evidence.
