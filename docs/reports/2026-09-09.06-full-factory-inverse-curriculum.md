# Full-factory terminal rejoining and inverse curriculum

Status: implementation, data admission and controlled learning complete. Inverse-task
learning transfers to related perturbations, but does not establish original-root
compression. The preceding goal turn made progress; this slice also makes progress.
Stages four and five remain open, including the original <=1% empty-XY goal.

## Why the prior movements could not be reversed

None of the five dense-root empty-region relocations from the preceding report had
its inverse in the default descriptor. Raising enumeration to 4096 scans and 256
candidates admitted only one. Directly executing the inverse of the other four
returned `local-terminal-collision`. The supported detachment could separate a
same-cell source/sink pair, but its direct rejoining was treated as a generic anchor
collision. This was an executor restriction, not an accepted game rule.

The [contract](../designs/2026-09-09.04-full-factory-terminal-rejoin-curriculum.md)
adds the inverse operation for a narrowly identified direct chain. Its uniquely
identified facility source and sink must each occupy a singleton typed anchor and
have one incident chain, with equal positive terminal/chain rates and no endpoint
component. The final typed slot must contain exactly those two terminals and no
component. Only those two original anchor identities may coincide. Other bodies,
anchors, external endpoints, third owners and carried paths keep their collision
checks. The old path becomes one shared cell and retains all identities and rates.

Static preflight recognizes the same single-group translation, and ordinary distant
vocabulary generation considers its exact terminal-alignment vector within the
existing candidate budget. No teacher-only action or candidate routing pre-evaluation
is introduced. Action/observation shapes remain schema two; source provenance records
the expanded executor revision. Historical runs require their recorded Git versions.

Three of the five measured inverses now occur in the default vocabulary and restore
`[2132,385,146]` under native acceptance. Candidate 132 still has an intermediate
bridge at `(30,35)` rather than one direct terminal-to-terminal chain; this slice
does not silently delete that bridge. Candidate 149 is a normal nonzero-path inverse
that the default finite destination scan misses; broader enumeration restores it.
These remaining restrictions are explicit, not evidence that reversal is impossible.

The shared rules now handle separation and rejoining within the same chain/movement
representation. There is no legacy move adapter, relaxed validator, alternate
factory request or production exact-solver fallback. Compared with the constructive
planner design, all changes remain bounded private edits of complete factories,
with pipe-first routing and complete native acceptance before best-state replacement.

## Controlled learning comparison

All pilots start fresh with seed 17 and width 32. Depth-zero original-root PG and
mixed-root/curriculum PG each receive 4096 selected actions in 128 updates of four
eight-action episodes. Mixed PG alternates an original-root group and a lesson
group while balancing the five root families. Rank objective, Adam .0003, entropy
.01 and norm clip .5 are common. This pair isolates curriculum starts.

Separate depth-zero and depth-two imitation pilots each receive 1024 single-lesson
cross-entropy updates over the same shuffled training order, Adam .0003 and clip .5.
They use the complete ordinary observation and action list; source-root geometry is
not passed as a hidden target feature. Both pay their own observation-cache setup.
This pair isolates relational depth. Cross-method PG/imitation comparisons have
different training work and supervision, so report their costs without claiming
matched sample efficiency or convergence.

Untrained depth-zero/depth-two, four final pilots and uniform selection each use
all 26 root inputs, banks 1250000/1260000, and four independent eight-action attempts
per cell with best retention. A single 30-second cell allowance includes resets,
observation, selection and recording. The root screen has 364 cells / 11648 selected
evaluation actions. Separately, 40 inverse validation lessons receive sampled and
greedy first-action tests for each method: 560 selections. Uniform's greedy rule is
the first tied candidate, not a second random draw. The overall screen guard is
1800 seconds. No inverse-task result substitutes for an original-root result.

## Verification and interrupted pilot

The local reembedding suite passes 97 tests, including both-owner rejoining, exact
path-cell removal, immutable inputs, rates, identity, branch/component/external and
third-owner negatives. The full-factory policy tests verify actual dense-root native
rejoining and group/destination gradients. One old test that expected an isolated
pair to collide is updated to the new contract and retains a mismatched-rate negative.

An initial pilot was interrupted before learning to finish the full local suite.
An anchor-graph fixture supplied chains without terminal metadata; eligibility now
conservatively skips that missing premise. The interruption also exposed shutdown
waiting while a large unread executor response filled its stdout pipe. Shutdown now
drains the owned worker before waiting and forcibly closes it only after its explicit
timeout. A million-byte response test covers the drain behavior. Both exact old
source variants and the initial partial run remain retained.

The corrected admission reproduces all 115 physical states, inverse actions and
inverse scores exactly. No seed, candidate budget, training allocation or learning
hyperparameter changed in response to outcomes. The completed comparison uses
`full-factory-inverse-curriculum-verified` and `full-factory-inverse-learning-verified`;
initial directories without that suffix remain historical partial evidence.

## Decision and remaining scope

Keep terminal rejoining and the admitted full-factory curriculum machinery. The model
can learn improving inverses; the next capability question is a sequence that releases
boundary space on an original dense root. Do not scale this same one-step teacher set
and call inverse restoration a substitute for that requirement. Compare a small
trajectory curriculum with coupled placement/port repair when retained ports block
the needed intermediate geometry. Reuse prior boundary/group diagnostics as evidence,
not as global impossibility proofs or as experiments to repeat unchanged.

The current descriptor permits distant moves and connected rigid groups, so lack of
any distant operator is no longer a valid diagnosis. It still bounds candidate scans
and route work, retains the current extent and has no external-terminal re-anchoring.
Their necessity for a successful compression remains unproven. Preserve the best valid
factory during exploration. New-family pipe/cycle learning and production CPU CLI
integration remain required; no fundamental impossibility is established here.
