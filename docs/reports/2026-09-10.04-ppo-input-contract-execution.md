# PPO execution across the twelve input contracts

Completed. Select CPU collection and CUDA FP32 learning with microbatch 64 for
the renewed input screen. Rich inputs preserve the reference behavior, and AMP
does not provide a consistent compute benefit on these representative workloads.

The optimized learner now accepts all twelve existing actor contracts. Actor
and critic retain their original separate parameters. A shared batching module
encodes exact raster shapes, independent graphs and per-world pooling; optional
actor worlds and causal histories no longer require individual model calls.
Geometry-only inputs omit graph messages and normalization. Empty histories
leave recurrent parameters without gradients. Padded histories use each real
endpoint, and absent operands retain their zero sentinel after graph offsets.

Collection builds the full critic observation once and derives the actor's
permitted view. History is recorded only when requested by that contract.
No-restore controls retain their explicit action-exhaustion failure. Direct
area rewards, valid temporary worsening, retained best witnesses, actual behavior
probabilities and native proposal validation preserve the original semantics.
Normal training does not replay observations, masks, rewards or whole updates.

The internal execution schema is `ppo-batched-input-contracts-v2`. The optimized
collector now requires an explicit candidate argument, and the standalone native
check requires `--candidate`. Historical frozen experiment sources remain
unchanged; the new execution path does not adapt richer inputs into action-only
observations. Actor and critic share world-batching code without sharing weights.

The fifteen PPO tests pass locally, including observation/mask hashes, reference
forward/gradient comparisons across all twelve contracts, mixed geometry/full
information, history lengths 0/1/20, meaningful recurrent gradients and explicit
no-restore exhaustion. The native tests use the rebuilt local release library.
`cargo check --workspace` and `cargo test --workspace` pass (538 tests, two ignored).

The native integration check deliberately audits initial/best geometry and saved
experience outside normal training. Each candidate runs two batches, each with
two native episodes and 64 selections. After the first update it saves nonempty
Adam and shuffle state, then compares the second update with continuation from
that checkpoint. All twelve candidates pass exact actor, critic,
optimizer, shuffle, credit and epoch-metric equality. Its second collected batch
is retained as an actual causal observation workload for device/AMP measurement.

A separate retained-workload check compares all 768 recorded actions with the
batched actor and critic at their actual behavior checkpoint. Maximum absolute
log-probability/value drift is 9.54e-7/5.96e-8. This check is a development command
and is never called by normal training.

All numerical screens pass and both optimizers step in every cell. BF16's
largest initial log-probability drift is 0.007946; FP16's is 0.001242. AMP resident
computation is consistently slower. Apparent combined-time wins for geometry
BF16 and rich FP16 come from lower preparation/transfer times, which do not use
autocast. These small, sequential samples do not establish a reproducible AMP
speedup. Use FP32 for all input contracts; no per-contract precision tuning.
