# Reuse movement indexes within a factory description

## Result

Large-factory description generation is **5.90 times faster** in the three declared
fresh-process samples: median 5.878 to 0.997 seconds, an 83.04% reduction. All ordered
non-timing description fields match the frozen baseline on fifteen cases, including
the complete 116-facility original and its four-contraction incumbent. Its 17,856
actions, 9263 poses, scan limits, order and rejection counts are unchanged.

The [contract](../designs/2026-09-09.19-factory-description-cost.md) preserves the
action domain and checkpoint bytes. Unlike the preceding graph correction, this
change does not remove any offered action. It makes repeated movement preparation
affordable enough for all three frozen controls to finish eight selections within
their existing 30-second allowance.

## Profile and implementation

On the original implementation, sampled self time includes 1538 ms in `movementPlan`,
1290 ms in `detachablePairs`, 542 ms in the per-chain cell intersection callback and
511 ms in repeated moved-coordinate lookup. These are repeated across hundreds of
preflights on the same witness. This is measured JS profile evidence, not an assumed
policy/model bottleneck.

`movementIndex` derives source terminal slots, detachable/joinable pairs, nonterminal
clusters, chain endpoints, source body cells and coordinate-to-chain membership once.
Translation and rotation enumeration each reuse their own index for one immutable
witness and chain extraction. Every candidate still owns fresh mutable movement,
collision and result sets. The helper rejects an index from a different witness or
chain extraction; callers must not mutate a witness during its indexed search.
There is no cross-state cache and no duplicated legacy movement implementation.

Only cells under moved anchors are visited, in their original network/cell order,
preserving first-failure diagnostics. Reverse cell membership replaces scanning
every route cell for each candidate's body/carried geometry. Changed chains are
then emitted in original chain order. Both transport layers remain affected by a
facility body; carried transport remains layer-specific. Standalone selected edits
use the same algorithm with a fresh index.

The subsequent profile shows 277 ms of movement-plan self time; the repeated
detachment and full-chain-cell scans no longer dominate. No further optimization
is justified before using the recovered time for large-factory capability work.
