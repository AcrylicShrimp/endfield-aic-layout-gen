## Intervention and accounting

Each case retains its exact 32-entry rehearsal-level multiset, 96 current episodes,
32 rehearsal episodes and setup work. Rotating each case's rehearsal order by its
position in the frozen case list reduces the largest same-stage group per update
from 14–16 cases to 2–3. The actual recorded schedules match the precomputed orders
in every branch. The first case has rotation offset zero; changes to its behavior
can still arise through the shared model's updates on other cases.

All 12288 training episodes and 25600 short-assessment episodes independently
replay. All 7168 root incumbents pass native/reference acceptance, and all 224
selected best/median root traces replay. Charged policy work is 196608 training,
409600 short-assessment and 917504 root commands: **1523712 total**, plus 15132
training and 3200 assessment setup commands. There are 12288 Adam steps. Total
wall time is 482.89 seconds; this is not a hardware throughput comparison.

The shared continuation helper now supports an explicit earlier-level order table,
leaves normal current starts unchanged, and derives root counts from actual rows.
The old sixteen-seed comparison retains its original behavior; this new sixty-four-
seed diagnostic does not inherit its old 256-episode accounting constant. No normal
training scheduler, policy objective or native game rule changes.

## Consequence

Gradient and advantage diagnostics identified synchronized rehearsal as a testable
hypothesis. This intervention does not establish it as the sufficient explanation
or a robust fix. Keep the original scheduler and avoid another full training matrix
based only on one improved pair or pooled success. No development or held-out
outcome bank was opened, and no policy is selected for production.

A useful next capability check is the already established bounded short-trajectory
restart inference on frozen entity policies: stage 3 used four 32-command attempts,
while this entity baseline uses one 128-command episode. These are different input
clock and state-reset procedures. Any comparison must first declare the frozen
checkpoint selection, include all relevant cases/seeds, preserve the total 128
commands and full score priority, and retain the current failed gates. It must not
be reported as a repair of ongoing training stability or silently used to replace
an unsuccessful result. No such inference comparison is run in this slice.

Stages 4/5 and the original 59-facility density/visual acceptance remain incomplete.
No fundamental impossibility is established by the bounded negative intervention.
