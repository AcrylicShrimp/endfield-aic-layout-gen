# Large-factory edits that expose area reduction

## Result

Seven of the 119 audited valid first edits from report 21 expose an ordinary
contraction on the complete 116-facility factory. Each of those seven trajectories
then improves area. The best moves **F100, F101 and F102 one cell west**, reroutes
their original obligations, and removes three newly available columns. Score changes
from `[58254,9925,697]` to **`[57456,9868,697]`**, or 219x266 to 216x266:
1.370% less area and 57 fewer transport tiles, with unchanged turns.

This is measured development teacher evidence, not learned policy performance. It
resolves the previous one-step screen's lack of area gains without changing the
operator vocabulary, native acceptance contract or score priority. The sole best
measured trajectory is 51, whose first action is parent contrast 132.

## Protocol and complete population

The [contract](../designs/2026-09-09.22-large-factory-contraction-continuations.md)
freezes all 119 completed valid first edits except insertions and restore-best.
It retains worsening and equal-score candidates. Every trajectory starts at the same
full original-graph state with zero ordinary contraction actions; parent report 21
separately charges its 108-step preparation. This continuation screen is separate
from the parent's 265 one-step trials.

Reexecute each first edit, then select the first ordinary contraction while one is
available, subject to five total actions, 30 seconds per trajectory, 5000 route
expansions per selection and 900 seconds for the study. Observation, edit and
validation costs are charged. Current state may explore a valid worsening edit;
the best validated incumbent remains preserved throughout.

All **119 trajectories / 128 selected actions** complete in **143.075 seconds**,
using 20,820 route expansions. All terminate with freshly described zero remaining
contractions. None reaches the horizon or time cap. The seven successful first edits
expose nine columns in total; all other first edits expose none.

## Verification and visual assessment

The independent audit reenumerates ordinary action membership and replays **every
one of the 128 actions**, checking original-request graph coverage, native physical
validity, independent complete metrics, current witness hashes, executor work and
status, and current/best score sequences. It checks exposed and final contraction
counts, the global best, and every retained best witness by first-action kind.
All pass. Parent first actions match their earlier status, work and exact witness.

The full before/after PNG and SVG are generated through native original-request
acceptance and the PNG is visually inspected. F100/F101 near the lower right and
F102 near the bottom move; column removal shifts the remaining geometry consistently.
Long external tails and the broad crossing structure remain. Empty XY is still
45,762 / 57,456 cells (**79.647%**), so this small area improvement does not establish
compact visual quality.

`cargo check --workspace`, `cargo test --workspace`, the native-backed full-factory
Python suite, the collection/audit CLIs and the view CLI pass. The initial Python
invocation used an unrecognized environment variable and correctly failed the
stale-default-build guard; the passing invocation explicitly sets `AIC_NATIVE_LIBRARY`
to the same frozen library used by collection. No Rust or production planner behavior
changes. The constructive design and production policy remain intact: all experiments
start with a complete valid factory and preserve a validated incumbent.

All complete traces, selected witnesses and the inspected view remain under ignored
artifacts. Best witnesses by first-action kind are intentional future references;
there are no obsolete intermediate candidate files. No training checkpoint changes.
The compact provenance manifest records source, configuration and retained evidence.

## Next learning decision

Use the measured four-action area-improving trajectory as the next large-state
learning target, with negative alternatives and the smaller-factory rehearsal needed
to measure retention. Compare against the parent checkpoint and deterministic
geometry policy under the same explicit selection and wall-time budgets. Measure
actual native-validated relocation and resulting area, not only target probability.
Keep this opened `enriched-consumables` train-family development case labeled as such;
its increased size does not make it a new held-out family.

The screen proves that the present move/route/contract vocabulary can improve this
specific contraction-exhausted state. It does not establish that a learned policy can
find the trajectory, that the grouping is globally optimal, or that all useful
continuations were searched. A five-selection limit and a finite parent action screen
are diagnostic bounds, not factory infeasibility or footprint constraints.
