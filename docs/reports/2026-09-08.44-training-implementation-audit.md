# Training implementation audit from four perspectives

Status: completed independent read-only reviews of PPO mathematics, normalization,
collection/evaluation, and environment semantics. The coordinator verified the
accepted findings locally and implemented two bounded corrections. Neither finding
is established as the cause of the current training regression. Frozen server
training sources and native libraries remain unchanged for the ongoing study.

## Confirmed and corrected

**Padded categorical sampling breaks per-episode RNG isolation.** Evaluation and
collection passed entire padded probability rows to `torch.multinomial`. Even
zero-probability padding consumes draws, so companion candidate counts affect the
seeded trajectory. Independent reproduction with random BN policy seed 97,
`case-relocation.json`, horizon 16 and sampling seeds 810000–810004 found 14, 14,
13, 14 and 12 differing commands between wave widths one and three before repair.
This does not bias each categorical draw or invalidate fixed-procedure outcomes.
It does invalidate stronger claims of companion-independent seeded trajectories.

Crop by the actual observation candidate count in `evaluation_batch.py`,
`curriculum.py`, `actor_benchmark.py`, and `collection_benchmark.py`. Do not infer
candidate count from nonzero probabilities: legitimate probabilities may underflow.
Restart evaluation already cropped its domain. New tests compare complete native
traces across wave widths 1/2/3/5, and compare sampled actions, log probabilities,
values and exact generator state with an enlarged companion domain over 16 draws.
Historical reports require their recorded source revision for exact reproduction;
new results must identify this sampling change rather than reuse old seeded claims.

**Duplicate action lengths are admitted.** The coordinator reproduced native and
reference parity with `segment_lengths: [1,1,2]`: after unbinding `battery:source`
in `case.json`, both exported 46 candidates containing two duplicate commands.
Identical selectable actions multiply semantic action probability without expanding
the domain. All 13 tracked configurations containing segment lengths use distinct
values, excluding this defect as an explanation of those existing runs.
Native and reference admission now reject duplicates in both length lists with
`input.config.duplicate_length` and the offending key. A parity test exercises
both invalid lists before an episode can begin. No legal unique-length domain or
production planner behavior changes.

## Reviewed concerns without a confirmed implementation defect

- PPO: randomized comparison of 1000 GAE cases against an independent scalar
  oracle has maximum absolute error approximately 3.4e-7; ten sign/clipping cases
  match the surrogate objective. No confirmed return, action mapping or clipping
  bug emerged. Passing these checks is not proof that optimization is stable.
- Normalization: calibration after updates follows approved design 08, and full
  checkpoint state is retained. A local zero-learning-rate probe preserves all
  parameters and reports optimizer KL zero while recalibration changes maximum
  log probability by about 4.29e-6 and value by 1.02e-4 on that fresh actor.
  Reversing sixteen synthetic calibration batches changes a running mean from
  7.853020 to 4.367449, confirming order sensitivity. Neither probe demonstrates
  corruption in the trained actors. Reported optimizer KL precedes calibration,
  leaving final-policy drift incompletely measured; this is a telemetry gap.
- Environment: binding feature cache keys include position context, canonical
  candidate ordering agrees, terminal roles remain represented, and incumbent
  promotion preserves the full lexicographic score. Area-only reward is documented
  scope. Discard restores the observed base, so omission of best geometry alone
  is not a demonstrated transition-state bug. Native/reference parity can share
  defects and is not an independent proof of all game semantics.

The [frozen weight/buffer intervention](2026-09-08.43-checkpoint-buffer-intervention-results.md)
provides stronger evidence about the selected regression than speculation about
normalization: old weights/new buffers retain 504 successes versus old/old 505;
new weights/new buffers fall to 454, and new weights/old buffers to 247. Measure
post-calibration deployment-policy drift and update stability before selecting a
new training intervention. Do not silently change the current capacity protocol.

## Verification and remaining risk

Verification passes: 123 Python tests (120 pass, three platform skips) with the
separately built corrected native extension; workspace check/tests; formatting;
and artifact worktree/index checks. A manual `run.py check` with the duplicate
configuration exits 1 and names `input.config.duplicate_length` and
`segment_lengths` through the existing CLI exception path. The historical local native binary remains intact
for saved diagnostics. The correction affects seeded comparisons going forward;
no retraining result or held-out improvement is claimed by this audit.
