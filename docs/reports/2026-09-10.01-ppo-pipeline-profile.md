# CPU profile of the completed PPO confirmation

The profile completed in 25.25 seconds on the retained seed-17 batch-8 workload.
It verified a 32-selection episode's physical trajectory, sampled actions and
actor/critic observations against the original experience. Collection profiling
includes episode execution and serialization; generation, checkpoint loading
and equivalence checks are outside that profile. Learner measurements use the
first shuffled 64-selection minibatch with the preceding nonempty Adam state.

| Measurement | Seconds | Interpretation |
| --- | ---: | --- |
| All 48 training collections | 1,414.87 | Original wall time, 24 workers |
| All updates plus duplicate reconstruction | 4,359.21 | Original wall time, one CPU thread |
| Representative collection episode | 5.000 | Instrumented diagnostic |
| Observation construction | 2.197 | Cumulative, 64 calls / 82 base encodings |
| Physical witness keys | 0.644 | Cumulative, 129 calls |
| Representative learner minibatch | 0.420 | Uninstrumented after warmup; one measurement |
| Same learner under Python profiling | 0.431 | Instrumented diagnostic |

Cumulative function times overlap and must not be added indiscriminately.
Observation construction accounts for 44% of this one instrumented episode;
it is not an estimate of 44% of total parallel collection wall time. Native RPC
and subprocess reads also matter. Serialization is smaller in this sample.

Learner backward consumed 0.225 seconds under Python profiling. The separate
Torch operator profile identified convolution backward (88.08 ms exclusive),
MKLDNN convolution (55.50 ms), matrix multiplication (45.92 ms) and affine
matrix multiplication (26.77 ms) as the largest operator costs. It also
recorded 12,702 fill operations and many small individual calls. Torch profiling
includes shape and memory instrumentation and is not a throughput benchmark.

The first optimization removes full duplicate update reconstruction, shares
actor/critic observation construction, reuses immutable physical keys, and
batches independent model work. Exact-shape raster buckets preserve GroupNorm;
disjoint graph and action membership must be preserved. See the
[execution contract](../designs/2026-09-10.02-ppo-batched-execution.md).
CPU/GPU and AMP comparisons follow that optimization, as requested.

Reproduce with the original isolated root and frozen confirmation:

```sh
python tools/factory-edit-pilot/profile_ppo_pipeline.py \
  --screen artifacts/factory-edit-pilot/ppo-area-comparison \
  --output artifacts/factory-edit-pilot/ppo-pipeline-profile \
  --seconds 600
```

The JSON report, Python profiles and Torch trace remain under the ignored
server artifact directory. A local report copy is also retained. The report
records source and workload hashes. No GPU or AMP timing was taken in this
profile. This is a focused profile of one admitted episode and one minibatch;
full-run original phase timings provide the broader context.
