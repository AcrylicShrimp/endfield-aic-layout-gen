Status: verified and measured, 2026-09-08. Implementation: `04656c3`.

## Controlled result

Prepare constant terminal/object features and port rotation offsets once from execution-loaded
catalog data. Each observation copies the read-only object template and fills current binding,
position, direction, placement, and rotation. No state/validation outcome is cached. This removes
repeated Fraction division, category lists, port scans and rotation arithmetic while preserving
all five owned observation arrays and external commands.

## Full server run and interpretation

The same 65,536-command allowance, 512 episodes, 4,096 Adam steps, model, float32 precision,
CPU actor and CUDA learner took **87.5185 seconds**, versus the preceding 76.5195 seconds.
This is an observed regression, not a full-run speedup. Candidate work rose from 6,349,706
to 11,384,992 candidates (79.3%) along a different sampled training trajectory. Observation
cost still fell from 17.2713 to 13.5443 seconds, while inference rose from 22.0145 to 28.9930,
candidates from 8.5620 to 12.4660, and PPO from 12.0554 to 15.3405 seconds. Fixed-input
replay isolates the code improvement; equal seeds do not isolate full-run performance here.

Separate evaluation took 19.9991 seconds. Two training episodes found positive area reward;
the retained champion is `[147, 24, 0]`, but all frozen evaluations still earned zero reward
and retained `[154, 25, 0]`. Discovery is not evidence that the frozen policy learned the edit.
Peak allocated CUDA memory was 770.927 MiB and process RSS 3035.621 MiB. All five layouts and
seven representative traces pass independent audit with no diagnostic-counter differences.

## Compiled actor investigation

`actor_compile_benchmark.py` uses `torch.compile(dynamic=True, fullgraph=True)` on the existing
CPU model. Every retained dynamic observation and an explicit weight refresh pass numerical
comparison (`atol=rtol=1e-5`, maximum absolute difference 1.526e-5). No parameters or layers change.
The elongated fixed-input median is 0.126335 seconds eager versus 0.103114 compiled per 256
commands, an 18.4% steady-state reduction. First wrapper/compile/execution costs 10.8345 seconds.

At that observed rate, cold cost amortizes after roughly 119,444 commands; extrapolation assumes
no additional compilation and similar shape/work mix. The user explicitly prioritizes long-run
throughput and accepted this setup cost. The next slice will install a measured compiled actor
path, charge initial and subsequent compilation, and check a longer complete training run.
Compilation is not enabled by the observation-table slice itself.
