# Same-item bridge channels and the first accepted large factory

## Result

The production constructor now completes the original 116-facility medical request
that previously stopped at 20 facilities. Its complete original graph and geometry
validate independently. The layout contains 603 bridges, including **90 same-item
bridges**, with both rates conserved and checked separately per axis. This provides
the first accepted 65–128-facility original for the learned-improver work.

The [contract](../designs/2026-09-09.16-same-item-bridge-channels.md) realizes the
existing independent-axis rule isolated in [report 15](2026-09-09.15-constructor-attachment-diagnosis.md).
No supply, recipe, rate, external obligation, facility count or production canvas
limit changes. This is a capability and input-admission result; it is not a learned
improvement, compact layout or universal constructor success.

## Internal cutover

A bridge now contributes two internal graph vertices at one physical coordinate.
The vertex key includes its horizontal/vertical axis; ordinary cells still use one
vertex. This identity is derived from existing directed segments and installed
components, so the physical DTO and one-network-per-commodity contract remain intact.

Construction permits same-item crossing candidates. Independent validation conserves
positive flow and checks line/component capacity per channel, requires exactly two
perpendicular straight channels globally, and rejects terminals, overlapping owners
or malformed arms. Indexed supply/demand coverage and its independent segment-scan
test oracle retain axis identity. A balanced circulation that only crosses a supplied
line no longer appears connected to that supply merely through a shared coordinate.

Shared attachment paths cannot turn between bridge axes or use a bridge as a branch
anchor. Their residual capacity uses each traversed axis. Ordinary splitter/converger
capacity still uses aggregate flow. Native and independent JS metrics count one
physical layer tile and no cross-axis turn. Scores of previously valid legacy
layouts remain identical; there is no metric conversion or claimed artificial gain.

The learned editor's JS bridge topology view, released-chain extraction and crossing
installation now support one network owning both axes. Release follows the original
straight channels, reembedding can install a same-item bridge, and its component ID
is recorded once per owning network. The old distinct-item-only filter and
coordinate-only graph identity are removed without adapters or synthetic item aliases.
The resulting design represents two channels directly instead of assuming two
commodity-network owners.

The constructive planner design remains satisfied: connected incremental growth,
pipe-first dedicated routing, existing private transactions and original acceptance
rules. No global exact fallback, new dependency or custom propagator is introduced.
