# The recent learner is imitation, not reinforcement learning

## Confirmed implementation and correction

The latest completed training, report 25, uses supervised best-action imitation.
It does not update the policy from rewards obtained by new on-policy factory
rollouts. Describing its results as evidence that reinforcement learning cannot
learn factory layout is incorrect. User-facing explanations failed to maintain
this distinction; this report corrects the interpretation before another training
intervention.

The actual objective in `full_factory_best_learning.py::best_mass_loss` is

`L(theta; s, T) = -log(sum(a in T) pi_theta(a | s))`.

Here `T` is a stored set of selected demonstration actions, including tied targets.
`full_factory_large_learning.py::run` retrieves those targets from its observation
cache, differentiates this loss, and applies Adam. Environment scores were used
offline to select the targets. They are not sampled returns in that update. Later
evaluation rolls out a frozen policy with gradients disabled.

Report 25 contains 53 training states and 56 target actions across eight starts:
six small factories and prepared/raw versions of one larger factory. It runs 1024
supervised updates for each of seeds 17/29. Reports 26/27 are frozen evaluations.
Report 28 only collects teacher trajectories. No subsequent model has been trained.
The drafted architecture comparison and longer-teacher intervention have not run.
They must not be presented as RL progress or as evidence about RL impossibility.

There were earlier actual policy-gradient experiments. Report 03 uses terminal
lexicographic ranks and entropy regularization, four eight-action episodes per
update, 1024 selected actions and only 32 rank updates per actor. Report 08 also
compares policy-gradient and imitation arms explicitly. Its root-PG actor has
1 win / 50 ties / 1 loss against initialization on 52 paired cells; 17 of its 32
rank groups have identical terminal best scores. Mixed PG has 0 / 52 / 0 and 12
flat groups. These are small, weak-signal experiments, not a proof that a different
RL objective, exploration process, training allocation or architecture cannot work.
See [report 03](2026-09-09.03-full-factory-policy-screen.md),
[report 08](2026-09-09.08-full-factory-compound-pose-learning.md) and
[report 13](2026-09-09.13-full-score-action-learning.md).

## What the evidence does and does not establish

Some supervised behavior is learned. Report 25 raises the designated large initiating
pose's probability from approximately `1.15e-9` in its parent to 0.999841/0.999968,
and both policies execute productive prepared-large paths. Both recognize all six
small initial targets. This contradicts a claim that no parameter learning occurs.
It does not establish the intended sustained rearrangement or transfer capability.

Exact small follow-up target recognition is only 17/42 and 15/42; some differently
ordered contractions reach the same or better complete score. A missed recorded
teacher action is therefore not automatically a behavioral failure. Conversely,
high first-action target accuracy does not establish a successful whole rollout.
Reports 26/27 contain no productive new-factory pose transfer despite valid physical
compression. Report 28's best demonstrations each start with one relocation and at
most five contractions. None demonstrates the full requested compact layout.

The following implications have not been proved:

| Claim needed for the full goal | Current evidence |
| --- | --- |
| A valid original Heavy factory can have at most 1% empty XY | No witness or impossibility proof; best retained incumbent is 30.5347% empty |
| Available ordinary edits and practical horizons can reach such a factory | Local valid moves and short improving paths only |
| Current observation/model class can represent a useful long-range policy | Some learned examples; no general representability result |
| Current optimization reliably finds that policy | Recent updates optimize imitation, not on-policy return |
| Learned decisions remain useful on states reached by the policy | Some short known-root paths; fresh pose transfer absent |
| The behavior generalizes to diverse whole factories | Valid contractions transfer; sustained rearrangement does not yet |

Also, minimizing used area and minimizing empty fraction are different objectives.
Empty fraction is `1 - occupied_xy / used_area`; changing area can also change
occupied XY. The configured lexicographic score remains area, physical transport
tiles, then turns. No training change may silently replace it, and minimizing that
score alone is not a proof of the separate 1% acceptance criterion.

## Bounded exact-input obstruction check

Run a read-only diagnostic on all 53 audited report-25 lesson observations. Verify
their frozen witnesses, original/current/best contexts, native admission, ordinary
action targets and source hashes. Check identical full input tensors with disjoint
target sets. Within each observation, check action pairs with identical action
features, operand indices, raster lookup position and unordered pose-member
descriptors. Such equal readout inputs necessarily produce equal logits for every
parameter setting of the current model.

For an alias class of size `m` containing `q` targets, its assigned probability
contributes at most the fraction `q/m` to target mass. The maximum such fraction
across classes bounds the attainable target mass under these equality constraints.
This can demonstrate a positive loss floor, but does not characterize all possible
GNN/readout expressivity limits.

The diagnostic completes in **12.215 seconds**. It checks 237441 candidate-action
rows across 53 observations and finds **zero duplicate observations, zero detected
action alias classes and zero detected positive-loss-floor lessons**. This rules
out only these sufficient exact-equality obstructions in the inspected lessons.
It is not proof that the fixed-width network can fit them, that gradient descent
will fit them, or that the full task is learnable with current inputs and resources.
It adds no training labels, performs no optimization and opens no future factory.

```sh
tools/factory-edit-pilot/.venv/bin/python tools/factory-edit-pilot/full_factory_learnability_audit.py \
  --screen artifacts/factory-edit-pilot/full-factory-trajectory-retention \
  --output artifacts/factory-edit-pilot/full-factory-learnability-audit
```

The three new focused tests cover a forced probability ceiling, member-permutation
equality versus changed member correspondence, and input hash sensitivity. All
52 native-backed full-factory Python tests pass. Workspace check and 538 Rust tests
pass with two existing ignores. No policy, optimizer, runtime or game-data changes.

## Theoretical interpretation and next decision

Ordinary supervised prediction guarantees do not automatically transfer to a
policy's own state distribution: its predictions change later inputs. DAgger
studies this problem and gives guarantees under explicit additional assumptions,
including access to suitable expert feedback. It does not show that every short
demonstration dataset suffices, or that every imitation method must fail.
[Ross, Gordon and Bagnell, 2011](https://proceedings.mlr.press/v15/ross11a.html).

More recent analysis gives stronger behavior-cloning guarantees with logarithmic
loss under controlled cumulative-payoff range and policy-class learning complexity.
Thus a blanket theoretical rejection of imitation is also unjustified. Those
conditions and useful expert behavior have not been established for this factory
experiment. [Foster, Block and Misra, 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/da84e39ae51fd26bb5110d9659c06e13-Abstract-Conference.html).

Finite-depth message passing also has expressivity limits. In the current graph,
facility/terminal/cell/network incidence spans three edges while the retained policy
uses two message layers. Global pooling still receives network information, so
this observation alone is not an impossibility proof for the combined raster/graph
policy. A capacity-matched architectural experiment can test usefulness, but cannot
repair a mislabeled training objective by itself.
[Xu et al., 2019](https://arxiv.org/abs/1810.00826).

The immediate corrective step is to establish an explicit RL contract and inspect
its actual reward/return, sampling distribution, credit assignment and gradient
path. On a small complete-factory diagnostic, verify that reward-dependent policy
updates occur without action labels; distinguish return-driven updates from entropy
updates when all returns tie. Then test delayed-reward sequences, sustained rollout
and fresh transfer with matched budgets. Any imitation warm start must be labeled
as such and separated from subsequent RL evidence. Do not treat positive immediate
reward as a required action label: RL may credit a temporarily worse action through
later return.

Longer demonstrations alone are not the next corrective claim. Retain the existing
validated incumbents and checkpoints, and do not infer a fundamental blocker until
a separating test identifies one. Original Heavy Xiranite's 1%/visual criterion and
bounded production CLI remain incomplete.
