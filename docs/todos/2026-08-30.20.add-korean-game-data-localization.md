# Add Korean Game Data Localization

Status: In progress

## Context

Recipe source choices currently expose stable IDs only. The web-facing workflow needs official Korean names for materials, facilities, and modes, plus official formula descriptions for recipes.

## Completion Criteria

- Vendor the pinned item and building-item relationship tables needed for name joins.
- Vendor the relevant Korean text-ID dictionaries with provenance and checksums.
- Generate a deterministic schema-versioned Korean localization catalog.
- Validate complete item, facility, mode, and recipe-description coverage.
- Expose localized contextual recipe source choices through the CLI.
- Manually verify the Heavy Xiranite source-choice report in Korean.
- Pass formatting, workspace checks, tests, and Clippy.
