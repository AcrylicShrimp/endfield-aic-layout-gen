# Fixed-placement wiring probe

## Status

Complete: first fixed-placement routing slice implemented, validated and measured. Follow-up
path-preservation/relocation research remains separate. North-branch baseline is `bf698ee`.

## Contract before implementation

- Separate explicit diagnostic binary; production APIs must not call this whole-placement workflow.
  Read frozen facility geometry, original logical requirements and runtime catalogs; project ports
  again from the catalog instead of trusting visualization port records. Validate identities,
  geometry and positive rates. Do not silently relocate or rotate facilities.
- Route internal belts before internal pipes. Within each layer, first try unobstructed straight,
  opposed, unused port pairs, then bounded alternate port pairs/A* detours on the frozen geometry.
  Keep external requirements explicit and pending; do not announce factory completion.
- Reuse the existing commodity-network engine, shared attachments, capacity/junction/crossing
  handling and independent witness validator. Do not introduce a simplified second physical model.
- Treat each connection as a private candidate. Search one port pair at a time so unselected port
  alternatives are not mistaken for assigned reserved corridors. Reject invalid witnesses and
  candidates that destroy a previously available pending boundary domain; preserve the old witness.
  A nonempty port domain is not proof of a complete route or sufficient simultaneous capacity.
- Preserve every logical requirement; continue other independent connections after a bounded
  failure. Report direct successes, detour successes, searches, validation/availability rejections,
  unresolved identities and timing. Every committed covered-route witness must independently validate.
- Search padding/cell and route-call limits are diagnostic resource bounds only. Failure within
  them is not global infeasibility. Report frozen coordinates and explicit search-only translation.
- Publish routes and failed logical requirements distinctly over the same facility placement.
  Inspect first failures before introducing local relocation: that is the next separable milestone,
  not an automatic global re-placement fallback.
