# Add Directional Facility Ports

Status: Complete

## Context

The exact placement backend can rotate rectangular facility footprints, but logistics routing needs explicit input/output port geometry. Public game tables expose footprint and port metadata that can be represented without embedding game-balance data in application code.

## Completion Criteria

- Define a versioned facility port DTO for belt and pipe inputs and outputs.
- Validate stable IDs, per-facility uniqueness, footprint bounds, and edge alignment.
- Document canonical coordinates and rotation transforms.
- Update example data through a hard schema cutover.
- Preserve the current placement behavior until a routing stage consumes ports.
- Pass formatting, workspace checks, tests, Clippy, and the placement CLI smoke test.
