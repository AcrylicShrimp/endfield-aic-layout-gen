### Port-preserving path retry contract

- For pending same-layer domains on other facilities consisting only of currently unused ports,
  preserve at least one connection cell, not every alternative or a three-cell escape corridor.
- If a generated path covers every still-free candidate of a protected domain, branch on avoiding
  one of those cells and retry the same port pair. At most eight path variants per attachment pair;
  all variants spend the existing shared 64-A* requirement budget. No unbounded route search.
- Domain guards are geometric heuristic witnesses, not a routing/capacity proof. Existing-network
  domains and domains on the current endpoint facilities still rely on full post-hoc validation.
- Record conflict requirement and avoided cells per physical search. Keep atomic multi-lane commit,
  all existing independent validators and the original production assigned-port path unchanged.
