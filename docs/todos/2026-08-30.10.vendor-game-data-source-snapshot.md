# Vendor Game Data Source Snapshot

Status: Complete

## Context

The project will keep game data in the repository and update it deliberately when the game changes. Source facts must remain external runtime data rather than Rust constants.

## Completion Criteria

- Store the source tables needed for facilities, modes, recipes, items, belts, and pipes under `data/game/source/`.
- Record the exact upstream commit, timestamp, snapshot date, and per-file hashes.
- Distinguish extracted data licensing from the source-code license.
- Document the update and normalization policy.
- Keep mode flattening out of the source snapshot.
