# Multi-step layout reinforcement learning

Status: complete. Delayed-credit mechanism demonstrated; general learned superiority not established.

## Context

The CPU one-step bandit demonstrated learning but did not beat screened geometric proposals.
The user requested a new goal testing long-term modification strategies, CPU parallelism,
and starting layouts from both the earlier closure generator and the recent chain constructor.
See [the experiment contract](../benchmarks/layout-rl/contract.md).

## Completion criteria

- Import and freshly validate full generated roots from both generator generations.
- Implement private nonmonotone trajectories with a separately preserved valid incumbent.
- Verify terminal credit, exact lexicographic comparisons, budgets and independent validation.
- Compare learned, myopic, greedy and nonlearning search under matched work and real time.
- Test temporary-deterioration paths and distinguish existence from local necessity proofs.
- Measure environment workers and learner threads; report bottlenecks, negative results and limits.
- Record reproducible evidence, audit final witnesses, run regression/workspace checks and commit.
