# Add Port-Aware Placement Boundaries

Status: Complete

## Context

Footprint-only placement can put a facility against the layout boundary while one of its ports faces outward, producing an unusable connection cell. Equal rectangle geometry also no longer means equal rotations after directional ports exist.

## Completion Criteria

- Retain every allowed rotation as a distinct solver orientation.
- Derive boundary clearance from rotated port edges.
- Constrain every port's adjacent connection cell to the hard W/H area.
- Prove with a square-facility regression that the solver can select `180` instead of collapsed `0` geometry.
- Keep full route selection deferred to the integrated routing model.
- Pass formatting, workspace checks, tests, Clippy, and CLI regression.
