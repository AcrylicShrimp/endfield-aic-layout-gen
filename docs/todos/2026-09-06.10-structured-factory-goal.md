# Structured complete-factory goal

Status: active. This is the full requested end state, not a local-interface completion claim.

Required milestones:

1. Plan split/merge/crossing structures at placement level from runtime recipe requirements.
2. Build only required, compact geometry; prefer recipe-independent reusable algorithms.
3. Generate the complete heavy-xiranite graph with independent validation and reasonable space.
4. Repeatedly inspect actual rendered output and improve correctness, time and footprint.
5. Validate additional complex recipes after heavy-xiranite quality is established.
6. Then remove obsolete experimental code and retain the necessary implementation/evidence.
7. Prepare and implement a web workflow accepting recipes and production targets and generating
   layouts. Do not count a static diagnostic page as this service.

Keep proven generation stable while testing alternatives. Local CP/SAT and global optimization
are permitted when scoped and sound; no minimum-area claim without proof. Profile and parallelize
useful independent work. No Rust migration until experimental efficacy warrants the collected cutover.
Inspect rendered images at every milestone. Stop only for a genuinely fatal unresolved problem.

Current slice contract: shared-trunk interface geometry

- Keep exact recipe/bucket allocations and external-boundary semantics.
- Place source vertical trunks in reverse source-port order. Reserve target leaf rows below
  all source roots. Each trunk branches at the selected consumer leaf rows, instead of expanding
  every leaf through a serial permutation rectangle. Merge compatible leaves with catalog-aware
  three-way trees.
- Derive crossings from those preplanned orthogonal trunk/lane intersections; do not run free
  routing or introduce crossings at turns, terminals or split/merge cells.
- Compare this candidate with the validated leaf-template family. Choose only independently
  validated, complete candidates by used area, physical tile count and turns. Preserve diagnostic
  failures and do not discard the working family solely because a new family appears promising.
- Apply the result to actual heavy-xiranite topology/margins, including explicit unresolved pipes,
  cycles and external obligations. A set of isolated successful interfaces is not a full factory.
