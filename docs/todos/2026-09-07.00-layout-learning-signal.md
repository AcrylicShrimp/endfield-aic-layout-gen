# Layout learning signal and CPU efficiency experiment

Status: complete; experiments, fresh audits and feasibility verdict recorded.

## Context

The user authorized a modest first learned-layout experiment: determine whether automatically
generated training data/rewards cause learning and measure efficiency, without requiring
strong layout quality. Python training is authorized, managed with uv, and PyTorch is preferred.
An RTX 5090 may be provided later; first measure CPU behavior and the actual bottleneck.

## Completion criteria

- Follow the [stage contract](../benchmarks/layout-learning/contract.md).
- Preserve production and the four pre-existing unrelated dirty paths.
- Generate externally backed, independently checked local-layout data with split hygiene.
- Compare fixed-seed normal/shuffled/zero-signal learning and nonlearned controls on held-out data.
- Measure generation, training and inference separately; audit selected actions freshly.
- Record limitations, verification and findings; commit the completed experiment.
- Address the subsequent explicit goal: evidence-backed CPU/user-quality feasibility verdict
  and inspect machine-readable community blueprint sources, especially Chinese sources.
