# R1-direction: fixed facility flow orientation

## Status

Complete as an opt-in experiment, not adopted as the default. User requested a fixed global
input-to-output direction after inspecting the rotated furnace/grinder conflict.

## Contract before implementation

- Optional request `flow_direction` / CLI `--flow-direction north|east|south|west`, default absent.
  The first measured direction is east (left-to-right material flow).
- Derive one legal rotation per required facility instance from runtime catalog port geometry and
  original incident demands. Maximize the number of required output transport/item groups having
  a port on the flow side, then required input groups having a port on the opposite side; break
  ties by the smallest legal rotation. Count groups, not arbitrary numbers of duplicate ports.
- Port assignment within a fixed rotation prefers the corresponding flow-facing output or
  upstream-facing input face, retaining existing capacity-grouped allocation and port variants.
  Prefer aligned faces before variants, so variants do not defeat the global direction preference.
- Some facilities have perpendicular required belt/pipe outputs. Report chosen rotation and the
  aligned/total output/input groups. This is orientation guidance, not joint capacity feasibility
  or a claim that all ports or all routes point along the axis.
- Keep the chosen rotation for seeds, SCC/private dependency groups, nearby and coarse escape poses.
  Do not silently retry another rotation. Keep existing pose locations, graph order, score, validation,
  future-interface policy and per-transaction resource caps. Spatial stage ordering is not added.
- Absent direction preserves previous witnesses and search choices. Request schema 1 is additive;
  report schema 2 adds orientation decisions. Missing legal rotation gives a structured input failure.
- Retain explicit partial/failure results and complete baseline. This restriction is heuristic,
  not a game rule or global infeasibility proof. External terminals still complete in the final stage.
