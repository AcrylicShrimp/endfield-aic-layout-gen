# Add Integrated Placement and Routing Model

Status: In Progress

## Context

Footprint-only placement cannot prove that logical item flows can be routed. The solver must bind facility positions, rotations, ports, and grid paths in one constraint model.

## Completion Criteria

- Define the integrated stage input, output, invariants, diagnostics, and target constraint mapping.
- Implement the first single-edge facility-to-facility integrated solve.
- Use hard maximum width and height during candidate generation.
- Derive route endpoints from selected rotated facility placements.
- Enforce flow conservation and facility-route exclusion in the solver.
- Minimize route length and return an ordered path.
- Reject unsupported inputs explicitly.
- Pass formatting, workspace checks, tests, Clippy, and a manual executable regression.
