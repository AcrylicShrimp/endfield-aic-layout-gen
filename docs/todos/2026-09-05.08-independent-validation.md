# M3: independently indexed witness validation

## Status

Complete. Baseline `57904fa` release binary preserved before edits. M3 only.
Evidence: [measurements and slice report](../benchmarks/constructive-independent-validation/report.md).

## Contract and measurement gate

- First instrument the unchanged validator with grouped setup, cell occupancy, segment flow,
  terminal, topology and reachability spans. Measure release Heavy Xiranite before selecting a
  rewrite. Preserve every check, check order and first failure diagnostic.
- Inputs remain the immutable concrete node and validated runtime facility/transport/component
  catalogs. Output remains exactly `Ok(())` or the same structured first diagnostic.
- If reachability dominates, build forward/reverse adjacency locally from the already checked
  witness cells and segments, then independently check supply-to-cell and cell-to-demand coverage.
  No index from construction, cached validity, prior validation flag or route-search state is trusted.
- Preserve the existing circulation policy: each cell must be reachable from a supply and able
  to reach a demand. Disconnected circulation is invalid; do not strengthen this into a new
  acyclicity or per-commodity optimization rule. Validate positive rates, adjacency, membership,
  duplicates, flow, terminals, components and bridge axes in their existing order.
- Any index lifetime is one validation call/network, uses O(V+E) sparse topology storage and no
  world-grid canvas or new W/H constraint. Retain the old traversal only in differential tests.
- Optional aggregate work counters and subspans extend profile schema 1, do not change planner
  budgets, and distinguish index construction from traversal and other validation checks.

## Completion criteria

- Record pre-change suboperation timing and an evidence-backed optimization/defer choice.
- Compare exact diagnostics on valid and deliberately corrupted chain/branch/merge/crossing
  witnesses, including rates, duplicate arcs/cells, port geometry, components and disconnected
  circulation. Controlled external graph fixtures cover forward/reverse directed reachability.
- Five paired unprofiled release runs plus separate profiles on full and small workloads, same
  inputs/budgets/full JSON+HTML; no compiler/test overlap. Record median/range, memory, input/binary
  hashes, identical accepted nodes and search choices, and the next demonstrated hotspot.
- Run fmt, workspace check/tests and manual CLI verification. Preserve independent final validation
  and original-wiring auditing. Update the roadmap and commit this verified slice separately.
