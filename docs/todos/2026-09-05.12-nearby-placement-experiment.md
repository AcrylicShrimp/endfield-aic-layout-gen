## Stage contract before implementation

- Input: immutable validated growth node, new facility, connected anchor, runtime catalogs, existing
  per-growth placement/A* budgets, and optional `nearby_candidates` request/CLI setting (0..=8).
- Zero retains the current coarse candidate sequence. Positive values try a bounded shortlist of
  nearby poses and compare up to that many successfully routed/validated candidates. Keep coarse
  poses as explicit escape candidates if the nearby shortlist yields no valid candidate. Start
  opt-in; adoption depends on measured completion, quality and runtime, not appearance alone.
- Generate deterministic cardinal-side/edge-aligned poses around existing facilities, with several
  small heuristic gaps and legal rotations. Filter occupied footprints, rank by prospective bounds
  and distance to the connected anchor, deduplicate, and bound actual nearby route trials. No
  caller W/H ceiling, global facility placement phase, global exact fallback or rule relaxation.
- Each trial clones the same incumbent, places one facility, immediately connects required edges,
  and runs existing independent network, future-boundary and original-wiring checks. Atomic-cycle
  members remain private until the full group validates. No parallel candidate winners.
- Compare actual routed candidates lexicographically by used area, unique physical layer cells,
  then existing route-turn semantics. Only retain the best candidate; equal scores retain earlier
  order. This ranks alternatives to the same growth, not an improvement pass over the old factory.
- Every tried placement and A* call, including discarded alternatives, consumes the existing
  operation budgets. Bound scoring/shortlist memory and report aggregated selection evidence by
  facility attempt: valid candidates, first/best score, selected pose and termination reason.
- Request schema 1 gains an optional default-zero field; production report schema 2 gains additive
  selection diagnostics. No unrelated report/history migration. Full JSON and HTML remain files;
  stdout remains one short completion. Invalid limits produce structured input diagnostics.
- Local exhaustion returns the last validated state and structured failure; it is not infeasibility.
  A compact partial graph is never reported as better than a complete baseline factory.

  catalogs, seeds, budgets and output mode. Record complete coverage, area, physical tiles, turns,
  attempts/A*, selection diagnostics, time and RSS. Keep failed trials as evidence.
- Repeat promising configurations without compilation/test overlap. Inspect actual resulting

- Run formatting, workspace check/tests and relevant manual CLI commands. Keep original remote

- Update roadmap/report and commit the verified experiment as one focused milestone.
