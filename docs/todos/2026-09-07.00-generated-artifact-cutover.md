## Context and contract

The user requested that regenerable benchmark outputs stop being committed. Human
findings, decisions, source code, reproduction configuration and minimal independent
inputs belong in Git. Non-regenerability alone does not justify an oversized file.

Input: the tracked tree at `e31b97a`, plus the separately preserved source overlay.
Output: a source-only benchmark tree, ignored local historical outputs, independent
test inputs, updated executable references and a small maintenance report.
No training restart, solver redesign, game-data changes or Git history rewrite.

## Completion criteria

- Classify benchmark payloads; remove raw JSON, generated views, logs and compressed
  run archives from tracking while keeping necessary authored input/configuration.
- Retain only minimal, documented fixtures where tests depended on execution reports.
- Resolve active consumers to source fixtures or explicitly external run artifacts;
  do not silently fall back to historical files in the source tree.
- Preserve historical conclusions and reproduction instructions without embedding raw
  data or creating another oversized migration manifest.
- Add a verifiable tracked-file size/artifact check, including documentation limits.
- Check references, run affected tests and workspace verification, then commit only
  this work. Preserve unrelated changes and report any remaining limitations.
