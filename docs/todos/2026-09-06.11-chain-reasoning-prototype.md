# Chain-reasoning prototype research

Status: active; milestones 0 and 1 complete, milestone 2 next. This is the current user-authorized prototype goal,
not a continuation of the paused breadth experiment or a production cutover.

## Context and objective

The user requested a new, separate prototype based on their demonstrated layout reasoning,
developed in small stages. When a stage fails, revisit the examples and the interpretation of
the patterns before adding complexity or enlarging search. The native Codex goal tracks the
full objective; this file records repository evidence, completion gates and the activity log.

The [completion research](../benchmarks/user-layout-reconstruction/completion-research.md)
demonstrated a partial-area ranking reversal on frozen screenshot-inferred geometry. It did
not implement a constructor or establish a complete factory optimum.

## Milestones and completion criteria

0. Reference and stage contracts. Validate rate-correct battery, citron-powder and enriched-iron
   internal references with explicit missing external margins. Preserve observed facility counts,
   use exact per-facility utilization and per-route rates, and do not claim screenshot operation.
   Establish a separate prototype interface and distinguish reference poses from generated poses.
1. Routed straight and bent chain growth. Construct from catalog-backed graph data without
   screenshot coordinates. Compare rotation, bend and interval proposals. Each added facility
   must be connected, routed and validated before the next growth step. Record rejected choices.
2. Seed cycles and branches. Grow an atomic cycle or approved closed dependency group privately,
   with each facility/connection routed incrementally. Validate closure before commit. Preserve
   exact split rates and separate multiple legal graph decompositions from layout choices.
3. Multi-input consumers. Order incoming chains and ports spatially; compose complete battery
   and enriched-iron examples without a global placement-only phase. Resolve real external
   boundaries, then independently verify full inventory, recipes, rates and geometry.
4. Completion-aware trials and bounded rollback/replay. Compare chain candidates through actual
   routed continuation; keep estimates distinct from validated final scores. Retain unrelated
   validated regions and a complete incumbent. No budget failure is global infeasibility.
5. Controlled comparison and research conclusion. For all three recipe families, produce
   complete independently checked factory artifacts. Compare matched inventories and boundary
   semantics under matched total work budgets; separate proposal-generation and evaluation
   effects. Report area, physical cells, turns, completion, work and failure categories.

Every milestone requires tests, a reproducible CLI check, an evidence-backed slice report,
and a focused commit. The full goal is not complete when only contracts, fixtures or a partial
prototype exist. Do not silently redefine a failed recipe away. Production replacement needs
separate user approval.

## Research loop

For a failure, preserve the immutable input, last accepted witness, decision trace and smallest
reproducer. Classify it as missing pattern, proposal omission, port assignment, routing,
evaluation, invalid closure, or exhausted work bound. Compare it to the user's straight/folded
chains, deliberate slack, branch ordering and future-consumer placement examples. State one
testable explanation, vary one mechanism, and measure the change. Ask the user only when a
specific missing intention or example prevents meaningful progress.

## Scope and guardrails

- Keep production commands, the global exact solver and unrelated dirty files unchanged.
- Load game data externally; use no screenshot coordinates as algorithmic hints or defaults.
- No power constraints. No caller-supplied production width/height limit.
- Preserve commodity compatibility, transport capacity, directional ports, independent layers,
  pipe-first routing, and validated transactional growth.
- Proposals may bend, rotate, slide and alter gaps. A connected chain is not an immutable macro.
- Final score remains lexicographic area, physical belt/pipe cells, then route turns.
- A body-packing relaxation is neither a routed completion nor a whole-factory proof.
- A screenshot with omitted exports is only an internal reference, never full-factory success.
- Compare nine-facility human enriched iron separately from an eight-facility production plan.
