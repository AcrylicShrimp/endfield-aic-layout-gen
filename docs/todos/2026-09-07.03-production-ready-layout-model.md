## Context

performance, few futile actions, and at most 1% unused XY area in the 59-facility Heavy Xiranite
factory. Dense geometry and clean routing must be confirmed visually. If impossible, stop
immediately and report reproducible evidence supporting that verdict.

  current implementation limitations or heuristic failure with impossibility.
