## Proposed Changes

Add `tools/factory-edit-pilot/diagnostics/declarative_success_native_audit.py` and
focused tests. Reuse `declarative_action_runtime.Runtime` open/restore/step and
external catalogs, existing scorer features/score, and actual source bindings.
Promote only the useful bounded procedures from the ignored reviewer probe into
the maintained diagnostic. Do not embed invented facility dimensions in runtime
code or copy a second native action implementation.

Inputs are an explicit case manifest, release native library, and retained full
request/start plus any required native prefix/checkpoint. The compact scoring
JSON lacks sufficient native state. Prefer the actual `07db6d65`, `49f420e2`, and
`28c3cd68` cases when their complete sources remain available; identify missing
cases individually. At most eight baseline cases and two counterfactual variants
per case, 24 native replays total, 300 seconds wall time, and the existing per-case
native routing/action limits. Stop at the first resource cap; never enlarge the
budget to turn an inconclusive result into success.

Every counterfactual starts from an identical complete checkpoint. Remove an
identified inverse pair or substitute the band/pose construction while retaining
the remaining action order and physical port obligations. Generate each command
against the current blueprint/revision. Do not replay stale revision identifiers.
Classify an action that is no longer legal; do not silently repair its ports or
change the downstream plan to manufacture an equal endpoint. Compare actual
native used area and complete canonical final geometry, not bodies alone.

The geometric arm is eligible for the later bounded comparison only if both an
actual outward success and a non-loop compaction success reproduce, and each of
the two reversal families has at least one decisive paired comparison: both
variants finish natively valid with identical canonical final physical state and
gain, allowing direct attribution of the score difference. No such pair may give
a higher geometric bonus solely for a removable loop. Rejected, different-endpoint
or otherwise non-comparable variants do not count as decisive coverage. Passing
is a local screen, not a general proof. Any missing decisive coverage or
resource-limited required case makes eligibility false.
Rarity-only experiments remain permitted independently of this result.

Write an English report under `docs/reports/` with case-level evidence and a
compact manifest. Keep complete native fixtures and generated plots under
ignored `artifacts/`; register any justified minimal tracked benchmark fixture
through the existing benchmark asset registry. No audit runs during admission.
