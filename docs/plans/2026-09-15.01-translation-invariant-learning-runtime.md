# Plan: Make observations and bounded actions independent of global translation

## Current Status

- State: Completed
- Last Updated: 2026-09-15 13:58:55
- Blocker: None

## Goal and Scope

Priority **1 for likely learning impact**: the current coordinate divisor changes
every geometric input, while world-origin guards change candidate availability
and repair space. The same physical arrangement can therefore look different and
offer different actions. Correct the complete translation contract in one bounded
native-runtime cutover; feature-only trimming cannot establish this outcome.
Do not change area scoring, catalog rotations, demands, masks' structural meaning,
repair transactionality, reward or PPO. Rotations/reflections/scaling are not
declared symmetries. No generator optimization or common-editor extraction here.

## Proposed Changes

Introduce a native `PhysicalFrame` helper under `blueprint/declarative/` and share
its extent/translation routines with geometry repair. Compute minima/maxima in
`i128`, check span before converting to bounded local `i64`, and use
`s=max(width,height,1)`. World geometry uses `(p-min)/s`; lengths and displacement
use `/s`; facility-local port offsets use `/s` without subtracting world minima.
Add `width`, `height` and `1/s` metadata for the following feature-schema step;
the current observation immediately exposes grid scale rather than losing it.
Replace affected hardcoded global widths with the native contract constants.

Normalize admitted and edited internal geometry into a local frame. Preserve the
raw admitted request/witness for source digests and original production evidence.
At admission, normalize a checked physical working view before blueprint/port
compilation performs any `i64` coordinate arithmetic; checking an extreme raw
coordinate only after compilation would be too late. Derive raw catalog port
offsets at the origin and add them to placement coordinates in `i128` for extents.
Keep all index/port/component relations while translating the draft, its anchors,
and the blueprint view used for reconstruction. Current and retained-best states
may each have their own canonical frame; comparisons are physical, not byte equality
against an unnormalized source. Normalization is not an improvement and not an edit.
Only actual non-facility anchors and selected terminal arms contribute to extents.
Facility slots in `State.anchors` are historical reference positions; translate
them consistently for preservation but exclude them from occupied bounds and
physical span guards. Current facility terminal positions come from selected ports.
Rebase the existing owned edit draft in place; do not add a second full-state copy.

Allow signed temporary action destinations and symmetric signed repair padding.
Rebase the whole changed draft before bounded persistent-state checks, and rebase
again after successful routing if a new path extends the occupied box. Replace
absolute-coordinate guards throughout declarative edits and geometry checks with
checked local span/extent limits. Keep the existing 250,000-cell repair materialization
guard and expansion allowances. Negative padding cells are valid search cells.
Do not simply normalize to zero and keep the old negative-coordinate filter.

The native decision/limits and checkpoint schemas must identify the new coordinate
contract. Old absolute decision JSON must fail clearly, not execute in a new frame.
Export new witnesses in canonical coordinates. The legacy native v2 physical
snapshot reader verifies its original input/catalog bindings and actual saved
state under its recorded format, then converts current/best geometry once without
regeneration. Save the converted state as the new version. Old learned checkpoints
remain incompatible through the prerequisite; native physical import is not old
optimizer continuation. New-version same-contract restore remains direct.

## Verification Plan

Extend `declarative/tests.rs` with an integrated translation matrix: existing crossing
fixture, bridge/external-terminal case, port reassignment, overlap and missing-route
draft; translations (0,0), (100,200), (-100,-200), and safe near-i64-limit offsets.
Compare numeric features with wall elapsed pinned/ignored only for that known field
until the physical-observation plan removes it; all geometry must match exactly
after row correspondence. Check roots/masks and execute scripted place/rotate/port/
insert/delete actions, including a negative local destination and a detour through
negative padding. Observe rejected and unchanged actions and stale consumed handles.
Require exact integer work/status/path correspondence, not merely equal final area.

Keep the existing `aic-data` translation-score test unchanged. Cover zero-length
edges, supported 1x1 components, leading empty space, excessive
span and safe extreme coordinates. New/legacy physical pending snapshots must keep
actual paths, bindings, counters and best; old absolute action schemas must reject.
Use larger rectangles only in the isolated extent-helper test. An actual component
larger than 1x1 must retain the catalog's `unsupported-logistics-component-footprint`
rejection; this plan does not expand supported component geometry. Include a moved
facility whose historical reference anchor lies outside the current occupied box,
and assert that the reference does not enlarge its frame or affect physical guards.

Run required fmt/default workspace and learning-enabled checks/tests as specified
in the dependency. Run one release native matrix (at most 16 episodes x 32 actions)
and compare with retained `artifacts/physical-editor-extraction/before/` evidence
where action domains overlap. Domain changes near the origin are expected and must
be listed, not hidden by weakening assertions. Do not rerun the entire old suite of
performance studies or assert unchanged old learned trajectories. Record runtime,
packing bytes and validation counts. Run documentation maintenance checks and commit.
