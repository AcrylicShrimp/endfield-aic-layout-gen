## Goal and Scope

Make the subsequent I/O corrections safe to execute without silently mixing old
features, actions, optimizer state or replay. This is a prerequisite, **not a
hypothesized cause of past weak learning**. One outcome: a versioned admission and
restore boundary covering the real Rust learner's artifacts. No model behavior,
reward, source distribution, checkpoint cadence or long training changes here.

The user requested plans first, ordered by likely obstruction to effective
learning. The correction order is coordinates, physical observability, port
bindings, action-family prior, then evaluation separation. Dependency links in
the corresponding files express the execution order; this guard precedes them.
The evidence establishes interface defects, not their historical effect sizes.

## Proposed Changes

Add a small typed `LearningContract` in the native learning interface and use it
from `aic-learning`. Each ID describes semantics, not a source-code commit or
automatic hash of all implementation files. The compiled current contract has
exactly one supported production value. Later plans bump only changed components;
they do not add runtime switches that resurrect old builders. Bind model widths
and message rounds separately through the existing model configuration.

Change `aic-training-v1` configuration and `aic-training-checkpoint-v1` manifests
to explicit v2 schemas with the contract. Update `tools/native-training/training.json`
and live supported examples, preserving all unrelated numerical values. Historical
experiment configurations remain historical and fail with a migration diagnostic.
Update `tools/native-training/prepare-cached.mjs` to preserve and validate the v2
manifest contract when copying a current checkpoint; keep this existing bounded
benchmark preparation usable without converting its saved learning state.
Persist the contract in the existing checkpoint manifest; replay chunks inherit
that manifest's binding and need no per-row duplicate metadata. Include it in
model export metadata wherever learned tensors can enter the current runtime.

Do not guess missing contracts from tensor shapes or allow `--resume` to start
cold. Old learned artifacts remain readable with their recorded historical build.
A future physical-only import is a different operation from optimizer continuation;
the coordinate plan defines the one supported native snapshot conversion. New
training starts with fresh optimizer and feature replay after semantic changes.
