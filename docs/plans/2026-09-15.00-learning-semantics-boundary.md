## Goal and Scope

Make the subsequent I/O corrections safe to execute without silently mixing old
features, actions, optimizer state or replay. This is a prerequisite, **not a
hypothesized cause of past weak learning**. One outcome: a versioned admission and
restore boundary covering the real Rust learner's artifacts. No model behavior,
reward, source distribution, checkpoint cadence or long training changes here.

The user requested plans first, ordered by likely obstruction to effective
learning. The correction order is coordinates, physical observability, port
bindings, action-family prior, then evaluation separation. Dependency links in
the corresponding files express the execution order; this guard precedes them.
The evidence establishes interface defects, not their historical effect sizes.

## Proposed Changes

The user explicitly rejected the separate semantic-contract system after its
implementation in `064b061`. Remove it entirely. Reuse the existing checkpoint
`schema` field as the single learned-state format version. Set it to
`aic-training-checkpoint-v3`, distinguishing the brief v2 contract-bearing format.
Future changes to learned input/action/prior/replay meaning increment this one
checkpoint version even if tensor dimensions remain unchanged. There are no
per-component IDs, runtime semantic inference, source-code hashes, compatibility
modes or per-step checks. Existing config binding continues to cover settings.

Restore the unchanged original `aic-training-v1` config structure because the
extra contract field is gone. The existing bounded manifest read checks its `schema` before conversion to the
current typed manifest or reading any learned payload. Missing schema is reported
as null in the same diagnostic; older manifests can have obsolete fields. Preserve existing payload hashes,
retention, resource bounds and direct native/session/replay restore.

The manifest owns learner/Adam/RNG, best tensors and sparse replay. No independent
production model import exists. Non-resumable failure evidence returns to its
existing metadata format. Keep native physical snapshot schemas separate; physical
snapshot conversion remains owned by the coordinate plan. Old learned checkpoints
require their historical build or fresh training, never a version-label rewrite.
Update cached preparation to check the checkpoint version and preserve the manifest.
