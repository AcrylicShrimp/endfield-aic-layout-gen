## Proposed Changes

Integrate the reviewed dependency outputs in `Factory::action_batch`, `LowerPager`, MCTS/beam and hierarchical collection. Remove obsolete one-shot lower paths after their callers are cut over. Preserve existing CPU pool, batched model inference, checkpoint identity, evaluation separation, episode lineage, and CLI diagnostics. Keep only input/publication boundary checks needed for external data and accepted candidates; reuse trusted source-bound internal results instead of repeating replay or distribution audits. Do not add runtime per-sample factory-distribution scans. The integrated run uses one live-memory owner and records compact counters, not exhaustive traces.

Beam's one expansion per frontier state has no MCTS visit counter. Keep one owned placement-page cursor and lower pager with each live beam state while assembling that state's expansion. Complete its selected initial lower page before ranking children, including anchor and guided phases when available; a soft stop retains the exact owner and accepted actions while another live state may run, and a hard stop reports typed Unknown. If the first completed placement/lower page yields no actions, advance authorized pages under the existing request allowance until an action appears, all domains are exhausted, or a typed stop occurs. Only proven exhaustion may yield `NoMacroActions`. Once a state's candidates are ranked into the next beam, release its unused pager and reservations; retained child states start their own source-bound owners. This uses the existing beam width and native allowances, without a new candidate or time cutoff. Plan .16 must already have removed inference `Err(_) => anchor/None` resource fallbacks and charged compiled model state to the shared run owner before this integrated CLI can claim typed stops.
