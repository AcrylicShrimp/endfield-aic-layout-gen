## Proposed Changes

Add `operations/compare_declarative_training_setup.py` and focused tests. Reuse
the explicit transition/readiness implementation, normal duration command,
evaluation workers and `declarative_learning_report.summarize`. This is one paired
comparison outcome, not a new training engine, hyperparameter sweep or permanent
automation. The changed settings are exactly the shortlisted retention/sampling
configuration. Keep optimizer algorithms, SIL coefficient, model, native bounds,
fresh generator and 80/10/10 curriculum unchanged.

Both arms start from the original paused parent, not the four-update readiness
endpoints. Execute them sequentially on the server to avoid resource competition.
Use the same actual fresh input slot bank, linking immutable existing inputs into
each private bank with the established source-bound loader. Allow later inherited
parents to differ as a consequence of learning; retain exact chosen curriculum
plans and report the difference. Never force the baseline's inherited outcomes
into the candidate. Both arms perform 32 updates / 32,768 new actions. Main
training stays paused and its accumulated duration is not charged for diagnostics.

Reuse the identical parent evaluation if retained and bound to its model/panel.
Evaluate only the two endpoints otherwise needed, through the existing fixed
panel and two paired action seeds. Reject training/panel geometry overlap under
the existing disjointness rule. Aggregate the two replicates per geometry before
stratum means; do not count them as independent factories. The panel is being
used for setup selection, not an untouched final generalization test. Native
resource exhaustion keeps its truthful outcome and validated retained best.

Preregistered decision: the candidate must first pass all earlier coverage,
native validity, hard capacity, recovery, runtime and storage gates. Choose it
only if its mean panel area reduction exceeds baseline by at least one percentage
point overall; neither stratum's mean is lower; and paired geometry wins are at
least paired losses in each stratum. Require endpoint normal median-update time
at most 110% and peak retained bytes at most 125% of baseline, consistent with
readiness. Report time/label-normalized metrics as context without changing the
rule after seeing data. These thresholds are bounded experimental acceptance
criteria, not a theorem or proof across training seeds.

If candidate learning gates fail or differences are inconclusive, keep the current
baseline as the best-supported operational choice and state the evidence limit.
If an earlier plan yields no candidate or cannot pass a required gate, do not
manufacture an alternative or run this comparison; report the upstream blocked
condition and baseline/no-change recommendation with runtime criteria unchecked.
Do not change a failed gate into a pass merely because all scheduled processes
have ended. A future wider experiment needs its own reviewed scope.

Bound execution to two arms, 64 new updates total, 2,400 wall seconds, 4 GiB added
artifacts and the parent's RSS/free-space/native limits. Abort cleanly at a hard
limit, retain the latest normal checkpoint and mark partial evidence. Reuse
publication/retention; no full trajectory saving, construction reports, periodic
profiling or additional recovery journals. Keep endpoint/parent checkpoints and
irreplaceable input evidence; clean only regenerable diagnostic intermediates.
Finally verify the main run is still paused with the same parent update/protocol
and that no diagnostic workers remain. Do not prepare or execute a resume command.
