# Plan: Resumable repair attempt selection and guidance pricing

- State: Ready
- Last Updated: 2026-09-27 KST

## Goal and Scope

Select each untried repair neighborhood and prepare priced guidance for its next member under the current task allowance without repeating work after a temporary page stop. Retain history, variant order, model input/inference output, live-cell prices, edge-price positions and guide-to-route-pager ownership. This step ends at a retained member route pager or a typed stop; draft rebuild, member replay and candidate publication are separate steps.

- [ ] Historical prices, combination enumeration and failed-attempt history updates retain connection/route-cell/combination/conflict-cell indices and memory ownership. A selected variant is marked tried exactly once when its draft is durably admitted, not before a stoppable draft build.
- [ ] Repair member guidance uses the reviewed route-guidance input cursor and retains its prepared input and existing batched inference result across a page stop. A single model batch receives measured soft-time admission and a live reservation before execution. The priced guide remains owned while `RouteCandidatePager::new_unpublished` prepares the member; a stop there retains the unfinished route preparation.

A measured bounded amendment runs directly after soft admission and does not gain its own cursor merely for uniformity.
- [ ] Local selected-neighborhood and shared bridge fixtures compare resumed with uninterrupted variant, history, priced guide, charged work, exact memory transfer and later repair candidate. Upper-scale first-turn measurement includes attempt choice, inference and pricing, with the maximum indivisible guide-amendment time recorded.
- [ ] Before implementing inner choice/history or guide-amendment cursors, measure each subphase against the actual first-turn work/time credit and ownership boundary. Keep the top-level attempt/guide owner through stops, but simplify bounded subphases to direct calls; the implementation reviewer records the reason for every retained inner cursor.
- [ ] Keep the draft `Session` at one stable address from `RouteGuidancePreparation` creation through its last advance. The reused preparation checks the source address; implementation review verifies ownership does not move the draft while input preparation is live.

## Proposed Changes

Move `historical_price`, `next_untried` and `update_history` from one-shot loops in `hierarchical_search/negotiated.rs` into an owned `RepairAttemptProgress` in `RepairPager`. It keeps score/combination/history indices and stages a proposed variant until `RepairDraftPreparation` accepts it. Refactor `guidance_for_member` into retained input, inference, live-price and edge-pricing phases. Reuse the existing native guidance-input preparation cursor and batched predictor; before inference reserve input/activation/output capacity and admit its measured uncancellable time, then retain the guide across subsequent price pages. Extract native `repair_live_cell_prices` into a cursor over occupied cells and nested capacity owners. Mutate guide costs in the private retained guide with a per-edge cursor only when measured first-turn work requires it; otherwise admit a bounded direct amendment. No model rerun occurs after any price-stage stop. Keep one-shot helpers as drive-to-completion wrappers and no new routine validation scans.

The priced guide and its reservation remain in `MemberGuideProgress` until `RouteCandidatePager::new_unpublished` transfers them into retained `RouteCandidatePreparation`. If native route preparation stops softly, keep that partial preparation with the same guide and reservation. Do not release the guide before pager admission or rerun guidance because route preparation yielded.
