- State: Completed
- Last Updated: 2026-09-27 KST
- Blocker: None. Plans .00 and .22 have completed their scoped implementation reviews; this plan passed fresh-context design review.

## Goal and Scope

Remove the independent 250,000-cell per-path materialization guard from the shared `aic-layout` compiled-draft admission and independent validator, while preserving externally supplied layout rejection, bounded memory and exact geometry validation at their existing owners. Audit the distinct entity, footprint, aggregate-cell, coordinate and span limits against the intended production factory envelope. Observed generator layouts are evidence about headroom, not a definition of the product envelope. This is a reusable layout admission contract, separate from physical-editor route search and the completed-layout cursor in Plan .00.

- [x] Record the predeclared production-use-case maxima for occupied cells, bounding-box area, route cells, coordinates, facilities, terminals and connections from the accepted sampler and Plan .08's intended spatial envelope; do not infer these maxima from whichever local generator sample succeeded. If any predeclared required legal band exceeds a retained finite guard, change that guard at this boundary with measured resource admission and rerun the upper case before readiness; do not relabel the band unsupported or silently select a smaller sample.
- [x] Inventory and audit each actual boundary separately: editor facility-footprint area (2,000,000), 1x1 component footprint rule, separate body/reference/total-path cell counts (2,000,000 each), compiled entities (250,000) and physical span (1,000,000); independent validator block count (4,096), terminal/connection/bridge/junction counts (32,768 each), footprint width/height (1,000 each) and area (10,000), separate body and total-route-cell limits (2,000,000 each) and absolute coordinate range (0–1,000,000). Bounding-box area is a metric, not a 2,000,000-cell rejection. Retain a finite, measured external one-shot guard because `validate()` grants cursor memory reservations unconditionally; do not claim the cursor alone bounds external input. - [x] Bounded compiled-draft and normal-size physical-editor library fixtures plus a real completed-layout `aic-layout-gen validate` CLI case verify shared structural admission, independent long-path geometry acceptance, malformed external input rejection, resumed/one-shot metric parity and comparable normal-size runtime. Do not promise compiled-draft or injected-path editor CLIs that do not exist. Independent implementation review checks this shared admission boundary; Plan .17 later checks the physical editor's long-path integration.

## Proposed Changes

Remove `path.len() > 250_000` from `editor::validate_compiled` and `route.cells.len() > 250_000` from `ValidationCursor`, preserving their existing nonempty and uniqueness requirements. Do not add path adjacency or catalog checks to `validate_compiled`; independent validation owns full geometry here. The physical editor's `check_path` has a separate limit assigned to Plan .17, not an implicit prerequisite of this step. Keep checked aggregate counts and the finite external one-shot bounds while measuring actual cursor reservations, RSS and visits on a legal long path. Audit the distinct shared editor and validator guards listed above against a production-use-case envelope declared before panel sampling. The current 256-facility generator output demonstrates margin for its own cases only; Plan .08 must not treat it as a final production maximum. Any guard that excludes a required legal band is changed at its owning boundary with a measured finite replacement and an integrated rerun before readiness. Keep normal execution free of an extra scale audit; the proof lives in bounded offline probes and this plan's report.
