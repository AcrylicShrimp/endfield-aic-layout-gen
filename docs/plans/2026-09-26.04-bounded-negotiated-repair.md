- State: Ready

## Goal and Scope

Propose diversified legal route/network and repair witnesses by tracking present and historical congestion, trying deterministic bounded rip-up neighborhoods, and returning only candidates that pass native replay. Negotiated intermediate guides may conflict but never become outer actions. Preserve the classical anchor and existing batched lower guidance.

- [ ] Deterministic present/history prices identify blocked resources and choose a bounded conflict order, using exact rate/transport/component capacity and both bridge axes separately.
- [ ] Every exposed route, network or repair action has a complete witness and passes native replay on a clone; oversubscribed negotiated guides are never returned as valid candidates.
- [ ] Local sequential-order trap produces a native-valid repair when authorized and a bounded failure when repair is forbidden; a typed report returns only complete validated actions, termination, per-category charged work, peak bytes, retries and legalization failures even when no action is legal. A later limit returns `unknown` plus previously completed actions, never an unfinished repair.

## Proposed Changes

Carry forward the queue, pricing and deterministic conflict-order techniques from `aic-routing/src/negotiated.rs`, but derive capacity and candidate legality from the current native session, catalog components and exact rate arithmetic. Lazily prepare a bounded request workspace or reuse plan 02's prepared page. Before initial present/history price seeding and conflict-order enumeration, reserve peak table/order bytes and preflight scan/choice counts; charge actual scanned cells, route records and conflicts to plan 02's endpoint/graph/blocked-set preparation record caps as applicable. Do the same at every price update and failed retry. Generate a guide, identify a small declared set of conflicting committed routes within the trusted repair request, then reroute via plan 03's transaction. Expose one shared internal `prepare_repair_draft` path from plan 03's transaction for read-only candidate validation and final commit, so candidate screening creates one draft clone, rebuilds derived state once, replays all replacement members on that draft through a non-cloning internal native path, and validates once; final live commit rechecks identity and repeats the same transaction. The internal draft replay calls the checked native primitives without `step()`'s per-command observation/progress/completion scans, advances turns/revision equivalently, and defers automatic final validation until one explicit final legality check. For incomplete drafts this check verifies every committed native stable-state route, junction, bridge, port and capacity invariant; only complete drafts call the independent full-layout validator once. Index boundary terminals for constant-time occupancy lookup during each extension; if any full-state or terminal scan remains, charge every visited record with periodic deadline checks. Preflight and charge clone bytes, every survivor route/cell/component/port record visited in derived-state rebuild, every replacement command/cell, every existing-route cell and occupied user touched by native `Connect`, every component definition/rotation inspected for junction choice, and every route/cell/component/port record visited by the final legality check against plan 02's distinct copied-byte, blocked/preparation, native replay and validation-record caps. Reserve the simultaneous live bytes of source, draft, validator workspace and candidate output before work. Check the deadline periodically within rebuild, native `Connect` existing-route and catalog scans, member replay and final stable-state or full-layout validation loops, not merely at their boundaries. The anchor and guided searches, model inference, deduplication and publication use the same allowance. Check deadline at every phase boundary; late results become `unknown` and cannot publish a partial witness. Return a `NegotiationReport { actions, termination, per_category_work, peak_live_bytes, legalization_failures, ... }`; a later limit preserves previously completed native-replayed actions alongside `unknown`. Deduplicate by semantic route/component identity and retain a non-learned anchor across widening pages.
