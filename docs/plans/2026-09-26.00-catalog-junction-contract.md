# Plan: Catalog-valid branch and merge topology in physical layouts

## Current Status

- State: Completed
- Last Updated: 2026-09-26 15:42 KST
- Blocker: None

## Goal and Scope

Make the physical layout and native constructive session represent catalog-backed splitter and converger components, reject uncomponented branches/merges, and publish only independently validated topology. Preserve legal collinear same-commodity trunk sharing and exact rates. In the same physical schema cutover, represent the connection set and exact flow on each independent bridge axis instead of fixing one route per axis; this step validates that geometry but does not add crossing or repair search.

## Completion Criteria

- [x] A versioned physical schema records selected splitters/convergers and rejects ordinary branch/merge cells, invalid direction/rotation/ownership, overflow and false flow conservation; legal straight sharing remains valid.
- [x] The same schema represents one or more same-commodity routes per bridge axis, validates two independent perpendicular straight channels and axis-local capacity, and rejects false cross-axis reachability or mixed commodity on one axis.
- [x] Native route commits materialize a legal catalog component or reject without committing a new route; final output contains the selected components and passes independent validation.
- [x] All affected physical layout producers, readers, fixtures and CLI diagnostics use the new schema or fail explicitly with a migration diagnostic; no silent old-format reinterpretation.
- [x] A bounded local belt and pipe fan-out/merge workflow demonstrates actual component placement and validator admission, with a negative uncomponented branch case.

## Proposed Changes

Add a junction DTO and axis-owned bridge channels to `aic-layout/src/physical.rs` and update `SCHEMA` once with an explicit migration note. Reuse the catalog direction/capacity helpers and the directed-arm validation logic in `aic-data`'s constructive network validator where compatible; do not copy its entire factory representation. The independent validator derives each layer's unique directed arms and summed exact flow from route obligations, checks aggregate rate on every directed arm, requires a splitter or converger for multiarm sites, and verifies component geometry, rotated catalog ports, flow conservation and capacity. It also rejects a junction overlapping a bridge, terminal or facility body. A bridge holds independent horizontal and vertical channel owners and sums rate separately per axis; same-item routes may share an axis without joining the other axis.

The native session must use the same legality contract before route commit. Recompute only sites touched by a new route and update selected components deterministically from eligible catalog entries, while the final independent validator remains authoritative. If no legal component exists, reject the command/route witness without changing the committed state. Preserve existing clone/atomic macro behavior, port residuals, work bounds and compact observations. Update `aic-layout-gen`, `physical_editor`, test fixtures, schema-tagged CLI paths and any other `Solution` producers found by source search; do not leave an older producer silently creating incomplete v3 layouts.
