# Plan: Normalize the root prior over available action families

## Current Status

- State: Completed
- Last Updated: 2026-09-15 15:14:00
- Blocker: None

## Goal and Scope

Priority **4 for likely learning impact**: subtracting total family counts after
masking gives a family less probability when many of its roots are invalid. That
can suppress useful band exploration, but the optimal prior has not been measured.
Implement the explicit proposal: equal logits give equal mass to each available
family and uniform mass within that family. This is a policy change, not a claim
that the existing PPO probability calculation was inconsistent.

One outcome: consistent available-family normalization in behavior, frozen
likelihood, entropy and restore. Keep root indices, structural band rules,
conditional port distributions and all three action families. Do not introduce
a separate family head, feasibility predictor or hyperparameter search.

  zero probability and cannot introduce NaNs through log(0) or entropy arithmetic.
- [x] Equal valid logits produce equal nonempty-family mass; fully absent or masked
  families receive zero mass. Existing indices and conditional port masks remain exact.
- [x] Behavior and frozen PPO/SIL recomputation agree, including entropy and gradient.
- [x] The single learned-checkpoint format version changes; same-shaped old checkpoints are rejected.
- [x] No extra candidate scan is added outside the existing root/mask construction.

## Proposed Changes

Count unmasked roots while emitting candidates, then emit the retained per-root
log correction. For masked entries store a finite neutral count value; their logits
are masked before normalization. Keep exact zeros for excluded probabilities, and
compute entropy with a safe masked expression that never evaluates `0 * -inf`.
An empty whole root domain is an explicit native/policy error with the case identity,
not a uniform fallback. A missing family is ordinary and needs no error.

The corrected prior is `p(root i) proportional exp(logit_i)/n_valid(kind_i)`.
Learned logits still determine family preference; equality of family masses is
only the equal-logit reference condition. Keep conditional port factors' zero
count correction. Record family draw counts through existing aggregate diagnostics
at episode/update boundaries, without per-action file output.

## Pseudo Code Diff

```diff
~ native .../declarative/learning/input.rs
- counts[kind] += 1 for every root
+ counts[kind] += usize::from(!root.invalid)
+ correction[root] = if invalid { 0 } else { ln(counts[kind]) }

~ crates/aic-learning/src/model.rs::{roots,distribution}
+ require_each_graph_has_available_root()?;
+ adjusted = mask(logits - retained_correction, invalid, -infinity);
+ logp = segment_log_softmax(adjusted);
+ entropy = segment_sum(where(valid, -exp(logp) * safe_logp, 0));

~ training/frozen.rs and model/tests.rs
+ retain the exact mask and correction supplied during behavior;
+ re-evaluate without consulting current candidate enumeration;
~ increment the single learned-checkpoint format version for the changed prior
```

### Changes and continuity

- Native root generation increments available family counts while emitting each
  candidate. The separate total-count scan is gone. Masked entries retain finite
  zero corrections; unmasked entries use `ln(n_available)`. Root indices, structural
  band rules and port domains are unchanged.
- The shared distribution helper masks excluded adjusted logits to `-infinity`,
  giving exact zero probability. Entropy replaces their logarithmic multiplier
  with zero before multiplication. Entirely unavailable domains fail with native
  case identity or `aic-learning.empty-actions` plus packed graph/case context.
  The packed boundary counts availability during the existing mask copy, without
  an additional root scan or GPU-to-host per-head check.
- An actual 2,044-root case exposed float accumulation error **1.09772e-6**, slightly
  above the prescribed CPU tolerance. Root denominator and entropy reductions now
  accumulate in double and return float values. Conditional port normalization
  retains its existing float reduction; no new head or family hyperparameter exists.
- Frozen PPO/SIL keep the exact observed mask/correction. Existing update JSON now
  records `action_families` (`place`, `insert_band`, `delete_band`) from counters
  incremented in the existing sample-retention loop. No per-action files or new
  checkpoint diagnostics state were added.
- The single checkpoint format is `aic-training-checkpoint-v7`. Model tensor shapes
  are identical to v6, but v6 and earlier learned state is rejected before loading.
  Existing settings binding, native physical snapshots and direct restore remain.
