## Goal and Scope

Make the existing hierarchical collection report serialize and deserialize symmetrically when beam search has no root training records. This is the collection-report file contract used by search, generation and curriculum. It does not change legal actions, search targets, model checkpoints or panel-file admission.

## Completion Criteria

- [x] `SearchResult.root_records` omitted by the existing empty-vector writer loads as an empty vector; a nonempty MCTS record retains its exact content. No report schema or record identity is silently changed.
- [x] A locally produced search report with beam and MCTS results reloads through the generation entry point. The same panel, report and model identities remain bound, and a malformed or mismatched report still fails at its established boundary.
- [x] Feature-enabled and workspace checks pass, and independent implementation review confirms the report contract and required integration are complete.

## Proposed Changes

The current `SearchResult.root_records` has `skip_serializing_if = "Vec::is_empty"` without a deserialization default. Search writes an absent field for beam results, while `load_published_report` requires it. Add the matching empty default to this one field. Retain the writer's compact omission and the current report schema. Verify using the actual locally published report that failed `train-hierarchical-generation` with `missing field root_records`; do not add a routine output audit or compatibility layer. A one-line local code edit was made while diagnosing the CLI failure; it is provisional until this proposal and its implementation review pass.

## Pseudo Code Diff

```diff
~ crates/aic-learning/src/hierarchical_search.rs
  struct SearchResult {
-     #[serde(skip_serializing_if = "Vec::is_empty")]
+     #[serde(default, skip_serializing_if = "Vec::is_empty")]
      root_records: Vec<RootRecord>;
  }
  load_published_report(path): parse omitted beam root_records as []; preserve MCTS records;
```
