## Goal and Scope

Make the frozen lower and outer model inputs, candidate features, guidance heads and training targets represent legal components, crossing axes, port-pair and shared-trunk choices, and exact cost/resource outcomes. Keep learned predictions as guidance only; native search and validation decide legality. Use an explicit checkpoint/schema cutover with safe handling of prior model weights.

## Completion Criteria

- [ ] Lower inputs distinguish ordinary occupied cells, legal junctions, bridge axes and every remaining obligation, including typed pending endpoints; invalid remaining endpoint preparation is never silently dropped. Candidate features encode exact component and capacity use in addition to learned cost.
- [ ] The lower model emits directed opportunity cost plus compatible endpoint-pair, shared-trunk/crossing preference, bounded-search success, downstream routability and uncertainty estimates. Native `Guidance` carries these fields with identity, finite bounds and masks for only currently legal choices. Candidate generation actually uses these priors for ordering/diversity while preserving an unmodified anchor; none can authorize an illegal transition.
- [ ] Outer action tokens and search-distillation records include the actual component/resource/cost features. Both warm-start training and the normal `hierarchical_generation::lower_loss` train the new heads from exposed native-valid candidates and later outcomes, not from current model self-scores.
- [ ] New input, report and checkpoint schemas reject direct resume from old incompatible checkpoints. An explicit transfer maps every compatible named/shape-matched weight from the old model, initializes only incompatible new heads, and records both source identity and transferred parameter counts; frozen old experiments remain identifiable.
- [ ] One local CPU prediction/target/reload workflow is finite and preserves anchor candidate generation and held-out separation.

## Proposed Changes

Extend the existing graph/raster encoders and candidate token path rather than building another model. Add channels for selected junction kind/rotation and two independent bridge axes; encode candidate component IDs, exact capacity and cost breakdown. Carry plan 02's typed pending/invalid endpoint treatment through the remaining-demand input. Score the variable set of native-enumerated legal endpoint pairs and trunk/bridge attachments with a shared head over encoded context plus each choice's identity/geometry/resource features. Preserve a stable choice ID and mask to match model scores and later native outcomes; empty sets emit no choice loss. Carry bounded masked values through native `Guidance`, and use them only to rank/diversify legal candidate choices; the anchor queue ignores them. Build targets from exposed native-valid candidates and later exact outcomes in both `route_guidance_training.rs` and the normal `hierarchical_generation.rs::lower_loss` path. Keep separate lower and outer parameters, batched inference and compiled/eager parity. Version the lower model and outer action feature schemas, update parameter order and checkpoint validation, and provide a one-time explicit transfer of all shape-compatible named weights; incompatible heads are freshly initialized and identified as such in the report.
