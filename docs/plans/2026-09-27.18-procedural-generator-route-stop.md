# Plan: Preserve generator route-stop uncertainty

## Current Status

- State: Completed
- Last Updated: 2026-09-27 KST
- Blocker: None. Plans .14 and .22 are completed and this proposal passed fresh-context review.

## Goal and Scope

Make the procedural layout generator use Plan .14's one-shot router without losing its zero-length/crossing behavior or reporting a bounded route, pair or total-work stop as exhausted construction. This step owns generator attempt/final failure classification and Survey row's compact reason summary. It does not add routing machinery or change search budgets.

## Completion Criteria

- [x] Existing `PathOptions` preserve `allow_zero_length: true`, crossing choices, per-call work budget and unbounded scan/frontier options used by the generator. `Attempt.route_calls`, `route_expansions` and routing status counts retain actual work exactly once.
- [x] A route search stopped by work, scan, frontier, deadline, allocation or numeric resources, or by `repeated-cell` reconstruction, may be followed by independent candidates while generator attempt/work budgets permit. Its exact stop reason remains in the attempt. Exhausting an attempt's pair-trial or total-route-work allowance also marks that attempt search-incomplete, even if every returned route was a complete local `no-path`. If no complete layout is found and any unfinished search could have succeeded, final `Failure` is typed `generation-search-incomplete` with recorded reasons and attempts, rather than `generation-exhausted`. The latter means the configured attempt range ended after only fully evaluated alternatives, never global infeasibility. A terminal router diagnostic already returned as `Err` retains its precise code.
- [x] External cancellation during `connect` immediately returns `generation-interrupted` from `generate_until`, preserving the interrupted attempt. A Survey row then has `completed=false`, and the report counts it in `incomplete` with `deadline_reached=true`. A fully run bounded attempt ending `generation-search-incomplete` is an executed survey slot (`completed=true`) but remains unknown on feasibility; yield denominators and failure summaries distinguish that from a completed local rejection.
- [x] Survey rows expose compact aggregates of existing per-attempt route-status counts and attempt-end statuses alongside the last attempt status, so CLI callers can see an earlier route, pair or work stop without retaining all attempts or adding hot-loop tracing. Both bucket and topology/packing summaries group unsuccessful executed slots by final diagnostic code, rather than only the last attempt's status; row aggregates carry the more precise reasons. Batch retains its full attempt details. Document the changed diagnostic and Survey row interpretation; preserve compact output and do not add runtime audits.
- [x] Bounded CLI workflows and forced per-call, pair, work, final and mid-attempt cancellation stops verify correct completion, uncertainty and work accounting. Compare path identity, result yield, wall time and RSS before/after; do not lower default budgets.

## Proposed Changes

Keep the existing generator search call, work counters and explicit budgets; Plan .14 changed the router beneath it. Classify `PathResult.status` at the attempt boundary as found, complete local no-path, or search-incomplete due to a finite resource or repeated-cell reconstruction. Retain exact reasons in the existing attempt routing-status summary while trying independent alternatives. Mark the attempt incomplete when its pair or total-work limit ends exploration; do not infer that untried pairs have no path. Propagate `interrupted` immediately from `connect` and let Survey mark that slot unfinished. Final `generate` returns `generation-search-incomplete` with all attempt summaries when success is absent and any candidate or attempt was censored. It returns `generation-exhausted` only when tried alternatives were fully evaluated. Survey aggregates existing route and attempt-end status counts once at row construction and groups both summary types by final diagnostic code, so an earlier censored attempt cannot be hidden by a later local failure. Normal routing remains unchanged. The new diagnostic code and Survey `completed` meaning are documented for report consumers.

```diff
~ crates/aic-layout-gen/src/generate.rs
  preserve_existing_single_charge_of_route_calls_expansions_and_statuses();
- if result.status != "found" { continue; }
+ match result.status {
    "found" => publish_legal_route(),
    "no-path" | "blocked-endpoint" | "same-endpoint" => try_next_independent_candidate(),
    "work-budget" | "scan-budget" | "frontier-budget" | "deadline" | "resource-limit" | "repeated-cell"
      => { attempt.censored = true; try_next_if_budget_allows(); }
  }
- connect_returns_Ok_None_with_attempt_status_interrupted_and_generate_until_continues_or_exhausts();
+ if attempt.status == "interrupted" { return Err(generation_interrupted_with_attempts); }
+ if attempt.status in ["pair-trials-exhausted", "route-work-budget"] { attempt.censored = true; }
- no_success => Failure("generation-exhausted", attempts);
+ no_success if attempts.any_censored => Failure("generation-search-incomplete", attempts);
+ no_success => Failure("generation-exhausted", attempts);
~ crates/aic-layout-gen/src/survey.rs
+ row.routing_statuses = sum_existing_attempt_status_maps(attempts);
+ row.attempt_statuses = count_existing_attempt_end_statuses(attempts);
  preserve_existing_completed_and_incomplete_accounting_for_generation_interrupted();
+ bucket.failure_reasons[row.status] += 1;
+ profile.failure_reasons[row.status] += 1;
+ document_completed_as_slot_execution_not_feasibility_resolution();
```

## Verification Plan

Run one bounded real generator CLI case and a zero-length/crossing case. Force a finite per-call route stop before later alternatives; verify later work is attempted and the already charged work counters/statuses match actual calls exactly once. Force pair-trial and total-work exhaustion independently with no censored `PathResult` and confirm final `generation-search-incomplete`, retaining the attempt reason and Survey's route/attempt aggregate status maps. Force an earlier attempt to be censored and a later attempt to end in a complete local rejection; both bucket and profile `failure_reasons` must retain the final `generation-search-incomplete` diagnostic while the row preserves the earlier stop. Force a one-attempt cancellation *inside* `connect` and confirm `generation-interrupted`, Survey row `completed=false`, report `incomplete=1` and `deadline_reached=true`; cancellation before an attempt alone does not cover this bug. Check that a fully executed search-incomplete slot counts as completed execution but not success. Compare prior/current result, runtime and RSS, then `cargo fmt --all`, `cargo check --workspace`, `cargo test --workspace` and tracked-file check. Request independent implementation review.

## Execution Result

Implementation started after Plan .22 code and closeout commits. The reviewed proposal remained valid: Plan .22 changed only generator admission and publication, not this attempt/failure classification contract. The implementation propagates mid-`connect` cancellation immediately, classifies censored route/pair/total-work attempts as `generation-search-incomplete`, and adds compact route/attempt status aggregates to Survey report v3. The first independent implementation review found that `packing::sample` returns prefixed `aic-layout-gen.canvas-guard`/`body-guard` codes; an earlier unprefixed comparison would have mislabeled these as fully evaluated. The comparison was corrected and a real `max_cells=16` regression passed. A two-facility fixed seed 9 generator case proves a zero-length routed path; the existing complete-layout case proves crossings. A one-second 256-facility Survey CLI deadline produced `generation-interrupted`, `completed=false`, `incomplete=1`, `deadline_reached=true` with a retained interrupted attempt. `cargo fmt --all`, `cargo check --workspace`, `cargo test --workspace --quiet`, and the tracked-file worktree check passed after all edits. The final-source server comparison preserved a 100-facility layout byte-for-byte and classified the 256-facility crossing-forbidden bounded stop without changing connected count or route work. The second independent implementation review passed with documentation/cleanup notes, now closed. Code commit: `cdfd675de2e24044b2b552f477ae1d593577b012`. Evidence and cleanup are in the [closeout report](../reports/2026-09-27-generator-route-stop-classification.md).
