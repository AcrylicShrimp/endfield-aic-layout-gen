## Proposed Changes

Add `diagnostics/declarative_retention_screen.py`, a checked-in experiment JSON,
and focused tests. Load the corpus once and reuse cached compact rows. The initial
pool is identical in every arm, including recorded utility. Fixed actor/critic
weights come from the corpus parent, never from evaluation. Compute the existing
stage-balanced mean `-logp * max(return_to_terminal - value, 0)` once per unique
sequence with packed inference, retaining the existing per-stage normalization.
Cache these values under model and sequence identity. This substitutes a declared
frozen utility model for changing online weights, not an estimate of unobserved
historical critic values. Do not call it an exact replay of training.

Preregister a core factorial: retention {unchanged v1, v2 q=0.10/area ordering}
by sampling {uniform, rare-3pp score mixture, positive-advantage reference} by
sequences-per-minibatch {8,16,32}: 18 profiles. Add a q=0/area-ordering control
with uniform eight draws. If plan 00 permits geometry, add six profiles replacing
rare-3pp with capped-exterior score mixture at each count and retention setting;
for those using v2 also use capped-exterior immature ordering. Compare the geometry
package to its matched no-geometry package, without attributing its effect solely
to eviction or solely to sampling. Maximum 25 profiles; no further quota/weight
sweep. All v2 profiles use grace=64 and the sampling contracts of plan 05. The
0.10 fraction is a fixed candidate for this screen, not a selected production quota.

Use paired learner seeds 17, 29, 41 with production per-update replay generator
resets: `5_000_000 + seed*1000 + ordinal` and order generator
`6_000_000 + seed*1000 + ordinal`. Same-mode arms share the same random draws;
weighted versus uniform algorithms may consume different RNG calls and need
not produce one-to-one sample matches. Keep capacities 4,096 sequences / 262,144
labels in every arm. Smaller buffers do not substitute for this comparison.

At each corpus update, first sample each arm's preexisting pool using actual
production sampling code with that arm's configured sequence count and the
recorded production minibatch-call schedule. Aggregate its own frozen raw SIL
utility measurements with `observe`, refresh its sampled positive-advantage
priorities when enabled, then replay terminal attempts in original order using
the shared index and duplicate rule. Initialize imported reference priorities
from the bound frozen-model cache; new entries use plan 05's cold priority until
sampled. Preserve update ordering and no same-update sampling of new admissions.
Use the actual KL-stop-dependent call schedule, but acknowledge candidate online
models and KL stops would differ. Record restored initial usage separately from
new experimental exposures. Importance factors affect the reference arm's
reported effective SIL weights, not raw utility/priorities; no optimizer runs.

The primary cohort is fixed before any arm runs. Include each semantic ID absent
from the initial pool whose first attempted terminal admission is in the first
half of the interval, has a facility edit, and has 32 subsequent complete updates
available. Anchor every ID at that common first attempt, even if an arm later
retains, evicts or re-admits it. Initial-pool IDs never enter this cohort on later
rediscovery. Multiple attempts of a cohort ID keep the same denominator/time
origin; sum its draws across any re-admissions within updates anchor+1 through
anchor+32. Count retained time as the number of these boundaries where the ID
is present; absence and later reappearance do not reset the clock. This gives
arm-invariant at-least-once, draw-count and restricted-retention measures.

Both strata need at least ten distinct facility-edit episodes in this common
cohort, at least 32 follow-up updates, and at least 4,096 distinct newly attempted
semantic IDs across the complete interval. Otherwise issue
`insufficient_evidence`, retain descriptive results and do not extend the run
automatically. Describe initial survivors separately as left-truncated. Per-arm
admission-spell survival/unused eviction remains a secondary descriptive measure;
right-censored spells are not assigned an invented eviction time.

Primary measures per stratum on that fixed facility-edit cohort: fraction of IDs
sampled at least once within 32 updates, mean draws, and restricted retained time
through 32 updates. Report per-ID draw concentration, median/range across seeds,
positive-contribution draw fraction and frozen loss contribution; sampled often
but zero-gradient is not a learning benefit. Secondary measures include unused
spell eviction and effective sample size. No significance claim from three seeds.

For ordinary deletion coverage, fix the analogous common first-half deletion-only
ID cohort and union geometries sampled within each ID's 32-update horizon. Report
unique sampled episodes/geometries and mean incremental validated sampled gain.
A zero baseline coverage denominator makes the relative coverage gate undefined;
report `insufficient_evidence` rather than treating it as 100% or dividing by zero.
Report composition, reason counts, both limits and label-capacity overrides.

For storage, price the union of candidate entry references with corpus-recorded
live-credit and retained-checkpoint roots at each boundary. Use complete
**diagnostic union chunks** and their coverage/bytes for every arm, not baseline
published chunks that may omit same-update-evicted rows. Verify every reference
belongs to its declared union coverage. Report active-only, mandatory-root and
total/peak bytes separately, alongside the original baseline's published bytes.
This is a conservative common-representation/root estimate; actual child
checkpoint/storage cost is verified in plan 04. Do not claim proportional disk
savings from selected segment count. Record one-off capture/inference separately
from replacement, sampling and publication costs.

Preregistered gates (experimental tolerances, not accepted product limits): every
seed passes hard capacities and source validity; each stratum's median primary
at-least-once fraction improves by at least 5 percentage points over v1/uniform/8,
with no seed worse; ordinary deletion geometry coverage is at least 90% of that
baseline in each stratum; peak common-root source bytes are at most 125% of it.
In addition, the median fraction of facility-edit cohort IDs receiving at least
one positive raw SIL contribution must not decrease in either stratum. If the
baseline at-least-once fraction is above 95% in a stratum, the 5-point gate cannot
be met there; return no candidate under this registered gate and report the
ceiling rather than silently changing metrics after seeing the results.

Geometry arms must also improve at-least-once fraction by 2 percentage points
in one stratum without reducing the other, compared with their matched same-count,
same-retention no-geometry arm. Candidates failing any gate are not shortlisted.
Choose among passing candidates by fewer sequence draws, then absence of geometry,
then fewer changed retention/sampling mechanisms, then lower peak bytes and stable
profile ID. Report matched contrasts for quantity-only, sampling-only,
retention-only and combined effects, including the positive-advantage reference.
No candidate's frozen exposure gain is presented as a trained-policy gain.

Bound the screen to 25 profiles times three seeds, 600 seconds, 2 GiB added outputs
and existing RSS/free-space limits. Build frozen per-sequence raw loss and positive
advantage caches in one packed inference pass. Use a noncompeting device; CPU is
supported. If required inference/screening cannot finish within the cap, emit
partial evidence and `insufficient_evidence`, never silently drop large factories.
No threshold, profile or run extension is added after inspecting results without
a material plan revision and fresh review.
