# Plan: Score outer actions in bounded pages with one encoded state

## Current Status

- State: Completed
- Last Updated: 2026-09-28 04:50 KST
- Blocker: None

## Goal and Scope

Expose a reusable encoded-state outer-model interface and a source-order score pass that produces globally normalized first-stage and anchor priors from bounded action pages. Preserve the current model head, `f32` model probability conversion, `f64` anchor normalization and first anchor mixture. Keep the graph encoding live once per root, use a bounded raw-score temporary for the global normalizers, and return sequential prior pages to the catalog. This step does not choose Gumbel actions, publish replay records or change the optimizer.

## Completion Criteria

- [x] `OuterModel` encodes the graph once and scores bounded action rows without page-local softmax. One value-head result belongs to that encoded state and its derived root model value reaches the catalog when the score pass finishes. Its existing multi-graph dense forward path remains a parity reference until the catalog cutover.
- [x] Preserve the existing `compiled_inference` benefit: support compiled page-head inference over the reused encoding, or show with a bounded comparable measurement that the new eager page path meets or improves the retained compiled path's integrated time and memory. Do not silently switch configured compiled inference to a slower path.
- [x] The score pass writes 12-byte `(f32 raw logit, f64 anchor score)` records in source order, computes global model/anchor normalizers, then reads the raw stream sequentially to yield `(f64 first-stage prior, f64 anchor prior)` pages. It preserves both normalizations, the `f32` `exp` conversion and current anchor-mixture arithmetic within declared parity tolerance; near-tie sort-order consequences are tested explicitly.
- [x] Page tensors, encoded state, temporary writes and normalizers have bounded ownership and admission through existing search memory/disk failure paths. A stopped incomplete root discards its unpublished raw stream; no new routine journal or per-action validation is added.
- [x] Bounded real-graph CPU timing records encoder calls, batch/forward time, output bytes and RSS. Tests and independent implementation review pass before catalog integration.

## Proposed Changes

Split `outer_model::Model::forward_unchecked` into a reusable encoded-state operation, action-head scoring and the existing full-batch normalization wrapper. Keep the same weights and action feature schema. Inspect `OuterRunner::Compiled` and preserve its useful inference cost through a compiled page-head path or a measured, comparable replacement. Add a narrow score-pass owner beside hierarchical search; it takes the existing `Input`, source-ordered action pages and anchor scores, appends checked raw records, and produces a sequential reader only after global normalizers are complete. `RootScorePass` owns its raw-score temporary until `finish` moves that owned temporary into `SourceOrderPriorReader`; the reader removes it after the second pass or on early drop. Plan .03's catalog owns the score pass/reader by value, then separately owns the normalized source-order ledger and sort temporaries. If the model is absent, retain the current anchor-only prior behavior and avoid a needless graph encoding. One admitted page owns its temporary tensors; successful page completion advances its in-process cursor. Crash recovery can discard the unpublished temporary and rebuild the root from stable input.

## Execution Result

Plan .01 is Completed after three independent implementation review rounds. `outer_model.rs` now shares an encoded-state/value-head owner between the old dense forward and bounded raw-logit pages. The compiled wrapper has a separately traced page head over the same reused encoding. The small dense-versus-page test passes for eager and compiled pages of different lengths; exact bit equality is not promised because matrix multiplication changes rounding with batch shape, so near-tie ordering remains a specific verification gate.

`hierarchical_search/root_scoring.rs` now owns the unpublished 12-byte raw-score temporary, one encoded graph, page admission, complete source-order global normalizers, a sequential prior reader and in-process early-drop cleanup. Its five-action physical-graph test matches dense priors within 1e-6 and exact anchor-prior bits for eager and compiled heads; early drop removes the temporary. The module is not yet integrated into the root catalog. No server has been used.

The mixed two-action fixture scores a real terminal placement and a native route witness from the same partially placed state; both first-stage and anchor priors match the dense path. Identical actions split across pages retain equal prior bits and stable source-order tie sorting. The anchor-only path returns anchor priors and no model encoding. A page-memory refusal leaves its temporary unpublished and early drop removes it. The raw stream is buffered only for sequential reads; a direct per-record file read was measured at 5.782 s over 5,715,346 actions, so one 64 KiB admitted reader buffer reduced the equivalent pass to 2.384 s.

A 64-action near-tie fixture measured maximum dense-versus-page prior error 7.451e-9 in eager and compiled modes; 124 pair orders changed, all among pairs within twice that measured error plus 1e-9. Exact duplicates retained identical bits. Page scoring therefore has a declared numeric tolerance but cannot promise the dense path's rank-Gumbel noise assignment for arbitrarily close scores. Plan .03 must test the resulting shortlist and selection consequence explicitly.

Local release physical score-pass evidence: 100-block partial, 5,715,346 Place actions/22,327 native pages, 2.384 s eager and 2.357 s compiled total; 68,584,152 raw bytes removed on reader drop; maximum RSS 220,250,112 eager and 218,447,872 compiled; peak charged memory 93,376,256 bytes. The 30-block partial ran 545,380 actions/2,132 pages in 0.193 s compiled, with 6,544,560 raw bytes and maximum RSS 221,675,520. All complete runs yielded a 2.0 checksum for normalized model-plus-anchor priors. The page head preserves the compiled path with a small per-page cost difference, while the full physical pass retains one graph encoding.
