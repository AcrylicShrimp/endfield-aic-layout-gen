## Goal and Scope

Make full-factory `candidates::describe` enumerate its complete bounded pose and component action vocabulary for legal observations above the current 200,000-cell area guard. Preserve action identity, deterministic candidate order, configured scan/candidate limits, exact preflight and compact diagnostics. This step owns the reusable full-factory pose/component vocabulary and spatial occupancy helpers, before Plan .19's route reembedding outcome classification.

## Completion Criteria

- [x] Remove `poses::actions`'s unconditional `area > 200000` rejection. Checked positive extents and allocation sizes govern `spatial::Prefix`, `empty_rectangles`, `origins` and movement checks; overflow or actual resource refusal produces a typed unknown/resource diagnostic, never a misleading missing-action, omitted group or infeasible verdict. `components::actions` uses the same checked/fallible prefix and checked canvas/stride arithmetic; `translations` propagates a resource failure from `Preflight::new` to `describe` rather than recording an `Omitted` group. No new smaller fixed area cap appears.
- [x] Preserve every pose and nonpose action that the prior code exposes on existing supported observations, its action key/order, configured scan/candidate bounds and preflight legality. Investigate the separate hard group truncations of 512 translation groups and 128 compound groups, plus the 16-member group/pose acceptance ceilings at the declared 256-facility/upper-pattern scale; replace an unjustified truncation with a bounded, explicit and observable group/work policy that permits the required legal groups, while retaining deterministic order. A bounded stop or required large closure omitted by a capacity rule reports search-incomplete vocabulary, never a falsely complete smaller action set. Keep genuine frozen-anchor exclusions distinct from capacity refusal. A sparse legal above-200,000-cell observation reaches `candidates::describe` and then Plan .19's reembedding route caller. Resource stops retain prior complete action candidates where the existing publication boundary permits.
- [x] Bound dense prefix/empty-rectangle memory by actual admitted capacity and avoid rebuilding full-area prefix maps per candidate/group when a measured upper observation makes that prohibitive. Reuse stable occupancy/geometry work where possible and keep small direct scans direct; no generic resume protocol or runtime output audit is added without a specific first-turn need.
- [x] Bounded existing and above-200,000-cell CLI workflows compare actions/keys, route reachability, elapsed, RSS, temporary peak and failure classification before adoption. Independent implementation review verifies no hidden upstream guard still prevents full-factory reembedding at the declared scale.

## Proposed Changes

Keep `candidates::describe`, `poses::actions` and `components::actions` as the caller boundary. Replace the flat area rejection with checked extents and an admission plan for the actual `spatial::Prefix` and `empty_rectangles` buffers, including simultaneous buffers. Make their constructors fallible and carry resource diagnostics through translations, compound poses and component actions to `describe`; check `origins`' `nx × ny` and stride arithmetic before iteration. Profile the upper observation's repeated prefix builds; reuse immutable occupancy or selected-group geometry within one `describe` call if repeated full-grid setup exceeds the configured first-turn cost. Retain the existing finite scan/candidate configuration and action ordering. Measure where the 512/128 group limits and 16-member closure/pose limits truncate legal upper-scale observations; make `groups::add`, `poses::options`, `changes::facility_rotations` and `movement::plan` agree on admitted group size; either demonstrate they never truncate the supported band or move them into an explicit admissible group/work budget with an incomplete status on exhaustion. Do not silently call the truncated vocabulary complete. Preserve external input validation once at admission and keep hot-loop occupancy queries direct.

## Execution Result

Implementation started after Plan .20 completed. A covered-geometry-valid 35 × 6,022 sparse witness (area 210,770; 12,006 route points) reproduced the upstream area rejection. The witness probe's `factory_validated` field is hardcoded false by that CLI and is not the covered-geometry verdict.

The area guard and 512/128 group truncations were removed, and the 16-member ceilings were aligned across group generation, pose options, rotation changes and movement. Pose enumeration now shares one body occupancy index, using sparse storage for very large mostly empty canvases. Spatial extents/allocation and origin/component arithmetic are checked; rectangle enumeration has explicit configurable work and temporary-buffer budgets whose exhaustion is typed `factory.vocabulary-resource-incomplete`. Independent implementation review found that the pre-existing 512-call global compound preflight limit still silently truncated later streams. The default global stop was removed because per-stream scans and retained candidates already bound enumeration; an explicit smaller global budget now reports typed incomplete. A second review found that empty compound work still scanned the canvas and that two point collections allocated infallibly; both were corrected and a zero-compound, large-canvas regression passed. A legal 255-facility replica stress witness above 200,000 cells produced 561 translation groups, 306 compound groups and 35,456 actions in 3,047.656 ms with 53,248 KiB process RSS from a clean commit checkout on the server. A separate legal long-detour witness produced 810 actions, and selected pose actions from both witnesses reached reembedding and returned candidates. The baseline 59-facility list had 2,261 actions in 103.168 ms; the complete changed list has 2,955 actions in 283.668 ms, retaining every old action unchanged and in relative order. The replica is only a stress input, not a training-distribution claim. Details and reproduction are in `../reports/2026-09-27-full-factory-pose-vocabulary-scale.md`.

`cargo fmt --all`, `cargo check --workspace`, `cargo test --workspace`, witness probe CLI checks, tracked-file worktree/index checks and the clean-commit server measurement passed. Implementation commit: `03ac8753`. Independent implementation review passed with a nonblocking measurement-distribution note. The server experiment was closed out and its regenerable source, build, generated witness and raw evidence directory was removed; cleanup details are in the report.
