## Goal and Scope

Replace dense **Gumbel** `RootRecord.actions` and `OuterExample` retention with the versioned source-order root catalog and an exact streamed outer-policy gradient. Keep a separately tagged **PUCT dense** record and its existing bounded replay/training path, because PUCT still publishes root actions. Keep the lower-model training examples, completed-Q target, selected-action replay, value loss, optimizer schedule and evaluation split. This is the complete Gumbel search-to-generation-to-optimizer cutover; remove obsolete dense Gumbel production paths after parity. It does not relax training distribution quotas or claim upper physical/GPU readiness.

## Completion Criteria

- [ ] Gumbel generation publishes versioned catalog descriptors rather than dense per-action root copies. On load/resume it verifies sidecar length/checksum, source, per-case `Limits`, effective config, checkpoint and feature schema once; it rejects old ambiguous records explicitly and preserves selected action identity, episode and evaluation separation.
- [ ] A tagged record distinguishes PUCT dense roots from Gumbel catalog roots. PUCT keeps its current complete bounded action records, selected index, replay and outer/lower training semantics; the Gumbel branch uses the catalog. Both variants have explicit schema/version handling, and old untagged records are rejected with a diagnostic rather than silently reinterpreted.
- [ ] Replay streams native placement pages in source order alongside retained first-stage/anchor priors, then retained initial and late lower witnesses. It reconstructs `f32` target pages from `q_0`, visited overrides, `logZ` and the second denominator; late actions contribute to the current-model softmax but get zero frozen root target, while their lower examples retain final provenance.
- [ ] Outer training encodes each graph once, computes the full current-model log-sum-exp with unchanged parameters, uses the actual `f32` target sum `T`, and accumulates page gradients with detached `(T × softmax_i − target_i)` coefficients. It backpropagates the combined context/entity gradient through the encoder once and applies the existing value loss and batch/optimizer scaling once. The true cross-entropy scalar is reconstructed for metrics; the old dense path survives only as a bounded offline oracle.
- [ ] Replay-window ownership holds descriptors and bounded readers, never all action rows or targets. Training storage and aggregate process memory are measured through actual collection, publication, reload, one optimizer update and resume on legal partial/placed 30/100 physical cases. A failed storage/memory/work budget reports resource Unknown without a partially committed target.
- [ ] Dense-versus-streamed loss and every model parameter gradient, selected-action replay, lower examples and a resumed training step agree within declared tolerance on bounded fixtures. Relevant CLI workflow, feature-enabled tests and independent implementation review pass before downstream training is resumed.

## Proposed Changes

Use a tagged `RootRecord` with a bounded `PuctDense` variant and a `GumbelCatalog` variant. The source-bound catalog descriptor is the single durable target authority for **Gumbel** roots. Its generation loader reconstructs the exact source state and opens its sidecar at a stable boundary; it never builds `Vec<RootActionRecord>` or `Vec<[f32; 49]>` for the full Gumbel root. An `OuterReplaySource` streams Gumbel actions/targets on demand, while PUCT continues through its existing dense bounded replay/training path. For the Gumbel optimizer, keep current parameters fixed across a no-gradient normalizer pass and a gradient page pass. Accumulate head gradients and encoded context/entity derivatives pagewise using the existing `tch` backward primitive, then run one encoder backward and the existing optimizer step. Preserve existing train/held-out separation and selected-example identity without downsampling hard roots to make a batch fit. Plan .08 later adds per-stratum quota selection over the published handles; that future selector is not an execution dependency or implementation task here. Remove the old dense **Gumbel** production path after parity and cutover. Use only boundary identity checks and required output publication checks, avoiding per-action provenance hashes or distribution audits.

## Pseudo Code Diff

```diff
~ crates/aic-learning/src/hierarchical_search.rs
- RootRecord { actions: Vec<RootActionRecord>, selected_action: usize, ... }
+ enum RootRecord { // tagged, versioned; old untagged input rejected
+     PuctDense { actions: Vec<RootActionRecord>, selected_action: usize, root_summary, ... },
+     GumbelCatalog { catalog: RootCatalogDescriptor,
+                     selected_action_id: Vec<u8>, root_summary, ... },
+ }
~ Gumbel root publishes the catalog descriptor after atomic sidecar publication;
~ PUCT keeps its existing bounded progressive-page actions and dense record.

~ crates/aic-learning/src/hierarchical_generation.rs
- for action in record.actions { child = action.apply(...); dense_features.push(...); }
+ match record {
+     PuctDense { actions, selected_action, ... } => existing_dense_replay_and_examples(actions, selected_action),
+     GumbelCatalog { catalog, selected_action_id, ... } => {
+         replay = OuterReplaySource::open_and_verify(catalog, panel_case, effective_config);
+         for page in replay.source_order_pages() {
+             rows = regenerate_native_or_retained_witness_features(page);
+             targets = reconstruct_f32_targets(page, q0, visited_q, log_z, second_denominator);
+             offer_bounded_optimizer_page(rows, targets);
+         }
+         replay_selected_action_by_physical_id(selected_action_id);
+         preserve_late_lower_witnesses_and_final_provenance_for_lower_examples();
+     }
+ }

~ crates/aic-learning/src/outer_model.rs
+ fn streamed_policy_and_value_update(encoded_state, replay_pages, optimizer) -> Result<Loss> {
+     frozen = no_grad_full_logsumexp_and_target_mass(replay_pages); // same parameters
+     for page in replay_pages_again() {
+         logits = score_page_with_grad(encoded_state, page.rows);
+         coefficients = detach(frozen.target_mass * exp(logits - frozen.log_z) - page.targets);
+         accumulate_head_and_encoded_gradients(logits, coefficients);
+     }
+     backpropagate_encoder_once_plus_existing_value_loss();
+     return true_cross_entropy_metric_plus_value_loss_before_existing_optimizer_step();
+ }
```
