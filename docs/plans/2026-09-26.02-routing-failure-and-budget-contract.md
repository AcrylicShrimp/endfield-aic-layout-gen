# Plan: Truthful routing failures and bounded network requests

- State: Ready
- Last Updated: 2026-09-26 15:15 KST

## Goal and Scope

Make every ready logical-network request produce a candidate set or a specific diagnostic/termination, and enforce a work and deadline allowance across all routes, variants and retries in that request. Preserve explicit local proof versus unknown semantics. No new route generation strategy is introduced here.

## Completion Criteria

- [ ] No selected or remaining obligation's endpoint error is silently converted into absent demand. Unplaced endpoints are explicitly `not-ready` in both task preparation and lower guidance; invalid stable requests surface a structured error; compatible-but-unroutable tasks retain local termination and work evidence.
- [ ] Allocate a `RequestAllowance` before any expensive selected or remaining endpoint preparation. Its separate finite caps cover endpoint-domain visits, raster/graph rows and underlying route-cell visits, blocked-set body/terminal/occupied-cell visits, copied state bytes, inference elements, A* expansions/frontier entries, routing-kernel scans (penalty/preflight maps, path reconstruction, candidate cost, overlap, diversity and deduplication), native replay visits to existing-route cells/occupied users/component definitions and rotations plus other replay/validation records, published bytes and peak live memory, plus a wall deadline and candidate/variant caps. Preflight record upper bounds without constructing full inputs; charge actual visits to their cap and check the deadline periodically within every long preparation, routing, candidate postprocessing, replay and validation loop. Reserve conservative memory/phase maxima before work. A stopped or overrun phase returns `unknown` with per-category actual use and releases reservations.
- [ ] Only complete, independently replayed candidates that passed a final deadline/budget publication check may enter the returned set. On later exhaustion, return those completed candidates together with `unknown`; discard incomplete pages. `NoMacroActions` is emitted only if the completed set is empty and preserves the diagnostic. A capped non-interruptible inference batch has an explicit maximum and observed deadline overshoot; late results are discarded.
- [ ] A fixed point-to-point request may prove local infeasibility only after its complete legal graph is exhausted without a work/time/candidate cutoff. The current finite greedy network variants never claim network infeasibility; zero network candidates after a ready compatible domain return `unknown` unless a separate complete network proof is implemented and reviewed. An empty compatible-port domain retains `NoCompatibleEndpoints`. Outer `NoMacroActions` preserves the reason.
- [ ] CLI-visible diagnostic examples distinguish missing endpoints, exhausted frontier, work limit and deadline, with compact counters and no per-visit trace.

## Proposed Changes

Replace the `ready` iterator's `.ok()?` and remaining-demand `if let Ok(pairs)` with typed results. A cheap readiness scan may inspect placement flags and obligation IDs, but must create `RequestAllowance` before allocating endpoint-pair domains, raster/graph guidance, variant sessions or model inputs. Pass the allowance into selected and remaining-demand preparation. Keep unplaced obligations pending, preserve the existing `NoCompatibleEndpoints` outcome for a placed but empty port domain, and propagate malformed stable requests. Use one envelope with independent count caps rather than adding incomparable units: endpoint-domain visits, raster cells, graph entity/relation/spatial row visits and underlying route-cell visits, blocked-set body/terminal/occupied-cell probes, copied state bytes, inference tensor elements, A* expansions and live frontier entries, routing-kernel visits to penalty maps, preflight checks, reconstructed path cells and candidate cost/overlap/diversity/dedup records, replay existing-route cell and occupied-user visits, component-definition/rotation visits during native `Connect`, other derived-state/validator record visits, and published candidate bytes each have a configured maximum; candidate and variant counts have their own maxima. Precompute conservative input row and route-cell bounds from immutable counts before allocating graph/raster buffers. The wall deadline bounds the combined path. Reserve conservative peak bytes for simultaneously live sessions, model batches, A* frontiers, price tables and output buffers before a bounded page, and release on completion; reject a page as `unknown` when its reserve does not fit. Charge actual work to its matching count cap. Lazily materialize variants in bounded pages. Check deadline before and after each preparation/inference/search/replay/publication page and every bounded interval of endpoint enumeration, raster fill, entity/relation/spatial row construction, blocked-set formation, penalty-map/preflight scanning, A* expansion, path reconstruction, candidate postprocessing, native `Connect` scans of touched routes and catalog rotations, derived-state rebuild, replay and final validation. Long preparation may never defer its clock check until after a whole input is built. A non-interruptible inference batch has a fixed size/input cap and reported deadline overshoot; late results are discarded. Return an atomic set of only previously published, complete native-replayed candidates with `unknown` when a later page exhausts an allowance; discard unfinished pages and preserve the reason even when candidates exist. Ensure the exact-graph local proof includes legal junction and crossing transitions after plans 00-01. Finite network variants never prove network infeasibility.
